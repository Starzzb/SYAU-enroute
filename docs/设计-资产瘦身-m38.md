# 内置资产瘦身（m38）：大纲去英译、培养方案目标与要求压成一句话

写于 2026-11-21。对应 `在途/curriculum/_work/squeeze.py`，不变量测试 `app/src/test/java/cn/dkarbon/enroute/PackedAssetsSqueezeTest.kt`。

## 1. 为什么动这两块

APK 里 assets 占 46.7%（5.41 MB / 8.52 MB），其中课程大纲 4.50 MB、培养方案 0.36 MB。
两块加起来 4.87 MB，比全部代码（dex 4.29 MB）还大。内容上它们是**同一段话的两份译本**和**结构化信息已经另存一份的原文长文**，属于可切冗余。

实测两处冗余的量：

| 位置 | 冗余形态 | 原文明文字节 |
|---|---|---|
| 大纲「二、课程简介 / 二、实践课程简介 / 二、实验课程简介」 | 中文段落后紧跟同义的英文段落（整段翻译） | 1.38 MB |
| 培养方案「培养目标 / 毕业要求」及两个列表 | 正文 2000–3500 字；编号条目（培养目标1、毕业要求1.1…）已另存 `培养目标列表` / `毕业要求列表` | 2.18 MB |

## 2. 切法与边界

### 2.1 大纲：只留中文

- 只处理标题**含「简介」**的小节。`一、课程基本信息`（表内英文名称属字段值）、`六、教学内容` 一律不碰。
- 判据：一行没有汉字、字母 ≥6 个且字母占比 ≥45% 视为英文正文行。
- 先试**整段切除**：从第一行英文起，若其后全部是英文，则整段删到节末；否则退化为逐行摘。
- **全英文的小节不删**（避免留一个空节）；删完为空则回退原文。
- `英文名称`、`基本信息.英文名称` 等结构化字段一个不动。

结果：2066 门里 2061 门有简介被处理；简介节明文 2.37 MB → 0.99 MB，其中英文行 1.38 MB → 0；残留英文 0 行。

### 2.2 培养方案：目标与要求 → 一句话 + 页码

替换后字段形态：

```jsonc
{
  "培养目标": "培养目标与毕业要求（含指标点）原文见《2025级沈阳农业大学本科人才培养方案》第 178–179 页。",
  "毕业要求": "",
  "培养目标列表": [],
  "毕业要求列表": [],
  "目标与要求页码": [178, 179],   // 新增：起 = 「2.培养目标」标题页，止 = 「4.主干学科」标题页前一页
  "目标与要求原文字数": 3489      // 新增：被删掉的明文字节数，留个可追溯的量
}
```

- **页码不猜**：现扫源 PDF（`D:/Download/课程大纲2021/*级沈阳农业大学本科人才培养方案.pdf`），在每个专业 `章节页范围` 内找 `2.培养目标`、`3.毕业要求`、`4.主干学科` 三个标题行，取前两个的页与主干学科页。168 份全部命中，0 份缺页码。
- 映射表落盘在 `curriculum/_work/目标与要求页码.json`（168 条，附每节各自页码）。
- 其它字段（专业介绍 / 主干学科 / 专业核心课程 / 主要实践性教学环节 / 修业年限 / 授予学位 / 课程设置与教学进程 / 学分结构表 / 各学期学分分配表 / 2025 版两段说明）**全部原样保留**。

## 6. 回归护栏

`PackedAssetsSqueezeTest` 四条：

1. `课程简介里不再有大段英文` —— 扫全部 2067 个简介节，英文行必须为 0。
2. `简介的中文正文没有被一起删掉` —— 抽到的简介中文不少于 20 字（防「切英文时把中文也切了」）。
3. `培养方案的目标与要求只剩一句话且页码真实` —— 毕业要求为空、两个列表为空、那句话 ≤120 字；页码必须落在本专业 `章节页范围` 内，带页码方案数必须 168。
4. `事实字段一个都没少` —— 池 5574 行不变、每份方案都有课程行、专业介绍非空。

跑法：`build-test.bat`（或 `:app:testDebugUnitTest --tests cn.dkarbon.enroute.PackedAssetsSqueezeTest`）。

## 7. 还能再切的部分（本轮没做）

按同样的「同义重复」标准继续找，还有两处候选，但都要先确认界面取舍：

1. **大纲 `一、课程基本信息` 的正文**（1.13 MB）：那是表格的纯文本 dump，`基本信息` 字典已经把同样内容结构化存了一份。删掉正文、只留字典，能再省近 1 MB 的明文，但界面「内容章节」里会少一节原始排布。
2. **大纲 `七、课程教学的基本要求`**（7.39 MB，全仓最大单节）：不是重复，是正文；能压的只有措辞，不能删。

继续动之前建议先看真机：`六、教学内容` 里含「课程思政内容」段落，删改要另立规矩（属原文内容，不是译本）。
