# m36 · 详情的框与底

原型：`docs/design/m36-详情压底.html`

---

## 1 结论先说

正文**要一个框**；纸纹是**底**，只在框外与页脚露出来。两层：

```
① 底　整页纸 + 纸纹（铺满，随视口固定，不随内容滚）
② 面　框（纸底 + 1 圈 1px 描边 + 压印），圈住眉行 / 标题 / 元信息 / 正文 / 落款
③ 字　标题 19sp·800 ／ 正文 14.5sp·行高 26 ／ 字段行 左标右值
```

框里**不重复铺纹**。纹的作用是让页面有一个「衬底」，不是做在正文上。

同一时间要退役的那套是 `AnchoredCardOverlay`（`ui/kit/AnchoredCard.kt:132`）——
304dp 宽的锚定卡 + 遮罩 38% + 卡内第二层滚动。它是「挑一项就关」的形态，
被用在资讯文章、考试详情、大纲详情三处阅读场景上，行宽被压到 276dp（一行约 12 字）。

改：三处详情都变成 **整页 + 一框**（整页不再是浮层，框在整页里）。
留：收藏长按菜单、来源筛选、导入面板、清空确认，它们仍在用浮层。

## 2 框的参数

| 项 | 值 |
|---|---|
| 圆角 | 8dp |
| 描边 | 1dp `t.outline`（#7E776A / 暗 #8C8474） |
| 框底 | `t.card`（#FCFAF6 / 暗 #1F1C17）；A 档不透明，B 档 `alpha = .96` |
| 压印 | 上 `pressIn`（亮 #2C2C2C@5.5% / 暗 黑@55%）16dp，下 `pressOut`（亮 白@85% / 暗 白@4.5%）12dp，内缩 12dp |
| 投影 | `0 1px 2px rgba(44,44,44,.05)`，只一层 |
| 内距 | 左右 16dp；上 16dp；下 18dp |
| 框外留白 | 页面左右各 14dp —— 纹在这里露出 |
| 位置 | 返回行下 6dp |

两种框底，任选：

- **A 实心（推荐）**：`background = t.card`，纹完全不透。长文最清爽。
- **B 半透**：`background = t.card.copy(alpha = .96f)`，纹淡透 4%，框与纸像同一张纸，长文会有一点噪。

## 3 八款纸纹

三款在用 + 五款新做。全部 `drawBehind` 逐笔画，不用 Bitmap、不用 Shader，暗档自动换色（`texInk`：亮取 `inkFaint`、暗取 `ink` 且 α×0.72）。

| 名 | 步距 | 线宽 / 半径 | α 亮 / 暗 | Compose 画法 |
|---|---|---|---|---|
| 十 CROSS | 30dp | 1dp，长 7dp | .080 / .058 | `drawLine` ×2 |
| 格 GRID | 24dp | 1dp ＋ 1.1dp 圆 | .055 / .10 | `drawLine` ＋ `drawCircle` |
| 织 WEAVE | 27dp / 54dp | 1dp | .052 / .038 | `drawLine` ±30° |
| **回 MEANDER** | 32dp | 1dp 折线 | .30 / .16 | `drawPath`（8 段方折回环） |
| **波 RIPPLE** | 22dp 环距 | 0.6dp 弧 | .080 / .058 | `drawArc` 同心（圆心在页脚外） |
| **鳞 SCALLOP** | 28×17dp | 0.7dp 弧 | .080 / .058 | `drawArc` 半圆叠瓦 |
| **砂 DOTS** | 12dp | 0.9dp 点 | .10 / .072 | `drawCircle` 阵 |
| **冰 CRACK** | 120dp 一组 | 0.8dp 折线 | .26 / .14 | `drawPath`（固定点表，五条斜折线） |

分配建议：

- 资讯文章 → 十（或 冰，最像旧纸）
- 考试详情 → 格
- 大纲详情 → 织
- 教务功能盒 → 回（方折回纹，最像公文）
- 校园功能盒 → 鳞
- 收藏与历史 → 织
- 课表卡 → 格
- 数据卡（成绩/培养方案/教室）→ 砂 / 波 / 冰，且 α×0.6（密度高，纹重了会成噪点）

`冰` 是唯一不规则的一款：五条斜折线按固定点表画，同机同尺寸下逐帧一致，不会闪。

## 4 详情骨架（三处一致）

| 层 | 参数 |
|---|---|
| 返回行 | 44dp；‹ 34dp 触区；来由 10.5sp `inkFaint` 字距 .05em；右侧动作 34dp |
| 眉行 | 分类 11.5sp·600 `inkSoft`；右侧（N 天后 / 学分）9.5sp 等宽 |
| 标题 | 19sp / 行高 27 / 800 |
| 元信息 | 9.5sp `inkFaint` 等宽，`·` 分隔，末尾靠右 |
| 通栏线 | 1px `ink`，元信息下 13dp |
| 正文 | 14.5sp / 行高 26；段间 13dp |
| 分节 | 9sp 字距 .20em → 7dp → 1px `rule`@.45 → 字段行 24dp |
| 字段行 | 左 11.5sp `inkFaint` 宽 68dp；右 12.5sp·600 等宽数字 |
| 页脚 | 22dp 后，10.5sp `inkFaint`；页底再叠 64dp `transparent → paper 62%` 渐隐 |

考试详情三节（考场 / 场次 / 原始记录）在同一框里，分节只靠小标题 + 淡线 + 留白，**不各做一张小卡**。

## 5 进出动效

- **进**：整页从被点条目矩形放大 —— 缩放 .94→1、位移 12dp→0、透明 0→1，220ms，`CubicBezierEasing(.22,.9,.24,1)`；框内内容再延迟 60ms 淡入 180ms。
- **出**：反向 180ms，`(.4,0,.2,1)`，无过冲；返回键与返回箭头同一路径。
- **滚动**：列表位置 `rememberSaveable`；详情内滚动重进归零。
- **减少动画**开时只做 120ms 交叉淡入。

### 10.2 实装时改掉的两处设计判断

1. **整页详情必须与下层互斥，不能叠。** 第一版是「叠加 + fillMaxSize」，真机上底下那层的返回按钮/刷新/⋯ 仍可点 —— 因为 Compose 里没有 `clickable` 的区域不吃事件，命中测试会落到下层兄弟节点。改成互斥：大纲替换 tab 内容、考试 `return@Box`、资讯本来就是 if/else。
2. **`paperTexture` 只画纹线、不画底。** 整页详情必须先 `.background(t.paper)` 再 `.paperTexture(...)`，否则纹画在透明层上，会透出下层页面文字（截图里能看到搜索框残影）。

### 10.3 真机实测的浓度

新五款初版按原型取值（回纹 .30、冰纹 .26），在 1080×2400 的真机上压过文字，读起来像迷宫。统一收到与 `GRID` 同档：

|---|---|---|
| MEANDER 回 | .300 | **.105** |
| RIPPLE 波 | .080 | **.055** |
| SCALLOP 鳞 | .080 | **.055** |
| DOTS 砂 | .100 | **.070** |
| CRACK 冰 | .260 | **.100** |
| CROSS 十（详情整页） | .062 | **.090**（整页面积大，反而要提） |

## 12 详情页要「真的是新页」（2026-11-20 修，主人指出）

第一版把三处详情都做成整页画布，但只做了「画满」这一步，没有做「换页」这一步：

- 资讯、考试两处详情画在 tab 内容区里 —— 底栏还在，能一边看详情一边换 tab；
- 考试详情还在 `ExamScreen` 内部渲染，外层 `UserScreen` 的 `SubHeader`（‹ 考试安排）照画不误，
  于是详情页头顶出现**两个返回箭头**；
- 大纲详情当时更糟：浮层盖着，底下的列表返回键还能点到。

改法统一成一句：**详情不是「盖在上面」，是「换掉这一屏」**。

| 谁 | 状态放哪 | 渲染在哪 |
|---|---|---|
| 大纲 | `AppState.syllabusOpenId` | 根节点，`if (…) SyllabusSheet(…) else …` |
| 考试 | `EnRouteRoot` 里的 `examDetail: Pair<ExamItem, Boolean>?` | 同上，`else if (shownExam != null) ExamDetailPage(…)` |
| 资讯 | `feedVm.detail`（本来就有） | `FeedScreen` 内部 if/else，`FeedDetailView` 占满 |

底栏一处收口：`if (ui.syllabusOpenId.isBlank() && examDetail == null && feedDetail.item == null)` 才画 `InkNavBar`。

`ExamScreen` 因此只上报意图、不持有详情：

```kotlin
onOpenDetail: (ExamItem, Boolean) -> Unit = { _, _ -> }   // 第二个参数 = 直接落「原文」那一节（长按进）
```

`ExamItem` 在 `cn.dkarbon.enroute.data.ExamItem`（`data/Academic.kt`），不在 `data.model`。

### 12.1 还有一处：整页画布必须自己铺底

`paperTexture` 只画纹线、不画纸色。整页详情如果不先 `.background(t.paper)`，
底下的搜索框、列表字会从纹线缝里透出来（真机上一眼能看见「找回放」四个字的残影）。
`DetailScaffold` 的外层 Box 现在是：

```kotlin
.fillMaxSize()
.background(t.paper)                 // ← 必须先铺纸
.paperTexture(tex, t, radius = 0.dp)  // ← 再画纹
.graphicsLayer { … 进出动效 … }
```

## 13 大纲章节正文：只断行，不动数据

大纲 JSON 里「一、实验课程基本信息」这类小节，是 PDF 直接抠出来的 key-value 长串：
`课程代码901130131开课教研室电工电子教研室课程名称模拟电子技术实验…`。
一坨挤在一起没法读，但它**就是原文**，不能改。

处理限定在显示层（`SyllabusSheet.kt` 的 `prettySectionText`）：

1. 少于 80 字不动；已经有多个换行不动；命中的键名少于 3 个不动（否则会把普通叙述切碎）；
2. 命中键名才在它前面补 `\n` + 全角空格缩进；
3. 键名表要容许字间空格 —— PDF 里是「学 时」「学 分」，写成 `学\s*时` 才认得。

两个踩过的坑：

- `trim()` 会把行首的全角空格（U+3000）当空白一起吃掉，首行就少了缩进 —— 只 `removePrefix("\n")`；
- 断行后值太长仍会在行内折行且续行不缩进（`Text` 的天然行为），不另外处理。
