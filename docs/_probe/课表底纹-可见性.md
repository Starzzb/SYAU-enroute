# 课表底纹可见性修复

- 日期：2026-11-15
- 真机反馈：课表页的超立方体底纹（MathBackdropMotion）看不见了
- 根因：票 33 把底纹从 GridArea Canvas 内（网格之后 = 视觉最上层）抽到
  TimetableScreen 最外层 Box 的最底层，被上方的行带/今日列/卡片盖住。
- 改动文件：仅 `app/src/main/java/cn/dkarbon/enroute/ui/timetable/` 下的
  `TimetableScreen.kt` + `MathBackdrop.kt`。

## 一、alpha 改动前后对照

| 项目 | 改动前 | 改动后 |
| --- | --- | --- |
| 底纹 alpha（暗色） | 0.075 | **0.17** |
| 底纹 alpha（亮色） | 0.042 | **0.11** |
| 底纹线宽 | 1 物理像素 | **1.4 物理像素** |
| 交错行带 zebra（暗色） | 0.55 | **0.22** |
| 交错行带 zebra（亮色） | 0.45 | **0.18** |
| 课卡实心度 | 实（t.card 不透明） | **不动** |
| 今日列 wash | 不变 | **不动** |

## 二、为什么提亮到 0.17 / 0.11

分层之前，底纹画在 GridArea 的 Canvas 里、画在网格**之后**，视觉上压着行带和卡片，
0.042/0.075 的极淡取值就够看。分层之后它落到最底层，上面依次盖着：

1. **交错行带 zebra**（最重遮挡）：每行整条 `drawRect`，原 alpha 0.55/0.45；
2. **今日列底色 wash**：`t.primary.copy(alpha = 0.045)`（编辑版）/ `Tt.todayWash`；
3. **课程卡片 `t.card`**：不透明实底。

0.075 被 0.55 的行带一盖，等效亮度只剩原来的一半还不到，等于消失。
所以底纹必须自己扛住遮挡：暗色 0.17、亮色 0.11。这个值比
`MathBackdrop.kt` 里 `tesseractAlpha(editorial, isDark)` 的编辑版口径
（0.115/0.085）更高——那个口径是按「关于页」（留白最多、无行带）调的，
课表页不共用它，见 TimetableScreen 固定背景层注释。

## 三、为什么行带降到 0.22 / 0.18

行带的职责是「提示行存在」，不是「铺一层底色」。0.2 左右已经足够看出隔行条纹，
0.55/0.45 则是把底纹整条盖死。降到 0.22（暗）/0.18（亮）后：

- 条纹仍然可辨（行带职责保留）；
- 0.17/0.11 的底纹能透出来；
- 课卡实心度不动——卡片是内容，必须实。

## 四、分层与省电四条（保持，未退化）

1. **分层保持**：底纹仍是 TimetableScreen 最外层 Box 的固定背景层，
   不随 Pager 左右滑动、不随页内 verticalScroll 滚动。
2. 可见才跑：`LaunchedEffect(visible, animScaleOff)`，页面不可见/Lifecycle 不达
   STARTED 时协程停止。
3. 每帧零分配：顶点/棱/角度复用 `TesseractBuffers`，`withFrameNanos` 的 lambda 不捕获变量。
4. 不逐帧重组：相位 `mutableFloatStateOf` 只在 Canvas draw lambda 读，只重绘不重组。
5. 动画时长 = 0 静止：`ANIMATOR_DURATION_SCALE == 0` 时不启动动画，只留静态姿态。
