## 2. 设计红线（继承 + 本次专项裁定）

继承 `HardTokens.kt` 三条红线，任何一条破了就是回退：

1. **圆角一律 0**。本规格所有卡片、时间轴节点、浮层、按钮、菜单行均为直角（节点用 `drawRect` 而非圆点）。
2. **无渐变、无 elevation**。浮层立体感只用 `Stroke.strong`(1.5dp) 实边；需要投影才用 `hardShadow`。**禁 shimmer**（骨架一律静态色块）。
3. **数字全部 `NumericFont`**（IBM Plex Mono，`tnum/lnum`）：日期、时刻、时长、场次、学分、分数、均分、倒计时、接口状态码。

本次专项裁定：

| 项 | 裁定 |
|---|---|
| 间距 | 只允许 `Space` 档位（2/4/8/12/16/20/24/32）。旧 `spacedBy(1.dp)` / 5dp 一律归一到 4dp 以内（本规格用 2dp / 0.75dp 线距） |
| 描边 | 四级制不跳级：网格/行线 0.75dp `rule`；卡片 1dp `outline`；浮层 1.5dp `outline`；「下一场」2dp `primary` |
| 色条 | 只允许 3dp（`Stroke.accentBar`）：「下一场」卡左侧、不及格成绩行左侧 |
| 动效 | 只允许 `Motion.fast/base/slow`（120/180/240ms），无回弹。**列表内零逐条动画**；浮层位移 180ms |
| 主色当文字 | 硬朗农业下 `t.primary`(#C74E17) 对卡面 4.37:1 → **≥14sp/700**（AA 大字号 3:1 档），本规格工具条「刷新」即 14sp/700 |
| 字重 | 400 / 500 / 700 / 800，禁 300 及以下 |
| 触区 | 一切可点元素 ≥ 48dp：工具条按钮、分组头（可折叠）、成绩行、菜单行、浮层关闭 ✕ |
| 图标语言 | 不用 emoji；沿用「方角字块」：`⋯`、`▸/▾`、`›`、`✕` |

## 3. 信息层级方案

### 3.1 层级总纲（三层漏斗）

```
第一层  时间层（还有几天？）   → 「下一场」卡（倒计时 + 日期 + 时刻 + 考场）
第二层  扫描层（哪天哪场？）   → 时间轴：左侧日期节点 + 右侧卡片（课名 / 起止 / 考场）
第三层  查证层（到底怎么算的？）→ 详情浮层：主信息 → 次信息 → 原始 JSON + 全部 key
```

### 3.2 工具条（替换页内标题，D2）

```
┌──────────────────────────────────────────────┐
│ 4 场 · 下一场 12-15 · 32 天后       刷新  ⋯  │  48dp
└──────────────────────────────────────────────┘   0.75dp rule
   点开看三层详情 · 长按直接看原始 JSON             9.5sp
```

- 左侧 `label`（**唯一一次计数**）：11.5sp / 400 / `NumericFont` / `inkFaint`；折行不换行（`maxLines = 1`）。
  内容由纯函数产出（`ExamRows.toolbarLabel` / `ScoreRows.toolbarLabel`），三态：
  - 有未来场次：`4 场 · 下一场 12-15 · 32 天后`
  - 全部考完：`4 场 · 已全部考完`
  - 有折叠：追加 `· 已折叠 1 组`（**筛选状态**）
  - 成绩：`55 门 · 6 学期 · 3 门不及格` / 筛选时 `只看不及格 · 3 门`
- 右侧「刷新」：14sp / 700 / `t.primary`（满足主色文字档），触区 48dp（视觉即文字，靠 padding 撑满）；加载中同位置显示 11sp `抓取中…` / `inkFaint`。
- 右侧「⋯」：26dp 方框 + 1dp `outline`，字符 13sp `inkSoft`，外套 48×48dp 触区。点开「更多」浮层（§4.6）。
- **不再出现任何「考试」「成绩」字样**：标题由 `UserScreen.SubHeader`（L86–90）承担。

### 3.3 首屏纵向预算（考试页，360 × 800 dp）

| 序 | 区块 | 高度 | 出现条件 |
|---|---|---|---|
| 1 | SubHeader（既有） | 44dp | 常驻 |
| 2 | 工具条 | 48dp + 0.75dp 线 | 常驻 |
| 3 | 交互提示行 | 16dp | 有数据时 |
| 4 | 下一场卡 | ≈ 74dp（10+16+3+22+3+16+6） | 存在未考完场次 |
| 5 | 「今天/本周」组头 | 48dp（可折叠）/ 28dp | 该桶非空 |
| 6 | 时间轴一行 | ≈ 84dp（课名 1 行）/ 100dp（2 行） | 每场一行 |
| 7 | 列表余量 | ≈ 430dp（无下一场卡时 504dp） | — |

**首屏必须同时可见**：真实场次数、下一场倒计时、至少 1 个组头 + 2 张考试卡。

### 3.4 结构化字段契约（D3/D4/D5）

`data/Academic.kt` 里 `ExamItem` / `ScoreItem` 的解析改为**逐行落位 + 全量保留**：

| 来源 | 字段 | 说明 |
|---|---|---|
| `title` 第 1 行 | `name` | 课程名 |
| `title` 第 2 行 | （仅当 `start`/`end` 解析不出时回填 `time`） | 时间段原文 |
| `title` 第 3 行 | `campus` | 校区 |
| `title` 第 4 行 | `building` | 教学楼 |
| `title` 第 5 行 | `room` | 教室 |
| `title` 第 6 行起 | `extraLines: List<String>` | 学校加字段时不静默丢弃 |
| `title` 中匹配 `座位…` 的行 | `seat` | 这套部署不返回；出现才认，且**该行不再当教室** |
| `start` / `end` | `date`、`startClock`、`endClock`、`durationMin` | 时长由真实起止算；解析不出 = `0`（不是脑补 100 分钟） |
| `id` / `color` | `apiId` / `colorHex` | 只存档，界面不使用（全 App 只有一套课程色） |
| 全部键 | `fields: Map<String,String>` | **原始 key 全量**，空值/null 也保留键名 |
| 成绩 `YWKCM` | `englishName` | 英文课程名 |
| 成绩 `KCSXMC` / `KCLXMC` | `category` / `courseType` | 课程属性 / 类型 |
| 成绩 `KCH` / `KXH` / `XS` | `code` / `classNo` / `hours` | 课程号 / 课序号 / 学时 |
| 成绩 `ZXJXJHH` / `KSSJ` | `termCode` / `examDate` | 学期代码 / 考试日期 |
| 成绩全部键 | `fields` | 同上（实测单条 21 个键，一个不丢） |

派生属性（不参与序列化）：`ScoreItem.creditValue`（学分 > 0 才有效）、`scoreValue`（百分制才有效）、`failed`（§5.5）。

## 4. 考试页：时间轴结构

### 4.1 分桶规则（纯函数 `ExamRows.bucket`）

| 桶 | 判定 | 排序 | 可折叠 |
|---|---|---|---|
| 今天 | `date == today` | 起止升序 | 否 |
| 本周 | `today < date ≤ 本周日`（**周一为首日**） | 起止升序 | 否 |
| 更远 | `date > 本周日` | 起止升序 | 是（默认展开） |
| 已结束 | `date < today` | **倒序**（最近考完的在前） | 是（**默认折叠**） |

- 「本周」用日历周而非「未来 7 天」：后者会把下周一也算进本周，和用户看周历的直觉冲突（单测 `今天 本周 更远 已结束 四桶按日历周切` 锁住：周五 → 周日属本周，下周一属更远）。
- 日期解析不出来的脏数据归「更远」并显示 `待定`，**不**归「已结束」。
- 已结束默认折叠：`ExamRows.build(..., collapsed = setOf(ExamBucket.PAST))` 的首屏只留组头（`已结束 4 场 · 已折叠 ▸`）。

### 4.2 时间轴几何（一行）

```
 11-15      ┃ ┌───────────────────────────────┐
  周六      ● │ 不动产估价              2 天后 │  ← 主：课名 14sp/700 + 倒计时
            ┃ │ 08:00-09:40 · 100 分钟         │  ← 主：时刻 11.5sp NumericFont
            ┃ │ 主校 · 第二教学楼 · 201        │  ← 次：考场 11sp/16sp
            ┃ └───────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 日期列 | 宽 40dp，右对齐，距卡 12dp；日期 12sp/700 `NumericFont`；周几 9sp `inkFaint` |
| 竖轴 | `drawBehind` 画 1dp `outline`（暗色下 `rule` 几乎看不见），x = 44dp，贯穿整行高 |
| 节点 | 7×7dp 方角，垂直中心 y = 20dp：**下一场** = 实心 `primary`；其余 = 纸色挖空 + 1dp `outline` 描边（先画 `paper` 再描边，否则轴线会穿过方块） |
| 卡片 | 1dp `outline`（下一场 2dp `primary` + 内距不变），内 padding 12/10dp |
| 列表边距 | `contentPadding(start = 12, end = 16, top = 2, bottom = 28)`；行间靠卡片自身高度，不额外 `spacedBy` |

### 4.3 「下一场」倒计时卡（P0 主诉求）

主人原话是「能一眼看出下一场还有几天」。实现上把倒计时提到**列表第一个 item**（不进任何分组、不可折叠）：

```
┃ 下一场                              32 天后
┃ 不动产估价
┃ 12-15 周一 · 08:00-09:40 · 主校 · 第二教学楼 · 201
```

- 左侧 3dp `primary` 色条（`Stroke.accentBar`）；卡 1dp `outline`；内 padding L14/R12/T10/B10。
- 头部标签「下一场」10sp / 字距 0.6 / `inkFaint`；倒计时 13sp/700 `NumericFont` / `primary`。
- 课名 15sp/700 `ink`（最多 2 行 ellipsis）；明细行 11sp/16sp `inkSoft`，**只拼真实存在的那几段**。
- 「下一场」定义：`isFinished == false` 中 `startAt` 最小者；`isFinished` 按**结束时刻**判（今天的上午场在 09:00 之后就不算下一场）。
- 关于「考点显示倒计时」：本轮按「关键点=下一场倒计时」实现；同时**考场三件套（校区/楼/教室）在卡与详情里全量落地**，两种读法都成立。

### 4.4 考试卡三层信息

| 层 | 内容 | 规格 | 落点 |
|---|---|---|---|
| 主 | 课程名、起止时刻、倒计时 | 14sp/700 `ink`；11.5sp `NumericFont` `inkSoft`；11sp `NumericFont` | 卡片正面 |
| 次 | 校区 · 教学楼 · 教室、时长、座位 | 11sp/16sp `inkSoft`；10.5sp `NumericFont` `inkFaint` | 卡片正面（座位真出现才显示） |
| 原始 | 完整 JSON + 全部 key + 复制 | 9.5sp `NumericFont`，`SelectionContainer` | 详情浮层第三段 |

### 4.5 分组头

`今天 1 场` / `本周 2 场` / `更远 1 场` / `已结束 4 场 · 已折叠 ▸`
- 标签 11.5sp/700/字距 0.4；计数 10sp `NumericFont` `inkFaint`；下方 0.75dp `rule`。
- 可折叠头最小高 48dp（触区），不可折叠 28dp；折叠后只留组头，组内条目不进列表（`build` 里 `continue`），**计数仍是真实场次**。

### 4.6 「更多」浮层（考试）

`重新抓取` / `接口诊断` / `折叠-展开已结束` / `折叠-展开更远（N 场）`；每行 48dp，行间 0.75dp `rule`，行内「标题 + 一句它会做什么」。

## 5. 成绩页：学期分组与统计

### 5.1 结构

```
工具条：55 门 · 6 学期 · 3 门不及格            刷新  ⋯
提示行：点开看英文名 / 课程属性 / 原始 JSON
┌ 2025-2026学年春            1 门 · 2 学分      ▾ ┐  ← cardAlt 组头
│ 算术均分 90.0 · 学分加权 90.0                     │
├──────────────────────────────────────────────────┤
│ 应用遥感技术                     90              │  ← 17sp/700 NumericFont
│ Application of Remote Sensing…   优              │
│ 限修课 · 2 学分 · 32 学时 · 901040337            │
└──────────────────────────────────────────────────┘
（…其余学期…）
页脚说明：不显示绩点与排名……
```

### 5.2 学期排序（`ScoreRows.sortTerms`）

- 排序键 `(学年起始年, 季次序)`，秋 = 1、春 = 2、夏 = 3；**倒序** → 最新学期在最上，同一学年里**春在秋之上**。
- 解析不出学年的学期排最后且不丢（组名用 `学期未标注`）。

### 5.3 组头统计（只显示算得出来的）

| 项 | 计算条件 | 不满足时 |
|---|---|---|
| `N 门` | 恒可算（计真实条数） | — |
| `X 学分` | 该学期**每一门**都有 `creditValue`（> 0） | 不显示这一段 |
| `算术均分` | 该学期**每一门**都是百分制（`scoreValue != null`） | 显示「含等级制课程，不计算均分」 |
| `学分加权` | 上面两条都满足且学分合计 > 0 | 不显示 |
| `N 门不及格` | 恒可算（§5.5），仅 > 0 时显示 | 不显示 |

### 5.4 纯函数与单测（D9）

`ui/academic/AcademicRows.kt`：`ExamRows`（分桶/倒计时/管线/统计）与 `ScoreRows`（学期排序/统计/筛选管线）全部无 Compose 依赖，JVM 单测直接打真实 payload 与边界：

- `AcademicRowsTest`：四桶边界、脏日期、倒计时文案、下一场跳过已考完、行序与折叠、key 唯一性、学期倒序、只看不及格、**字段缺失→不算**（缺学分 / 混等级制 / 学分 0 或负）、空学期不崩、工具条文案。
- `AcademicFieldsTest`：title 五行落位、线上考场、起止与时长、`fields` 全量（21 键）、`scoreValue/creditValue/failed` 派生、诊断文案。

### 5.5 不及格的判定（宁少判不误伤）

只认两种证据：**分数 < 60**，或**等级文本含「不及格」**。`合格/不合格` 制、`优秀/中等` 这类无分数课程一律按「未知」——不计入不及格、不计入均分分母。

## 6. 原始数据出口（D6）

| 入口 | 位置 | 内容 |
|---|---|---|
| 长按考试卡 | 直接打开详情浮层（原文已在同屏底部） | 主 → 次 → 原始 |
| 点击考试卡 | 详情浮层 | 同上，且首屏即「日期/时间/考场」 |
| 点击成绩行 | 成绩详情浮层 | 分数/等级 → 英文名/属性/学分/学时/课程号/课序号/考试日期/学期代码 → 原始 |
| 浮层内 `[复制]` | 原始 JSON 右上 | 复制全文（`LocalClipboardManager`） |
| 接口诊断浮层 | 工具条 `⋯` 或失败态按钮 | 请求地址 + 状态码 + 字节数 + 是否 JSON + 原文前 200 字（`ui.probe`） |

- 原始区用 `SelectionContainer` 包裹，可直接选中复制；`fields` 按「键 / 值」两列列出，**空值显示 `—` 但保留键名**（判断 schema 是否变过靠这个）。
- 浮层最高 560dp，内部滚动；`BackHandler` 与 `✕` 都能关。

## 7. 状态矩阵（失败态必须可动手，D7）

| 状态 | 触发 | 界面 |
|---|---|---|
| 加载中（首次） | `examsLoading && exams.isEmpty()` | 工具条显示「抓取中…」，列表区空但**不白屏**：显示失败态骨架文案 `考试安排没读出来` + 说明 |
| 有数据 + 刷新中 | `examsLoading && exams.isNotEmpty()` | 旧列表照常可读可点；工具条「抓取中…」 |
| 刷新失败但旧数据在 | `msg` 不以 ✅ 开头 | 工具条下 10sp `brick` 一行说明；列表不清空 |
| 未登录 | `!loggedIn` | 失败态：说明「接口在校内网 10.2.0.47，登录态只存在本次运行」+ `[重新抓取][接口诊断]` |
| 已登录但空 | `loggedIn && exams.isEmpty()` | 失败态：显示 VM 给的**真实原因**（`ui.examsMsg`）+ 同上两个动作 + 一段「诊断会做什么」的解释 |
| 筛选后为空（成绩） | `onlyFailed && shown.isEmpty()` | 「没有不及格的课」+ `[显示全部]`（43dp 文案不误导成「没有成绩」） |
| 单条缺字段 | 课名为空等 | 卡片上直接写「这条返回里没有可用的课程名与地点，点开看原始 JSON」（`brick`） |

**验收硬要求**：手机不在校园网时，两页都必须走到「失败态 + 可点诊断」，不得白屏、不得只写「暂无数据」。

## 8. 备选设计风格：两套候选与对比度实测

### 8.1 候选 A：学院纸本 / E-Ink（**已实现，可选开关**）

设计意图：纸白底、石墨黑字、细格线，**强调色收敛到一种**（褪色墨水靛）。理由：考试/成绩是长读表，需要低刺激 + 高可读，而不是农械橘的分区提示。

| 角色 | Token | 亮色值 | 暗色值 |
|---|---|---|---|
| bg | `paper` | `#F6F5F1` | `#131519` |
| surface | `card` | `#FCFBF8` | `#191C21` |
| surface-alt | `cardAlt` | `#EDEBE4` | `#23272D` |
| text | `ink` | `#17181A` | `#E9EAE6` |
| secondary | `inkSoft` | `#3B3F45` | `#C2C6C2` |
| tertiary | `inkFaint` | `#555A61` | `#9AA09C` |
| border | `rule` / `outline` | `#D9D7CF` / `#B5B3A9` | `#2C3137` / `#3F464D` |
| accent | `primary` | `#1F4A66`（墨靛） | `#7FB4D2` |
| danger | `brick` | `#A32A1B`（朱砂） | `#E39B90` |
| ok / warn | `olive` / `amber` | `#2F5D46` / `#7A5314` | `#93C0A6` / `#D9B36A` |

**对比度实测（WCAG 2.1 相对亮度公式，脚本 `contrast.py` 现算）**

| 前景 / 背景 | 亮色 | 暗色 | 门槛 | 结论 |
|---|---|---|---|---|
| `ink` / `card` | **17.17:1** | **14.13:1** | 4.5 | ✅ |
| `ink` / `paper` | 16.29:1 | 15.12:1 | 4.5 | ✅ |
| `inkSoft` / `card` | **10.23:1** | **9.88:1** | 4.5 | ✅ |
| `inkFaint` / `card`（9.5–11sp 小字） | **6.72:1** | **6.41:1** | 4.5 | ✅ |
| `inkFaint` / `paper` | 6.37:1 | 6.86:1 | 4.5 | ✅ |
| `primary` / `card`（**强调色当文字**） | **9.10:1** | **7.61:1** | 4.5 | ✅（对比硬朗农业的 4.37:1，这是本套最大的收益） |
| `brick` / `card` | 6.99:1 | 7.61:1 | 4.5 | ✅ |
| `olive` / `card` | 7.31:1 | 8.40:1 | 4.5 | ✅ |
| `amber` / `card` | 6.60:1 | 8.63:1 | 4.5 | ✅ |
| White / `primary`（主按钮实底） | 9.42:1 | 2.24:1 → **改用 `#0C1116` 作字色** | 4.5 | ✅（暗色主按钮字色已按此修正） |

### 8.2 候选 B：夜校高对比（**规格保留，未落地**）

深底近黑 + 荧光青强调，考期冲刺/夜间用。

| 角色 | 值 | 对比（对 `#141920`） |
|---|---|---|
| bg | `#0A0C10` | — |
| surface | `#141920` | — |
| text | `#F4F7F9` | 16.41:1 ✅ |
| secondary | `#BCC5CD` | 10.09:1 ✅ |
| tertiary | `#8E98A2` | 6.02:1 ✅ |
| accent | `#38E1C6` | 10.72:1 ✅（White/accent = 1.65:1 ❌ → 实底必须配深字） |
| danger / warn / ok | `#FF7A6B` / `#FFC53D` / `#6EE7A8` | 6.93 / 11.18 / 11.48 ✅ |
| border / outline | `#232B34` / `#38434E` | 1.37 / 1.75（仅作结构线，不承载信息） |

**为什么收敛到 A 而不是 B**：

1. B 的荧光青（10.72:1）对长读是**过度刺激**——它就是为「一眼锁定」设计的，而这两页 90% 的时间在读表格。
2. B 与既有「暗色模式」职责重叠：用户要夜间可用，切主题（`ThemeMode.Dark`）即可；而 A 提供的是**语汇**差异，主题切不出来。
3. B 的值被吸收进 A 的暗色档（`#131519` 底 + `#D9B36A` 警告色），保留可用部分，不引入第三套维护成本。

### 8.3 与 HardTokens 红线如何共存（关键）

| 红线 | 处理 |
|---|---|
| 圆角 0 | `HardShapes` 全局不变，风格切换**不碰 shapes**（`Theme.kt` 只切 colorScheme + `InkTokenSet`） |
| 无渐变 / 无 elevation | 两套色板都只给实色；浮层仍是 1.5dp 实边 + `hardShadow`（`hardShadow` 字段在两套 token 里都显式赋值） |
| 数字 `NumericFont` | 字族与字号阶梯**完全不动**（`EnRouteTypography`），理由见 §8.4 |
| 不引新依赖 | 只有一个新文件 `ui/theme/ScholarTokens.kt`，无新库、无新字体 |
| 业务代码零改动 | `InkTokenSet` 字段集完全一致，页面只读 `InkTokens.current`，不判风格 |

落地方式：`Prefs.styleSet`（`style_set`，默认 0）→ `AppState.styleSet` → `EnRouteTheme(themeMode, styleSet)` → 设置页「外观」下方新增「硬朗农业 / 学院纸本」两个方角开关（`SettingsScreen` 外观段）。**风格与明暗正交**（风格管语汇，主题管明暗），所以刻意不塞进 `ThemeMode`。

### 8.4 刻意不做：换成衬线中文

`NumericFont`（IBM Plex Mono）只覆盖数字与拉丁；中文衬线要靠 ROM 的 Noto Serif CJK 回退，国产 ROM 不保证有。一旦回退到黑体，「纸本」就假，而且数字会跟正文不同族 —— 违反红线 3。所以这一套**只改色、线、面**。

## 10. 性能实现约束（按 jetpack-compose-performance 审计）

1. **派生上移**：分桶/排序/倒计时/学期统计全在 `ExamRows` / `ScoreRows` 纯函数，屏幕层 `remember(ui.exams, today, stamp, collapsed)` 缓存；Composable 内无裸 `filter/sortedBy`（唯二例外：`onlyFailed` 的行内 `filter` 也只包在 `remember` 里）。
2. **时钟只读一次**：`stamp = remember(ui.exams, ui.examsLoading) { LocalDateTime.now() }`，随参数下传；**禁止**每张卡 `LocalDate.now()`（旧版隐患）。
3. **Lazy 契约**：全部 item 带 `key`（`ExamRow.rowKey` / `ScoreRow.rowKey`，均为 `String`，Bundle 可存）+ `contentType`（`exam-header` / `exam-card` / `exam-card-next` / `exam-next` / `score-term` / `score-item` / `score-note`）。下一场卡与普通卡 `contentType` 不同，回收不串味。
4. **CompositionLocal**：`InkTokens.current` 只在屏幕级读一次，行拿到 `InkTokenSet` 值参数（`@Immutable`），不在 item 内查 Local。
5. **无逐条副作用**：列表内无 `LaunchedEffect`/`DisposableEffect`/动画；浮层位移用 `Modifier.offset { }` 懒读，不触发重组。
6. **绘制**：竖轴/节点/行线/色条全部 `drawBehind`（一次绘制，无 `Canvas` 节点、无 `Box` 套 `Box`）；不用 `onGloballyPositioned`、不用 `BoxWithConstraints`。
7. **列表模型用标准 `List`**：`ui.exams` / `ui.scores` 均为 `List<T>`，Strong Skipping 下 `===` 比较；未加 `@Immutable`/`ImmutableList`。
8. **小集合不用 Lazy**：字段列表、菜单行、诊断结果都是 `forEach`（元素 ≤ 21），不套 `LazyColumn`。

## 11. 验收清单

**结构（考试）**
- [ ] 页内不出现「考试」标题字样；工具条左侧是 `N 场 · 下一场 MM-DD · X 天后`。

- [ ] 分组顺序：今天 → 本周 → 更远 → 已结束；已结束默认折叠，组内倒序（最近考完在前）。
- [ ] 周五查看时，周日场次在「本周」，下周一场次在「更远」。
- [ ] 时间轴：竖轴 1dp 贯穿、节点 7dp 方角、下一场实心主色、其余空心。
- [ ] 长按卡片 → 浮层直接看到完整 JSON 与全部 key；`[复制]` 可用。

**结构（成绩）**
- [ ] 学期倒序，同学年内春季在秋季之上；组头显示 `N 门 · X 学分`。
- [ ] 混入等级制课程时组头写「含等级制课程，不计算均分」，**不出现任何数字**。
- [ ] 缺学分时组头不显示学分段；加权均分不显示。
- [ ] 「只看不及格」只剩分数 < 60 或等级不及格的行；筛空时给 `[显示全部]`。
- [ ] 页面任何位置都不出现「绩点 / GPA / 排名」。

**失败态（本轮验收硬项）**
- [ ] 手机不在校园网：两页都显示 `…没读出来` + 真实原因 + `[重新抓取][接口诊断]`，**不白屏**。
- [ ] `[接口诊断]` 能就地跑出状态码 / 字节数 / 是否 JSON / 原文前 200 字。
- [ ] 有旧数据时刷新失败：列表仍可滚动可点，只多一行 `brick` 说明。

**红线**
- [ ] 全页 0 圆角；无渐变、无 elevation、无 shimmer。
- [ ] 所有数字 `NumericFont`；间距 ∈ `Space` 档位；主色文字 ≥14sp/700。
