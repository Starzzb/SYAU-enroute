# 16: 「我的」页重构（去平铺 + 修掉评审发现的真缺陷）

**What to build:** 「我的」页不再把十来个入口平铺在一张卡里；分成「现在 / 学业 / 工具 / 本机状态」四层，
高频信息一屏可见。同时修掉三位设计评审在代码里查出的**真实缺陷**（见 §A，与选哪套方案无关）。

**Blocked by:** 无

**Status:** needs-triage（**等主人拍板选哪套布局**；§A 的缺陷修复可立即开工）

---

## 专家评审结论（2026-11-14，三方一致）

三位（UI Designer / UI Finish-Gate / Persona Walkthrough）独立评审，结论收敛到同一处：

> 不是入口太多，是**每件事都有三个入口**，而每天要用的那件事在 1.57 屏下方、和「设置」同高同权。

### 现状量化（按实际渲染顺序加总，可视 696dp）

| 目标 | scrollY | 折合 |
|---|---|---|
| 下一场考试 / 学分 / 成绩 | 226 / 338 / 462dp | 首屏 ✅ |
| 「教务」组标题 | 883dp | 1.27 屏 |
| **空闲教室（第 8 行）** | **1095dp** | **1.57 屏** |
| 设置（末行） | 1179dp | 1.69 屏 |

**六处重复**：登录态 ×3、设置 ×2、考试/成绩/培养方案各 ×2（卡片 + NavRow）。

### 三位共同给出的分组原则（可判定）

1. **数据即入口**：数字已在屏上，那张卡就是唯一入口，下面不许再列同名项
2. **唯一真相**：别处已有权威显示的状态，本页删
3. **时间优先**：会自己变的（倒计时）必须第一层
4. **日频提权**：一周 ≥3 次可直升第一层（唯一例外：空闲教室）
5. **危险隔离**：会丢数据的（清除数据/凭据/调试）一律进设置页
6. **诊断折叠**：只在出问题时看的，默认收起

分组必须锚定**数据来源 / 可用性前提**，而不是「常用/工具/其他」这类功能感受词
（后者是可替换性最高的一招，也是评审黑名单第 5 条）。

## A. 必须修的缺陷（与布局方案无关，立即开工）

评审在代码里查出的**真 bug**，不是审美问题：

| # | 缺陷 | 位置 | 性质 |
|---|---|---|---|
| A1 | **「培养方案进度」卡点进去是成绩查询** | `UserScreen.kt:262-266` `onOpen = onOpenScore` | **预期落空**：想查「还差多少学分」被送到只回答「考了多少分」的页面 |
| A2 | **课表为空时显示「0 门课」** | 本机数据组 `StatRow("课表", "${...} 门课")` | **违反 AGENTS 第 1 条**「绝不填 0」；同组「周次」行写法是对的（显示「未校准…」），属漏改 |
| A3 | **可点行高约 40dp < 48dp** | `NavRow`（12dp×2 padding + 13sp） | 触控不达标；仓库其它页都用 `heightIn(min = Space.minTouch)` |
| A4 | **箭头方向反了** | `NavRow` 用 `KeyboardArrowLeft` | 右端「进入」暗示应为右向 |
| A5 | **`Divider()` 用 0.6dp** | `UserScreen.kt` 页内 `Divider` | 低于 `HardTokens` 记录的 0.75–1dp 下限（收敛到 `Stroke.hairline` 或写明理由） |
| A6 | **子页栈切 tab 后重置** | `remember { mutableStateListOf(Root) }` | 从「空闲教室」切走再回来，回到页首、丢失阅读位置 |
| A7 | **登录行条件插入导致整列位移** | `UserScreen.kt:303-306` | 续期成功那一刻登录行消失，下方九行全部上移一格 → 误点 |
| A8 | 徽标语义混乱（说明文字/常量/搜索计数混在同一列） | `NavRow` 第二参数 | 「相对位置」「土地资源管理」「N 位」都不是状态；**留空比放噪声更诚实** |

**A 段验收**：`培养方案进度` 点进培养方案页；无课表时显示 `—` 或「未同步」；行高 ≥48dp；
箭头向右；栈用 `rememberSaveable`；徽标列里只允许「真实状态」或空。

## B. 布局方案（**待主人选**）

### 方案一：三段式 + 工具抽屉（保守，≈1 人日）
首屏 613dp 一屏装完：身份卡压缩 → 「现在」区（考试倒计时 90dp + 空闲教室 52dp）→
「学业」区（学分卡 108dp + 成绩行 52dp）→ 工具抽屉（默认收起，展开 4×44）。
全页 849dp（1.22 屏）。

### 方案二：学业磁贴 2 列 + 工具格（**三专家推荐**，≈2.5 人日）
首屏 496dp 内含**五个核心数字**（考试倒计时 / 学分进度 / 绩点 / 空闲教室 / 通过门数）：
```
┌──────────────────────────────┐  下一场考试（span2，倒计时 26sp 等宽）
├───────────────┬──────────────┤  培养方案 64% │ 加权绩点 3.42（两个 1×1）
├───────────────┴──────────────┤  空闲教室 · 第5节·47间（span2）
│ 工具 ┌────────┬────────┐     │  地图/查教师/大纲/历年（2×2，76dp 每格）
│ 本机状态 课表0门·第12周    ▸  │  折叠
└──────────────────────────────┘  全页 814dp（1.17 屏）
```
- 只借 v3 方向 A 的**布局轴**（2 列 span），**拒绝材质轴**：仍 0 圆角 + 1dp 描边 + 无阴影 + 等宽数字
- 磁贴**不做 4 色分区**（6 格 4 色会把纸墨风变成看板）
- 层级靠「磁贴尺寸 + 数字字号 + 描边轻重」，不新增 token

### 方案三：手风琴（极简上限，≈1.5 人日）
四组互斥展开，全页 570dp 一屏不滚。**缺点**：把最高频的「现在」也做成可收的，等于给高频动作加一道门
（收起时变 2 击）。仅当主人认定「我的 = 账户页」时选它，且必须同时给课表页补三个入口。

### 裁决依据

| 若… | 选 |
|---|---|
| 希望在「我的」里一眼看到全部核心数字 | **方案二** |
| 一周内要真机验证 | 方案一（分层规则可原样迁移到二） |
| 认定「我的」是账户页、功能都在别处 | 方案三（需同步给课表页补入口） |
| 要与 v3 方向 A 完全一致 | 直接照 v3 §4，但那会破 `HardTokens` 红线，需书面确认 |

**三套共通**：折叠头 48–56dp、`animateDpAsState(180ms)`、箭头 120ms 旋转、`rememberSaveable`；
**不新增长按**（全 App 只有课表卡片有长按，这页加长按＝隐藏功能）；
「数据诚实」在折叠摘要里同样生效（未知 → `—`，不准把三种空压成一个符号）。
