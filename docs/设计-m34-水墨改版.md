## 2. 五个组件（实际落地参数）

**底部导航（`InkNavBar.kt`）**：整条贴底，`topStart/topEnd = 16dp` 上圆角、顶边 1dp `outline` 弧线，底边吃 `navigationBars` 安全区。三格 `weight(1f)` 等距，各 50dp 高、8dp 圆角；当前项浅底（`cardAlt`）+ 墨色图标 + 下方 3dp 朱点，未选中项留同尺寸空位防跳动；未读徽标用 `primary`。三个位：今日 / 资讯 / 我的。

**个人信息卡（`UserIdentityCard.kt`，向下摊开）**：14dp 圆角、`inkPress` 压印质感（见 §2.1）、**右上角狗耳折角**。收起态露 46dp 墨圈头像（姓名首字）+ 姓名 + 右对齐学号 + 专业年级，下一行三格读数（加权绩点 / 已修学分 / 排名，缺数据如实写「暂缺」）。点击**向下撑开**：卡高由 `animateContentSize(520ms, CubicBezierEasing(.22,.9,.24,1))` 增长，明细延迟 150ms 起、300ms 淡入并从 +10dp 上移归位；顶部一道 1dp `rule` 折痕，下面四条账目行（点线行底 + 右侧 `›`），第四条是培养方案入口。折角在展开时 180ms 淡出、收起后延迟 260ms 淡回，并有 4.18s 一次的 1.5dp 呼吸与按压抬起 —— 这是唯一的「能摊开」线索，界面里不写说明。没有 3D 翻页：摊开一张纸是抽出来，不是翻过去。

**2.1 压印阴影怎么在 Compose 里做（`ui/kit/InkPress.kt`）**：参考件那条 CSS `box-shadow: inset 0 18px 16px …, inset 0 -18px 16px …, 1px 1px 2px …, -1px -1px 2px …` 拆开是四件事 —— 上缘一道向内的暗带（凹槽吃光）、下缘一道向内的亮带（唇口受光）、左上亮边 / 右下暗边的一像素立体外沿、由上到下极浅的底色渐变。Compose 的 `shadow()` 只能画在**外侧**，没有 inset box-shadow，所以逐层画在**一次** `drawBehind` 里，顺序完全可控，也不用 blur：
1. `drawRect(Brush.verticalGradient(paperTop → paperBottom))` —— 底色渐变，对齐 CSS 的 `linear-gradient(180deg, …)`；
2. `drawRect(verticalGradient(shade → 透明))` —— 上带，长度 `depth + feather` = 18 + 16dp；
3. `drawRect(verticalGradient(透明 → sheen))` —— 下带，同长度；
4. `drawRoundRect(brush = linearGradient(edgeLight → edgeDark), style = Stroke(1dp))` —— 外沿描一圈，内缩半像素避免被裁掉一半。

整块先 `clip(RoundedCornerShape(radius))`，两条内带自然沿圆角收口，不会露方角。亮档 `shade = #2C2C2C @5.5%`、`sheen = 白 @85%`；暗档换成 `黑 @50%` 与 `白 @4.5%`，外沿同理反过来 —— **亮档的白绝不能带进暗档**，否则深纸会被洗成灰白（原型第一版就踩过）。卡片很矮时（行内小卡、翻卡定格帧）带子比例收到全高 50% 上限，免得两条带压成一块灰。成本：4 次 draw，无离屏渲染、无 blur，滚动时与普通背景同价。

**加载（`InkLoader.kt`）**：Canvas 画五片纸，各以左边缘为轴 `rotateY 0 → -180deg`，片宽按 `|cos θ|` 收缩模拟透视、翻过 90° 镜像到轴左侧；相位差 150ms、周期 2s，颜色依次 ink / inkSoft / slate / olive / amber。三档 `InkTinyLoader` 16dp（资讯「正在抓取 / 正在读取正文」、大纲「正在读大纲」、登录中）、`InkLoader` 30dp（默认）、`InkBigLoader` 44dp（整页）。

**登录卡（`LoginCard.kt`）**：`InkLoginField` 用 `BasicTextField` 画左 + 下两条 1.5dp 墨线、左下 8dp 圆角连接；标签平时落在行内，聚焦或有值时上浮到左上角、缩到 10sp、变墨底纸字（180ms）。`InkOutlineButton` 平时 1.5dp 墨框墨字，悬停 / 按下反白（墨底纸字）。登录中指示器由旧 `CircularProgressIndicator` 换成 16dp 墨洗 loader。

**主题收敛（`Theme.kt` + 设置页）**：`InkTokenSet.Light/Dark` 换成 ink-wash 色值（见 §3），明暗两套；设置页「主题风格」切换块已移除，只留明暗与取色。`StyleSet` 常量与 `normalize` 语义按单测锁定保留，只是不再有 UI 入口——这是为了不破坏 `ThemeDynamicTest` 与取色管线，视觉上只呈现 INK 一套。

## 5. 验收口径

1. 两种明暗下，五个组件与参考件的形态特征对得上：贴底圆角托、右上折角压印卡、五片翻页、左下墨线。
2. 身份卡点击后高度平滑撑开、明细延迟淡入无跳变；再点收起回到原高度，列表不留空条；暗档卡片不得发白。
3. 移除主题切换后，设置里找不到入口；`StyleSet`/`styleSet` 仅作为测试与取色管线的内部实现保留，不再暴露给用户。
4. ink-wash 配色下正文对比度 ≥4.5:1、线 ≥3.0（见 §3 实测）。
5. 全局单测全绿（已验证），新组件都是绘制层，无新增依赖。
