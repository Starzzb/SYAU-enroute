## 三、关键实测结论

1. **7 个源全部可达（均 200），没有反爬**。空 UA、伪造外站 Referer、不带 Cookie 全部照常 200，没有 403/412/跳登录。
2. **正文形态分布**：6 个源以 A 为主；**xsc 是唯一 D 类（整篇 PDF）**；B 类插图只出现在 jwc / news / tw，且**没有一家用 `data-src` 懒加载**（`data-src`、`data-original`、`class` 含 lazy 的计数在 56 个页面里全为 0），全是写死 `src="/__local/..."`。
3. **正文嵌图 100% 走 VSB 的 `/__local/` 绝对路径**（以 `/` 开头，不是相对路径），直接拼主机名即可取；无 `/__local/` 的 `<img>` 全是模板 logo/角标，属于垃圾节点。
4. **附件全部是 `/system/_content/download.jsp?...`，而且挂图形验证码**（实测返回 3805 B HTML，内含 `createimage.jsp` 与 `codeValue` 提交逻辑）。**没有一条附件是可直链下载的 PDF/ZIP**——不存在 `/__local/xxx.pdf` 形式的附件。加 `codeValue=1234` 也是同一张验证码页。
5. **例外：xsc 的 PDF 是正文本身，走 `/__local/*.pdf?e=.pdf` 直链，无需 Referer/Cookie**，`Content-Type: application/pdf`，`Accept-Ranges: bytes`，可断点续传（也就可以做分段预取）。
6. **未发现「整篇只有一张扫描图」的公告**：56 篇样本里，正文文字 <40 字且含图片的页面数 = 0。图片型正文（E 类）在这 7 个源上不存在。
7. **未发现 F 类（需 JS 渲染）**：所有正文都在服务端渲染好的 HTML 里，`document.write` 之类只用于点击数/轮播。
8. **编码**：全部 UTF-8；jwc/www/xsc/news/job/cxcy 六个源**带 UTF-8 BOM**（`EF BB BF`），tw 不带。按 GB18030 解全部失败，所以不必猜编码，但要**先剥 BOM 再解析**，否则 `<html>` 前面的 `\ufeff` 会让部分解析器把首个标签当文本。

## 六、对 App 渲染的直接影响

1. **xsc 必须内置 PDF 渲染通道**。它的正文是 `<iframe>` 指向的 PDF，抽文本只能拿到 115 字的「请安装 PDF 阅读器」垃圾文案。要么上 `PdfRenderer`/系统 PDF 组件，要么只显示「本公告为 PDF，共 N 页」+ 直链外跳。直链不需要 Referer/Cookie，可以安全地交给下载器——**这也是 7 个源里唯一一条能真正直接下载的文件**。
2. **必须能剥 BOM。** 6/7 的源带 UTF-8 BOM，直接 `OkHttp.body.string()` 再喂 Jsoup 通常没事，但自定义正则/手写解析会吃到 `\ufeff`。解析前统一 `trimStart('\uFEFF')` 最省事。
3. **正文容器 id 有一处不一致**：cxcy 用 `#vsb_content_4`，其余 6 个用 `#vsb_content`。选择器要写成 `div[id^=vsb_content] > .v_news_content`，别写死 `#vsb_content`，否则 cxcy 会整页空白。
4. **图片可直接加载，但要过滤模板垃圾图**：只保留 `src` 以 `/__local/` 开头的 `<img>`，其余（`../../images/logo.png`、`images/conac2025.png`、`snjybq.png`、`ewm.jpg`）全是模板 logo/二维码/角标。news 的图还带 `orisrc`——**同一条新闻有 1024×682 与 2976×1984 两个版本，差 33 倍体积**，列表/正文用 `src`，点开大图再用 `orisrc`，别默认拉原图。
5. **附件链接触发验证码，必须做「提示 + 外跳浏览器」而不是 App 内下载**。7 个源里 www/jwc/xsc/job/tw 的附件都是 `download.jsp`，实测返回 3805 B 验证码页。App 内直接下会拿到一张 HTML，用户会以为下载坏了。正确做法：识别到 `download.jsp` 就显示「附件在浏览器中打开」，交系统浏览器处理人工验证码。
6. **日期解析要准备 4 种格式 + 1 种拆装**：`2026-11-19`（jwc/www/xsc/job/cxcy）、`2026/11/18`（news，斜杠）、`2026年11月17日 08:42`（tw 详情）、`<b>17</b><span>2026-11</span>`（tw 列表，日与年月分居两个节点，必须拼）。tw 这一条最容易漏，漏了就是全列表没日期。
7. **分页别用 `/2.htm`**。要跟 `下页` 的 href，或者按 `(总页数-1).htm` 倒推。cxcy 的内容最新只到 2025-12-17，如果 UI 要显示「最近更新」，这个源会长期空窗，得允许列表为空/很旧而不报错。
