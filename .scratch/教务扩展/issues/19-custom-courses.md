# 19: 自定义课程（手动添加 + 备注 + 按周次/单日排课）

**What to build:** 用户能自己往课表里加课，卡片外观**复用现有课程卡**，可写备注；
排课规则支持两种：**按周次区间**（第 N–M 周，可含单双周）与**固定某一天**（指定日期的一次性课程）。

**Blocked by:** 无

**Status:** ready-for-agent

## 数据模型

```kotlin
/** 一条自定义课程的排课规则。一条课程可有**多条**规则（例如前八周周二、后八周周四）。 */
sealed interface CustomRule {
    /** 按周次：第 [fromWeek]–[toWeek] 周，[parity] 控制全/单/双 */
    data class Weekly(
        val fromWeek: Int,
        val toWeek: Int,
        val parity: Parity = Parity.ALL,   // ALL / ODD / EVEN
        val weekday: Int,                  // 1..7（周一=1）
        val bigIndex: Int,                 // 第几大节（1..6，对应 1-2/3-4/…/11-12）
    ) : CustomRule

    /** 固定某一天：具体日期的一次性课 */
    data class SingleDay(
        val date: LocalDate,               // 2026-11-20
        val bigIndex: Int,
    ) : CustomRule
}

data class CustomCourse(
    val id: String,                        // 稳定 id（uuid），编辑/删除靠它
    val name: String,                      // 必填
    val room: String = "",                 // 可空
    val teacher: String = "",              // 可空
    val note: String = "",                 // 备注（主人点名要）
    val colorKey: String = "",             // 科目配色键；留空则按名称哈希取色（与现有 famOf 一致）
    val termCode: String,                  // 属于哪个学期（与课表同一口径）
    val rules: List<CustomRule>,
)
```

存本机（`filesDir/custom_courses.json` 或 Prefs），**不上传、不进地图补丁、不与教务数据混写**。

## 硬规矩（不可破）

1. **必须可区分**：自定义条目在网格里要有**看得见的标记**（角标/细杠/「自」字，选一种，别太吵），
   否则用户分不清「学校排的课」和「自己加的课」—— 这跟数据诚实是同一条原则。
2. **重拉课表不清自定义**：`fetchSchedule` 成功覆盖教务数据时，自定义条目**必须保留**。
3. **冲突不静默**：同一格同时有教务课与自定义课 → 两门都要可见（并排或叠加角标 + 点开能看全），
   **绝不允许自定义覆盖教务、也不允许教务覆盖自定义**。
4. **备注不许被截断丢掉**：详情/长按里必须能看到完整备注。
5. 学期切换：`Weekly` 规则按周次过滤、`SingleDay` 按日期归到对应周次，**不属当期就不显示**。

## 添加页设计（主人点名要「清晰易懂」）

设计归你（代理），但有这几条硬要求：

- **先选规则类型**：进页面先问「按周次」还是「固定某一天」，两条路分开，不要混在一屏塞满表单
- **必填只有课程名**：其余都可以留空，不要一上来逼用户填教师/地点
- **规则必须给一句人话预览**，随填随变：
  - 按周次 →「**第 3–16 周 · 每周二 · 第 3-4 节**」（单/双周要写「每周（单周）」）
  - 单日 →「**2026-11-20（周五）· 第 5-6 节**」
- **周次选择给快捷档**：常用区间一键填（第 1–16 周 / 第 1–8 周 / 第 9–16 周），仍可手改
- **冲突即时提示**：选中的格子里已有课 → 当场提示「该时段已有《XX》，两门都会显示」
- **支持多条规则**：允许给同一门课再加一条规则（同页面「＋再加一个时间」）
- 编辑 / 删除入口复用现有长按菜单，不新增隐藏手势
