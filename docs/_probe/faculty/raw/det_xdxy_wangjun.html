    王俊

    【来源：     日期：2026/08/03 17:11:57浏览量：  】【打印本页】 【关闭】

    个人简介：

    王俊，男，1979年5月生，黑龙江省龙江县人，中共党员，2002年、2007年本科、硕士毕业于沈阳农业大学农业电气化与自动化专业，2013年博士毕业于哈尔滨工业大学电力系统及其自动化专业，教授，博士研究生导师，入选辽宁省“兴辽英才”计划。现任沈阳农业大学信息与电气工程学院院长，兼任中国农业工程学会理事、中国农业工程学会农业信息与电气工程专委会副主任委员、IEEE PES可再生能源系统集成技术委员会（中国）可再生能源建模技术分技术委员会常务理事，《农业工程学报》期刊编委会委员。

    研究方向：

    智能配电网、可再生能源电力并网运行与控制

    联系方式：

    信息与电气工程学院323室，Email：wddream2016@syau.edu.cn，电话：024-88487123

    主讲课程：

    1.《电力系统稳态分析》（本科课程，省线下一流课程，校精品课）

    2.《架空线路设计原理》（本科课程）

    3.《电力系统仿真与建模》（研究生课程）

    教学项目：

    1. 农业工程与信息技术领域农业硕士教育质量保障体系建设研究(2019-NYYB-41), 全国农业教指委2019年立项研究课题，主持。

    2. 农业电气化转型发展示范性专业建设研究与实践（2018-356），辽宁省普通高等教育本科教学改革研究项目，主持。

    3. 校企协同育人的工程硕士专业学位研究生实践能力培养体系研究（2020-yjs-30），校级教改课题，主持；

    4. 农业电气化专业复合应用型卓越农林人才培养方案的研究与应用（2018-32），校级教改课题，主持；

    5. 电气工程领域专业学位研究生教育质量保障体系建设研究（2018-yjs-23），校级教改课题，主持；
