# 10: 课程大纲（进课表课程详情 + 可搜索筛选）

**What to build:** 两处入口共用同一份数据：
1. **课表里点某门课 → 详情里能展开「课程大纲」**（基本信息、课程简介、教学目标、课程目标、
   教学内容与学时分配、教学基本要求、相关课程、参考资料）
2. **独立的大纲页**：可按课程名/课程代码搜索，按课程类型（理论/实验/实践）筛选

**Blocked by:** 09（共用 assets 与索引加载层；若 09 未完成，本票可先做数据层与页面，最后接入口）

**Status:** ready-for-human

## 已就绪的资产

| 文件 | 内容 |
|---|---|
| `syllabus_index.json` | `[{id,code,name,type,credit,hours,bytes}]`，**166 门**（土环学院 2021 版） |
| `syllabus_<id>.json` | 单门大纲：`课程名称/英文名称/课程类型/课程代码/课程学分/理论学时/实验学时/课程类别/开课教研室/执笔人/制定时间/基本信息/章节/教学章节/教学内容学时一览表/课程目标列表` |
| `META.json` | 诚实规则（含「只覆盖土环 167 门，通识课不在册」） |

`章节` 是按原文小节分的对象，键形如：
`一、课程基本信息`、`二、课程简介`、`三、教学目标`、`四、课程目标`、
`五、课程目标与毕业要求支撑关系`、`六、教学内容、教学目标及学时分配`、
`七、课程教学的基本要求`、`八、与本课程的相关课程`、`九、教学参考资料说明`。

## 覆盖率实测（2026-11-14，务必按此设计空态）

学生本学期 7 门课：**4 门有大纲**（不动产估价 / 国土空间规划 / 地球表层系统概论 / 土地信息管理），
**3 门通识课没有**（形势与政策Ⅴ / 社会主义发展史 / 创业基础Ⅱ）。
→ 没有大纲是**正常现象**，文案要说「这本院级大纲册子（土环学院 2021 版，167 门）里没有这门课，
通识课/外院课通常不在其中」，**不许显示空卡片或"加载中"转圈**。

## 匹配策略（课表课程 → 大纲）

- 课表侧给的是 `课程名` 与 `课程号`（`kch`）。**优先按课程代码精确匹配**，
  再退化为课程名精确匹配，最后才是名称包含匹配；命中多条时列出候选让人选，**不要猜**
- 课程名有罗马数字/全半角差异（`Ⅴ` vs `V`），匹配前要归一（`课程总索引` 的 `归一名称` 就是干这个的，
  但资产里没带，实现时自己写一个 `normalizeCourseName`）

## 交互

- 课表课程详情（`CourseDetail.kt` 那个浮层/页）：加一段「课程大纲」入口，
  有大纲才显示入口；点开进大纲页
- 大纲页：顶部课程名 + 课程代码 + 学分/学时；下面按 `章节` 顺序渲染小节标题 + 正文（可折叠）
- 搜索页：输入框 + 类型筛选 chip；列表行显示 课程名 · 代码 · 学分/学时 · 类型
- 全文里若有 `教学章节`/`教学内容学时一览表`，用小表格渲染

**几个数据上的坑（都写进测试了）**

1. **章节标题不是文档写的那套**：实测是「三、教学目的」「八、本课程的先修课程」「九、教学大纲修订说明」，
   而票里写的是「教学目标 / 与本课程的相关课程 / 教学参考资料说明」。所以渲染**完全按 JSON 的 `章节`
   顺序与原文标题**，一个字都不写死。
2. **空正文小节要保留**：「八、本课程的先修课程」正文只有几个字，删掉会让人以为没有这一节；
   保留并显示「原文这一节为空」。
3. **学时合计不能瞎加**：「教学内容学时一览表」最后一行是「课程思政内容」，三列学时全空。
   `Syllabus.hoursTotal` 只要有空行就返回 null，界面写「原表有空白学时行，故不显示合计」；
   只有当每行都有数时才给合计（有单测锁两个方向）。
4. **索引 166 门**（META 的措辞是 167、票里两处也各写了一个数）—— 实现以 `syllabus_index.json` 实际条数为准，
   界面上显示的是索引真实条数，不写死。
