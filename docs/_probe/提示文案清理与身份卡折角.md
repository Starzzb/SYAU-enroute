## 三、身份卡折角参数（`UserIdentityCard.kt` / `DogEarFold`）

- 位置：卡片右上角，26dp × 26dp 正方形，右上直角三角为折角正面，对角线为折痕（右下 45°）。
- 折叠方向：沿对角线向卡内平移，位移分量 `dx = -lift × 0.7071`、`dy = +lift × 0.7071`。
- 折角正面：比纸色略亮（`t.card`）；折痕线：1dp `t.inkFaint`，固定于原始对角线。
- 下沿投影：黑 6%、2.5dp 宽、`StrokeCap.Round`，再往左下偏 1.5dp。
- 呼吸：4.5s 一周期（`delay(4180)` + 160ms 抬 1.5dp + 160ms 落，`FastOutSlowInEasing`）；
  系统「动画时长」设为 0 时静止。
- 按压：折角抬到 2.5dp（`tween(140)`），整卡 `scale` 0.992（140ms 回落）。
- 展开态：折角消失、角落恢复平整 —— 这是「已展开」的唯一信号；卡内左右对开
  （左 0.42 身份 / 右 0.58 成绩 2×2），中间 1dp 竖直折痕（`inkFaint` 35%，上下留 6dp），
  过渡 180ms（`AnimatedContent` 淡入淡出 + `SizeTransform`）。
- 未登录 / 过期：整卡为登录门禁（「未登录」/「会话已过期」+「登录教务」/「续期登录」描边按钮），
  不画折角、不展开。
