## 2. 深色模式下所有卡片的体检

### 改了什么（都是真值）

| token | 改前 | 改后 | 为什么 |
|---|---|---|---|
| `card`（暗） | `#1F1C17` | `#272219` | 对 `paper #191713` 只差 3 级亮度，卡片边界看不见 |
| `cardAlt`（暗） | `#2B2721` | `#322C24` | 与 card 挤在一起，两级层次分不开 |
| `outline`（暗） | `#8C8474` | `#9A9282` | 对 card 约 2.6:1，低于 3:1 门槛 |

### 纸纹在深色下等于没有（真 bug）

`PaperTexture.texInk` 原来写 `alpha * 0.72f` —— 深色下**把纹理压得更淡**。深底是 `#191713`、
纹理用 `ink #EDE7DA`，乘 0.72 之后基本不可见。改成 `× 1.35`（封顶 0.22）。

`drawEdge` 的暗档原来用 `Color.Black` 压边 —— 黑底黑边等于没有边，而且配的是 0.55/0.42/0.34 这组
「用黑压边」时代的强度。改成同一个 `ink` 色低强度提亮（0.075/0.055/0.040），上沿一条亮边。

### 课程卡的 washDark 与 spineDark

| 款 | washDark（改后） | spineDark（改后） |
|---|---|---|
| 1 | `#2A1D18` | `#C4776A` |
| 2 | `#1B2226` | `#7E9AA5` |
| 3 | `#20241A` | `#93A57E` |
| 4 | `#262019` | `#B4956A` |

旧值 `#3A2620 / #232C31 / #2A2E20 / #322A1B` 亮度跨 18–20% 但色相跳得远，暗处人眼先读亮度、
后读色相，于是看成四块补丁。新值亮度跨度 1.14 倍 —— **同亮度、不同色相**。

spine 原来在暗档直接取亮档 `wash`（近白），2.5dp 白条在黑底上发光、比课名还亮。
新增 `Fam.spineDark` 字段，取同色系提亮到 65–70%。

### 侵蚀之后课名照常读

机制没改（2026-11-17 已定）：侵蚀层只画在 `drawContent()` **之前**，正文最后画、整块、永不裁切。
这一轮只把 `ErodedCard` 里三个硬编码色（`#17150F / #3A362E / #211E18`）改成从 token 派生
（`blend(t.paper, t.cardAlt, 0.62f)` 与 `blend(t.paper, t.inkFaint, 0.10f)`），换主题不再露馅；
卡片描边在暗档从 0.30 提到 0.55。

## 4. 资讯正文形态：三路实测后的适配

三个子代理把 21 个源的正文形态全部实测（证据在 `docs/_probe/feed-render/`），据此改了五处：

| 改动 | 依据 |
|---|---|
| `BodyPayload` 新增 `images` / `pdfUrl` / `attachmentsBlocked` | 56 个校内详情页：正文图全在 `/__local/`；学生处正文是 iframe 指向的 PDF；附件全挂图形验证码 |
| 正文容器认 `vsb_content` **前缀** | 校内竞赛 cxcy 是 `vsb_content_4`，写死会让它整页空白 |

| 新增 `FeedImages`（正文图缓存，上限 3 MB × 8 张） | 沈农新闻原图 2.4 MB、挑战杯一条 13 张 2.16 MB；校内图出校门拉不到 |
| 新增 `FeedParser.decodeJyBody`（base64→zlib→base64） | 就业信息网正文全在脚本变量里，WebView 还得跑站点自己的 base64.min.js |

界面侧：`FeedImageList`（`FillWidth` 等比铺满，长截图不设高度上限）、`FeedPdfCard`（如实说"这是 PDF"）、
附件行在有验证码时改叫「浏览器打开」而不是「下载」。

## 7. 本轮踩过的坑（写在代码注释里了）

1. `BorderStroke(dp, color, pathEffect)` 这个重载在 Compose 1.x **不存在**，只有 `(Dp, Brush)` 与 `(Dp, Color)`；虚线要自己 `drawBehind` 画。
2. Kotlin 反引号函数名里**不能有 `.`** —— `附件走 download.jsp 时…` 会让编译报 `Name contains illegal characters: ..`。
3. 二进制→字符串必须显式 `Charsets.ISO_8859_1`：默认 UTF-8 会把非法字节替换成 `U+FFFD`，再转回字节永远 inflate 失败。
4. `Deflater` 循环里 `deflate()` 返回 0 不等于结束，要判 `d.finished()`（写成 `if (n <= 0) break` 会截断输出）。
