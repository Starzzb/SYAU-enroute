状态机

Idle └ 点「更新」/ 静默检查后点「更新」 ↓ startDownload(info) Downloading(done,total) ← 进度回调 ├─ 成功 + sha256 过 → Ready(apk) ├─ 失败 → Failed(reason) └─ 取消（无入口） Ready ─ 点「安装」→ 权限 → 系统安装器 Failed ─「重试」→ Downloading └「稍后」→ Idle
  • 状态与协程都挂在 UpdateCenter（Application scope），UI 重建、切 tab、转屏都不丢。
  • 下载中不给「取消」：按钮只有一个「正在下载」，没有出口，只能等或等它失败。
  • 失败才有出口 —— 阻塞不能变成卡死。

失败判定（确定规则）

条件判定
连接 15 秒未建立连不上 · 服务器无响应
连上后 20 秒零字节没有数据 · 首包未到
连续 30 秒平均 < 10 KB/s速度过低 · 网络在动但传不动
总耗时 > 15 分钟未完成超时 · 中断重试
收到字节数 ≠ Content-Length不完整 · 少 n 字节
sha256 与 manifest 不符校验失败 · 文件已丢弃
HTTP 4xx / 5xx 且镜像全挂源不可用 · 五个候选都试过
  • 低速与零字节两条都用「滑动窗口」判：每 5 秒采一次，累计 30 秒不足 300 KB 即判死。
  • 失败一律保留 .part 与已下字节数，重试从断点续传（服务端支持 Range 时）。

已拍板的三个决策

  • 阻塞强度：轻量档 —— UI 全屏阻塞 + Application scope 托管。不加前台服务。
  • 失败态：放行返回键，给「重试 / 稍后」两个出口。
  • 静默检查：发现新版本仍然只做提醒（弹窗 / 设置页角标），点「更新」之后才进阻塞下载。

真机验收

  • 下载中按返回 → 无反应；点遮罩 → 无反应；切 tab → 被盖住
  • 下载中转屏 → 百分比继续走，不回到 0
  • 断网 30 秒 → 落到失败态，「稍后」能退出
  • 完成点「安装」 → 无权限跳系统设置，回来自动拉安装器
