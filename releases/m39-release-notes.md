把 m34 拔掉入口后仍在编进包里的那两套课表主体接回界面，并修掉深色下卡片看不清的问题。

## 课表卡片可以换版式了

设置 →「课程表卡片」新页。版式可选 **纸卡 / 账页**；另有底色（四色 / 单墨 / 无色）、左侧竖脊、上课进度侵蚀、小幽灵、食物图标、当前课描边六项独立开关。

「账页」那套（`LedgerCourseCell` / `LedgerAxisRow` / `LedgerBand` / `LedgerWeekStamp` / `LedgerUnscheduledRow`，326 行）从 m34 起一直编在包里跑，只是没有入口——课表卡片照常加载，所以看着像「设计还在、入口消失」。现在能切过去了。

所有开关的**默认值都等于改造前的行为**，升级后不点设置的话，看到的一个像素都不变。

## 深色下所有卡片重新体检

不只看课程卡，是把深色下会出现卡片的形态逐个过了一遍。改了三处真问题：

- **卡片与页面底分不开**：`card #1F1C17` 对 `paper #191713` 只差 3 级亮度，暗处看不见边界。提到 `#272219`，描边 `#8C8474 → #9A9282`（对卡片 5.12:1）。
- **纸纹在深色下等于没有**：`texInk` 暗档写的是 `alpha × 0.72`——把纹理压得更淡。深底上那样乘等于消失。改成 `× 1.35`（封顶 0.22）。
- **边缘深度卡的黑边**：原来用纯黑压边，黑底黑边等于没有边。改成同色低强度提亮 + 上沿一线亮边。

课程卡四款底色也重做了：`washDark` 压到亮度跨度 1.14 倍（同亮度、不同色相），不再像四块补丁；竖脊从「近白」改成同色系提亮 65–70%，不再抢课名。

侵蚀机制不变——侵蚀层画在正文之前，**课名永远在最上层**，下课之后卡片是旧纸色而不是空白，照样点得开。

## 课程大纲筛布重做

三层筛：搜索框 → 类型 chip 带数量 → 学院横滑**多选**（空集 = 全部，另有「全部」chip 一键清空）。按钮形态分三种不靠文字解释：实心 = 选中、细边框 = 可点、虚线 = 布尔开关（有学分 / 有页码）。

列表行补上课程类型与 **PDF 页码**（`pdf页码范围` 一直在资产里躺着没上屏）。索引构建期回填 `pages`，2066/2066 条全部命中。

## 资讯正文解析器重构

把 21 个源的正文形态全部实测了一遍（原始响应存在 `docs/_probe/feed-render/`），据此改的：

- **正文图**：只收正文域（校内 `/__local/` 等），模板 logo / 角标 / 二维码一律滤掉。新增 `FeedImages` 缓存（上限 3 MB × 8 张），界面用 `FillWidth` 等比铺满——长截图不裁、不设高度上限。
- **PDF 正文**：学生处那种「正文只有『请安装 PDF 阅读器』」的公告，现在如实显示「这份公告是 PDF」+ 一键交给系统查看器。
- **附件验证码**：校内站附件走 `download.jsp` 会拿到验证码页，按钮从「下载」改成「浏览器打开」，不假装能直接下。
- **容器 id**：校内竞赛是 `vsb_content_4` 不是 `vsb_content`，写死会让它整页空白。改成认前缀。
- **UTF-8 BOM**：7 个校内源里 6 个带 BOM，解析前统一剥掉。
- **就业信息网**：正文是 `base64 → zlib → base64`，数据层自己解，不引 WebView。

还加了正文缓存的 schema 闸门：解析能力升级后旧缓存视为未命中自动重抓。这条是被真机逼出来的——升级后学生处那条公告照旧显示「请安装 PDF 阅读器」，因为读的是旧缓存。
