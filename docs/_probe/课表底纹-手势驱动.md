# 课表底纹：滑动才转（手势驱动）

> 主人原话：「课程背景的动态效果，能做得到滑动才背景超立方体才去变化转动吗？」
> 结论：能。底纹从「无条件 34 秒自转」改成「手指在动才转，手停 600ms 就彻底静止」。

## 1. 驱动量怎么来的

两个方向合并成一个 `backdropDrive: MutableFloatState`，单位是「圈」（1.0 = 超立方体一个完整四维周期，与 `MathBackdropMotion` 的 `phase` 同单位）：

| 方向 | 采集点 | 换算 |
|---|---|---|
| 横向（切周） | `snapshotFlow { pagerState.currentPage + pagerState.currentPageOffsetFraction }`，吃位置变化量 | 变化 1.0 页 → `× 1/6` 圈 |
| 纵向（滚课表） | 底纹宿主层（外层 Box）挂 `NestedScrollConnection`，在 `onPreScroll` 旁听 `available.y`，返回 `Offset.Zero`（只旁听、不消费，滚动行为一行不改） | 每 px → `× 1/2400` 圈 |

两者都只做累加（`backdropDrive += …`），`MathBackdropMotion` 每帧只吃它的**变化量**（delta），
不关心绝对值——所以初始值从 0 起没有跳跃，也不会因为绝对位移累积而越转越快。

## 2. 翻一页转多少

**横滑翻一页 ≈ 转 1/6 圈**（`TURNS_PER_PAGE = 1f / 6f`）。

- 换周的那一下「转换」被看见，但不会转花眼。
- 按钮跳周（`animateScrollToPage`）也走同一条 `snapshotFlow`，所以按钮切周同样有转换。

纵向量级对齐：`TURNS_PER_VERTICAL_PX = 1f / 2400f`，滚满一屏课表（约 400px）也约 1/6 圈。

## 3. 静止阈值

- `DRIVE_IDLE_NANOS = 600_000_000`（600ms）：最后一次位移之后 600ms 内无新位移 → 停止推进 phase。
- 判定在 `MathBackdropMotion` 的帧循环里做（记录 `lastInputAt`），不是松手惯性、也不是慢转——是**彻底静止**。
- 静止后不空转帧循环：协程挂起在 `snapshotFlow { drive.value }.first { it != lastDrive }` 上，
  下一次 drive 变化才被唤醒，这才是「我滑它才动」。

## 4. 省电四条状态

| # | 要求 | 状态 |
|---|---|---|
| 1 | 不可见（生命周期非 STARTED）不跑 | ✅ 保持：`LaunchedEffect(visible, animScaleOff)`，`ON_STOP/ON_PAUSE` 置 `visible=false` 直接停协程 |
| 2 | 每帧零分配 | ✅ 保持：`withFrameNanos { it }` 单例 lambda；顶点/棱/角度复用 `TesseractBuffers`；drive 变化量是纯 float 加减 |
| 3 | 不逐帧重组 | ✅ 保持：`phase` 只在 `Canvas` 的 draw lambda 里读，只重绘不重组；drive 变化只改 `phase` 这个 `FloatState` |
| 4 | `ANIMATOR_DURATION_SCALE == 0` 时完全不播 | ✅ 保持：`animScaleOff` 为 true 时协程直接 return，只留静态姿态 |
| 5（新增） | 静止时真正停机 | ✅ 新增：600ms 无位移后帧循环停掉，靠 `snapshotFlow` 唤醒，不空转 vsync |

## 5. 真机手感

由 Lead 复核：滑动跟手度、手停即止、按钮跳周也有转换、静止时无后台空转。
