# m35 纹理与考试轴

对应原型：`docs/design/m35-纹理与考试轴.html`（单文件自包含，工具条可切「宣纸 / 夜墨」）

这一轮把五件视觉改动一次性摊在一页里：纸纹进卡片、设置页分区分盒、考试卡仿卡面、
资讯列表底部灰度收束、考试轴一条线走到底。个人身份卡按 m04458 的决定**保持纯净无纹**。

---

## 1 五块改动各解决什么

| 改动 | 原来的问题 | 现在的做法 |
|---|---|---|
| 纸纹进卡片 | 卡片是纯色块，层级只能靠间距，扫读时一片平 | 三款 1px 级纸纹，只压在功能盒内部，密度区分轻重 |
| 设置页分区分盒 | 一行一行排到底，看不出哪几项是一组 | 每组一个 box，组内 1px 细线分项，组间 22dp 留白、不画横线 |
| 考试卡仿卡面 | 考试信息和普通列表项长得一样，抓不住 | 竖向细条纹 + 双层描边 + 右下大字水印 + 底部 EXAM 标签位 |
| 资讯底部灰度收束 | 长标题被硬切，像是渲染坏了 | 底部 64% 起渐隐 + 一条 1px 实线落灰，明确「这里被截断」 |
| 考试轴对齐 | 分组头把轴切断，节点随 gap 漂移 | 一条连续竖线，节点恒在日期行中线，已结束不单独隔离 |
| 下一场盒 | 和普通卡同一个面孔，优先级不突出 | 左边缘一道溢出波纹 + 圆图标 + 右侧「N / 天后」大数字 |

## 2 三款纸纹

全部用 `background-image` 多渐变叠出来，没有位图，没有额外依赖。

### 2.1 参数（CSS 实测值）

```css
/* 织：斜向菱格，27px */
.tex-weave {
  background-image:
    linear-gradient(30deg,  transparent 45%, var(--tw1) 45% 55%, transparent 55%),
    linear-gradient(150deg, transparent 45%, var(--tw1) 45% 55%, transparent 55%),
    linear-gradient(90deg,  var(--tw2) 0 .6%, transparent .6% 99.4%, var(--tw2) 99.4% 100%);
  background-size: 27px 27px, 27px 27px, 100% 100%;
}
/* 格：24px 方格 + 交点圆点 */
.tex-grid {
  background-image:
    repeating-linear-gradient(0deg,  transparent 0 23px, var(--tex1) 23px 24px),
    repeating-linear-gradient(90deg, transparent 0 23px, var(--tex1) 23px 24px),
    radial-gradient(circle at 24px 24px, var(--texDot) 1.1px, transparent 1.1px);
  background-size: 24px 24px;
}
/* 十：30px，每格 1/4 与 3/4 处两道线，交点成十字 */
.tex-cross {
  background-image:
    linear-gradient(0deg,  transparent 24%, var(--tex2) 25% 26%, transparent 27%, transparent 74%, var(--tex2) 75% 76%, transparent 77%),
    linear-gradient(90deg, transparent 24%, var(--tex2) 25% 26%, transparent 27%, transparent 74%, var(--tex2) 75% 76%, transparent 77%);
  background-size: 30px 30px;
}
```

纸色化后的墨色（亮 / 暗）：

| 变量 | 亮 | 暗 |
|---|---|---|
| `--tex1`（格线） | `rgba(140,133,120,.072)` | `rgba(237,231,218,.052)` |
| `--tex2`（十字） | `rgba(140,133,120,.042)` | `rgba(237,231,218,.030)` |
| `--texDot`（格点） | `rgba(126,119,106,.14)` | `rgba(237,231,218,.095)` |
| `--tw1`（织线） | `rgba(140,133,120,.055)` | `rgba(237,231,218,.040)` |
| `--tw2`（织竖线） | `rgba(140,133,120,.032)` | `rgba(237,231,218,.024)` |

织比另两款再淡一档 —— 它线密，同浓度会在小盒里显脏（第一版 17px 时像防伪水印，现在 27px + 单独低一档）。

### 2.2 分配

| 位置 | 纹理 | 理由 |
|---|---|---|
| 个人身份卡 | **无** | 已经有压印 + 右上折角，再压纹只会脏；它靠体量和折角当主角 |
| 教务盒（成绩 / 考试 / 培养方案） | 格 | 三项并列，方格帮眼睛对齐 |
| 校园盒（校历 / 空闲教室） | 十 | 最疏，两项，不需要强引导 |
| 收藏与历史盒 | 织 | 菱形斜纹区别于上面两个方正的组，暗示「私人收藏」 |
| 资讯详情正文卡 | 十 | 大面积长文，疏纹不干扰阅读 |

### 2.3 硬约束

1. 纹理浓度总和不超过 18%（叠三层渐变时的视觉总强度）
2. 只出现在卡片内部，卡片外的页面底一律纯色
3. 一张卡只用一款，不混
4. 正文卡只用「十」，因为只有它疏到不影响 15px 中文行距
5. 圆角 4dp、1dp 描边与 m34 的口径一致，纹理跟着既有形状语言走

## 3.5 个人卡：展开与收起是同一套时序的镜像

个人卡保持 m34 装机版的样子（14dp 圆角、压印、右上折角、点一下向下撑开明细），
这一轮只改收起的节奏 —— 原来收起是把展开的曲线原样倒放，明细淡出慢（300ms）、
折角在收拢中途就冒出来、纸张高度又比明细晚一步动，看着拖尾巴。

现在两侧都是 520ms，且分段各管一段：

| 段 | 展开 | 收起 |
|---|---|---|
| 卡片高度 | 0 → 520ms，`cubic-bezier(.22,.9,.24,1)`，末端略微过冲 | 100 → 520ms，`cubic-bezier(.4,0,.2,1)`，加速、无过冲 |
| 明细文字 | 150 → 450ms 淡入，同时 +10dp → 0 归位（130ms 起 420ms） | 0 → 100ms 淡出并退回 +10dp，退净即离场 |
| 右上折角 | 60 → 240ms 淡出 | 340 → 520ms 浮现 |
| 总时长 | **520ms** | **520ms** |

- 收起先让字退净（100ms），再收纸（420ms），两段首尾相接、互不重叠
- 明细退到 `alpha ≤ 0.01` 才离开布局，卡片高度从那一刻起才真正开始收 —— 顺序稳定，不会出现半行字
- 折角等纸收到 340ms 才用 180ms 浮现，避免在收拢途中闪一下
- 展开侧的过冲保留（`.22,.9,.24,1` 末端略微越过再回落，纸被摊开的弹性），收起侧换成纯加速，落定即停

Kotlin 落点：`app/src/main/java/cn/dkarbon/enroute/ui/user/UserIdentityCard.kt`，
`revealAlpha` / `revealShift` / `foldAlpha` / `animateContentSize` 四处按 `expanded` 分支取不同 spec。

## 6 考试轴：一条线走到底

### 6.1 诊断

原实现的轴在每个分组头处断开，节点用 `Axis.nodeY(gap) = gap + DateLine/2` 计算 —— 只要上方多插一个分组头，gap 就变，
节点跟着漂；文件里 `padding(start = Axis.ContentStart)` 与 `Axis.X = 24.dp` 的差值又让轴本身偏过一次。

### 6.2 现在的口径

1. **一条轴**：`.axiswrap::before` 一条竖线，`left:24px`，从第一行画到最后一行，底部 78% 后渐隐，不随分组重画
2. **节点相对日期行定位**：`.node{position:absolute; left:-28px; top:50%; transform:translate(-50%,-50%)}` ——
   x 恒为 24px，y 恒为日期行中线，与 gap 完全解耦
3. **去掉 PAST 分组头与折叠**：`collapsed` 默认值从 `setOf(ExamBucket.PAST)` 改为空集，已结束的条目直接接在轴上，整卡 55% 透明表示过去
4. **今天 / 本周 / 更远 三个头也去掉**：只靠日期行 + 节点实心/空心区分，轴不中断
5. **进页面停在下一场**：`rememberLazyListState(initialFirstVisibleItemIndex = 下一场所在行)`，
   不必让主人自己往下找

保留的：下一场的实心节点 + 外扩光晕 + 页面右上「现在 HH:mm」随时间的极细标记（m34 已有的 `nowMarker`）。

## 9 验收

1. 三款纹理**只在卡片内部**，缩到 30% 截图仍能分辨织 / 格 / 十，但看不出「贴了张图」
2. 个人身份卡放大到 200% 看不到任何纹理
3. 设置页缩到 50% 时，四个分区一眼分开，组内行的横线不越过 box 边
4. 考试轴：从第一场滚到最后一场，轴线连续、无断口；任一节点圆心到左边距恒为 24dp（截图量像素）
5. 已结束的条目与未来条目共处一条轴，视觉靠 55% 透明区分，不靠折叠
6. 下一场盒的左波纹在亮/暗两档都可见，且不压到课程名
7. 资讯列表最后一条的截断处有实线，滚动到底部时不出现半行字
8. 全量单测绿，无新增依赖

## 10 落机后的实际参数与偏差（2026-11-20 实测）

原型上讲得通、上机才暴露的东西都记在这里，后面照这份改，不照原型图改。

### 10.1 纹路

| 项 | 原型 | 落地值 | 为什么改 |
|---|---|---|---|
| 格（GRID） | 线 .072 / 点 .14 | 线 **.052** / 点 **.095** | 24dp 步距在 1080p 上密度是原型的两倍，原值上机后像防伪底纹 |
| 十（CROSS） | 单档 .042 | **.075** | 正文页那层是整屏铺，.042 在这块屏几乎看不见 |
| 织（WEAVE） | .055/.032 | 斜 **.050** / 竖 **.032** | 保持；步距 27dp、竖导引 54dp |
| 暗档 | 同亮度 | ×0.72 | 深色下同 alpha 会显脏 |

`texInk` 统一取 `if (dark) ink else inkFaint`，再乘 alpha。调用顺序：`paperTexture` 必须在 `border` **之前**，否则描边被纹路盖住。

### 10.2 考试轴

- `ExamRows.build()` 改成**一条时间流**：全部按开考时间正序，不产 `ExamRow.Header`，`collapsed` 参数保留但不吃任何一场（老调用方仍可传）。
- 归档的 `AcademicRowsTest` 两条用例按新语义重写：`行是一条时间流 按开考时间正序 不产组头`、`已结束的不再折叠 也不被关进单独的段 仍留在轴上`。
- **下一场盒从 LazyColumn 里搬出来，固定在列表之上**。放在列表里会被 `scrollToItem` 和用户滚动一起带走，翻两下就找不到下一场。
- 进页 `LaunchedEffect` 一次 `scrollToItem(idx)`（idx = 下一场那一行），此后不再抢滚动位置。
- 波浪参数：`amp 11dp` / `belly 24dp` / 三段 cubic / `waveAlpha` 亮 .16、暗 .085。原型是 ±7dp——在 190dp 高的卡上就是一条直灰带，看不出浪。卡内 `padding start` 同步 16 → **30dp**，否则圆图标压在波谷上。

### 10.3 考试卡

绘制顺序踩了一个坑：`edgeGlow` 要画在 `.background(t.card)` **之前**，条纹 / 115° 光泽 / 内层亮边要画在 **之后**。顺序错了会被卡面整块盖掉，看起来"什么都没生效"。条纹 `inkFaint@.11`（暗 `White@.075`）、步距 4dp。

### 10.4 资讯

- 详情正文：`paperTexture(CROSS, radius = 0.dp)` 挂在 `verticalScroll` **外面**、`padding(horizontal)` **前面**，这样纹路铺满整宽且不随内容滚动。
- 列表条目底界：一条 `1dp t.outline` 实线 + 线下 8dp 灰晕（`outline@.10 → 透明`）。**必须画在行外层的 Column 里**——画在内容 `Column(weight(1f))` 内时，`fillMaxWidth` 拿到的是行内剩余宽，真机上只出半截。
- 组间那条 56dp 短横线（`LedgerGroupBreak`）保留，与组内实线分工不同：组内是"条目边界"，组间是"翻页"。

### 10.5 详情浮层

`ExamCard` / `NextUpCard` / `TimelineRow` 的 `onClick` 签名改成 `(Rect?) -> Unit`，用 `onGloballyPositioned { boundsInWindow() }` 把卡片矩形交给 `ExamDetailSheet(anchor = …)`。没有 anchor 时 `AnchoredCardOverlay` 会把面板挤在右上角约 210dp 宽——这就是"点开之后显示畸形"。
