# 设计 · 课程表组件化与预设（m41）

> 目标：把课表页从「一个 71 KB 的屏幕」拆成**可换件的拼装体** —— 每个模块、模块内部的部件
> 都能单独换掉，预设只是「一组选择的命名」。本文定槽位与取值口径，原型在 `docs/design/`。

## 0. 为什么现在拆

`ui/timetable/TimetableScreen.kt` 有 71 KB、20 多个 `@Composable`，格子的外观被写死在
`CourseCard` 与 `LedgerCourseCell` 两个函数里；能换的只有 `TtCardConfig` 的 7 个布尔/枚举
（版式、底色、脊、侵蚀、幽灵、食物、当前时刻环）。结果是「换皮肤」只能在这 7 个开关里排列组合，
而真正的差异（轴怎么画、页签什么形、Meta 怎么排、浮层长什么样）全被焊死。

拆的目标不是加设置项，是**让外观成为数据**：预设 = 一串槽位取值，换预设 = 换一串字符串。

## 1. 四层结构

```
L0  Shell            页面骨架：页头 / 周条 / 主体 / 页脚 / 浮层挂载点
L1  GridRegion       主体内的结构件：轴 / 页签 / 格阵 / 当前时刻 / 背景
L2  Cell             单个课程格：色带 / 课名 / Meta / 角标 / 侵蚀 / 小图形
L3  Overlay          浮层：详情 / 快捷操作 / 导入 / 校准 / 空态
```

层级之间只能**通过槽位注入**，不许跨层直接调用具体实现 —— 否则换预设时又会漏改。

## 2.5 从「一个槽位一个枚举」升级为正交轴（2026-11-21 主人追问后改）

第一版槽位表把「卡片长什么样」压成一个 `cell` 取值（paper/ledger/rule/block），这不够：
主人要的是**先挑卡片形状，再单独挑这张卡上的装饰与效果**，两件事不能焊在一起。
所以格子层拆成七条**互相正交的轴**，任意两轴可以叠：

| 轴 | 取值 | 管什么 | 互斥约束 |
|---|---|---|---|
| `shape` | 方卡 / 便签 / 细线 / 色块 / 标签 | 骨架：圆角、投影、底色、内边距 | 细线不叠投影 |
| `decor` | 无 / 左脊 / 顶帽 / 角点 / 底线 / 淡底 / 斜纹 | 骨架之上的装饰，**任何形状都能叠** | 角点与 `badge=corner` 抢同一角落 |
| `meta` | 三行 / 同行 / 底栏 / 只课名 | 课名与地点教师怎么排 | 只课名时不显示角标文字 |
| `badge` | 无 / 折角 / 斜纹带 | 自标/未读状态 | 斜纹带只在只课名时用（否则吃字） |
| `erosion` | 不褪 / 上褪 / 斜线 / 整块淡 | 上完课的褪色方式，只褪色不删卡 | — |
| `motion` | 关 / 呼吸 / 褪色呼吸 | 格子微动效，**整页可一键关** | 关掉后与静态逐像素一致 |
| `tone` | 四色 / 单墨 / 无色 | 颜色从哪来 | 无色时色块形状退化为描边 |

单格组合 = 5 × 7 × 4 × 3 × 4 × 3 × 3 = **15120**，扣掉互斥约 1.2 万。
布局层同理：`axis` / `dayHeader` / `grid` 三条轴独立，`backdrop` 与 `bgMotion` 拆开 ——
**「底纹换成纯色、动效关掉」是一个独立开关，不是一种底纹**。

原型：`docs/design/课程表-组装器.html` —— 左边 12 行槽位逐个点，右边手机实时重拼；
下方 8 格是同一批课程只换轴的并排对照。

## 3. 预设 = 槽位取值的一组命名

```json
{
  "preset": "ledger",
  "shell": "ledger", "header": "toolbar", "weekStrip": "chips",
  "axis": "gutter", "dayHeader": "ribbon", "grid": "bands",
  "cell": "ledger", "accent": "cap", "meta": "stacked", "badge": "corner",
  "erosion": "wipe", "glyph": "ghost", "nowLine": "ring", "backdrop": "none",
  "detail": "sheet", "quick": "grid", "empty": "ledger"
}
```

首版五套（代号即 `preset` 值）：

| 预设 | 气质 | 关键选择 |
|---|---|---|
| `paper` 纸卡 | 现状默认，硬朗农业 | shell=editorial, cell=paper, accent=spine, grid=lines, backdrop=ridge |
| `ledger` 账页 | 便签浮起、零横线 | shell=ledger, cell=ledger, accent=cap, grid=bands, axis=gutter |
| `dense` 密排 | 一屏塞下整周 | shell=dense, cell=rule, meta=inline, axis=inline, nowLine=band |
| `agenda` 周历 | 竖向流水，像日程本 | shell=dense, cell=block, meta=footer, dayHeader=stack, grid=air |
| `quiet` 极简 | 只有课名与留白 | shell=quiet, header=bare, cell=block, accent=wash, meta=minimal, glyph=none, nowLine=rule |

**兼容**：`TtCardConfig` 的 7 个开关保留，作为预设之后的手动覆盖（预设先落地，开关改的是覆盖层），
老用户升级一个像素不变 —— 默认预设 = 迁移前的全部取值。

## 9. 浮层层交付与落地风险（kit-overlay，2026-11-21）

`docs/design/课程表-浮层.html`（171 KB，单文件自包含，亮/暗各 6 段 + 可点的演示）。
`detail` = `sheet`（底部贴边、20 dp 上圆角、36×4 把手）/ `card`（左右各留 40 dp，四边都看得见底下课表） / `full`（整页推进、无遮罩）；
`quick` = `grid` 3+2 / `list` 5 行 / `radial` 180° 弧（半径 112、标签收进 52×48 药丸、锚点格描 `--ring` 反白）；
`empty` = `list` / `cards` / `ledger`；另有整周无课（印章「本周无课」+ 共 0 门 0 节）、没大纲整页、导入三种（paste/sync/file）、校准两态（未校准显示「教历 暂缺」）。

原型自查改掉的六件事（都是真问题，抄进实现时别再犯）：按行过滤课块否则溢出压字；空态必须排除已排课的课程，否则「未排课」与格子里的马原自相矛盾；
粘贴框错误行不能用 box-shadow 铺色（暗色盖字、亮色被裁），改整行底色并去掉 `<pre>` 内换行；radial 半径 100 时标签撞邻格 → 112 + 内收；
没大纲页要整页骨架而不是「课表页 + 一段大纲」；radial 暗色锚点靠 2 px 反白描边才读得出。

### 写进 Kotlin 会难的地方（按风险排序）

1. **格子里的两行中文 × `fontScale`**：41×126 dp、10 px 字在原型里写死。Compose 的 `sp` 跟系统字阶走，1.3 倍时一格只放得下 3 字，`Ellipsis` 会吃掉课名。要么全表 `LocalDensity.provides(fontScale = 1f)`，要么按 fontScale 降级（横排 → 缩字 → 只留首字）。这是最可能翻车的一条。
2. **`sheet` 的把手与吸附**：M3 `ModalBottomSheet` 的 scrim、圆角、handle 全走 M3 token；要贴 42%/52% 遮罩与 20 dp 圆角只能自绘 `nestedScroll` + `anchoredDraggable`。
3. **`radial` 必须活在课表坐标系里**：`Popup`/`Dialog` 脱离布局坐标，锚点格 bounds 要靠 `onGloballyPositioned` 上传；自定义 `Layout` 算极坐标并手动扩大命中区。
4. **虚线「暂缺」**：Compose 无虚线修饰符，要 `drawBehind` + `PathEffect.dashPathEffect`，圆角虚线得自己画 `RoundRect` stroke（2 px 在 1.5x density 下会断成点）。
5. **导入的「第 N 行第 M 列」**：能报位置，但逐行高亮对齐要 `AnnotatedString` + 固定行号列宽，中英混排宽度会漂 —— 真要做准得 `TextMeasurer` 算 tab 停位，或直接渲染成表格。
6. **暗色错误标签是「实底 + 深字」**，不是 `colorScheme.error`；三种宿主（BottomSheet / Dialog / NavHost 目的地）各配一次遮罩，否则出现三种灰。
7. **393 dp 是设计假设**：7×45 + 40 = 355，剩 38 dp；360 dp 宽机型必须给列宽下限兜底，否则一格只剩两个字。

## 8. 落地映射（Kotlin，等主人点头后一批写完只编译一次）

```kotlin
// ui/timetable/TtPreset.kt（新）
@Immutable
data class TtPreset(
    val id: String = "paper",
    val shell: String = "editorial",
    val header: String = "toolbar",
    val weekStrip: String = "chips",
    val axis: String = "rail",
    val dayHeader: String = "tabs",
    val grid: String = "lines",
    val cell: String = "paper",
    val accent: String = "spine",
    val meta: String = "stacked",
    val badge: String = "corner",
    val erosion: String = "wipe",
    val glyph: String = "ghost",
    val nowLine: String = "ring",
    val backdrop: String = "ridge",
    val detail: String = "sheet",
    val quick: String = "grid",
    val empty: String = "list",
)
```

- `TtCardConfig` 的 7 个开关**保留**，语义改为「预设之上的手动覆盖」：先解析 `TtPreset`，再用开关覆写对应槽位；默认预设 `paper` 的取值 = 迁移前写死的全部取值，老用户升级零像素变化。
- 配置仍走 `LocalTtCardConfig`（`compositionLocalOf`）+ AppState 的 StateFlow 单真身，**不加**第二份状态。
- 渲染侧按槽位分派：`when (cfg.cell) { "paper" -> PaperCell(...) ; "ledger" -> LedgerCell(...) ; "rule" -> RuleCell(...) ; "block" -> BlockCell(...) }`；每个分支是独立 `@Composable`，签名统一 `(course, cfg, onClick)`，互相不许直接调用。
- 设置页新增「课程表外观」：五张预设缩略卡 + 展开后的槽位覆盖项（高级）；预设缩略图用 Compose 画，不用位图资源（避免涨包体）。
- 回归：`TtCardConfig` 相关单测保留，新增 `TtPresetTest` 断言「paper 预设逐槽位等于迁移前的硬编码值」，这条锁住老用户不变样。
