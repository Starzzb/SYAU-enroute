## 1. 为什么是"四维旋转"而不是"转圈"

四维里刚体旋转是**在一个平面内的转动**，共 6 个坐标平面：`XY XZ XW YZ YW ZW`。

只有绕 **XW / YW / ZW** 转，顶点才会在 `w` 方向上移动；`w` 一动，4D→3D 的透视除法
`k = 1/(D − w)` 就变了 —— 视觉上就是**内层小立方体涨大穿出、外层缩回**。这就是"转换"。
只在 XY 平面上转 = 整个图形在屏幕上转圈，一眼假。

**相机不动**：3D 视角固定（`CAM_PITCH 0.52` / `CAM_YAW 0.36`），变化的只有四维姿态。
否则"是四维在转"和"是相机在转"就分不清了。

### 速度配比（`TURNS_PER_CYCLE`，一个周期转多少圈）

| 平面 | XY | XZ | XW | YZ | YW | ZW |
|---|---|---|---|---|---|---|
| 圈/周期 | 1.00 | 0.58 | 0.46 | 0.50 | 0.70 | 1.04 |

两条约束一起满足：

1. **六个速度两两不同**（否则等于同一个平面转了六遍）；
2. **贴近"等斜对"**：四维里 `(XY,ZW)`、`(XZ,YW)`、`(XW,YZ)` 是等斜配对，对内角度相近时
   图形整个周期保持饱满；差太多时某些瞬间会压成一条线。这里三对基速 1.00 / 0.58~0.70 / 0.46~0.50，
   对内偏移 0.04–0.12 圈。

`W_DISTANCE = 2.6` 不是随手取的：顶点是 `(±1,±1,±1,±1)`，到原点距离 **2**，
所以旋转后 `|w|` 最大能到 **1.94**（不是 1！）。取 2.0 会让分母 `2.0 − 1.94 = 0.06` 爆掉
（实测外接半径会窜到 1856 倍）。2.6 是既有代码就选对的，这里沿用并写进注释。

## 2. 「转换」怎么被量化（不是"看着像"）

肉眼判不准"是不是四维在转"。所以把效果定义成可测的量：

> 任一时刻，投影后**半径最小的 8 个顶点**是内层立方体、**最大的 8 个**是外层。
> 如果四个维度真的在转，**同一个顶点会时而属于内层、时而属于外层** —— 这就是交换。

实测：**16/16 个顶点都在一个周期内进过内层与外层**（180 个采样点）。
单测 `内外两层在整个周期里确实交换` 断言 ≥12/16，红了就说明做出来的不是转换。

## 4. 省电与"不抢戏"（代码里能看出来的四条）

| 要求 | 实现 | 位置 |
|---|---|---|
| **只在可见时跑** | `LaunchedEffect(visible, animScaleOff)`；`visible` 由 `LifecycleEventObserver` 维护（`ON_START/ON_RESUME→true`，`ON_STOP/ON_PAUSE→false`）。页面离开组合时协程本身也会被取消 | `MathBackdropMotion` |
| **每帧零对象** | 顶点/棱/角度/深度全在 `TesseractBuffers` 里复用；`Color`/`Offset` 是 value class 不进堆；推进循环写成 `withFrameNanos { it }`（**不捕获变量** → 编成单例，每帧不 new 闭包） | `TesseractBuffers` / 循环 |
| **不逐帧重组** | 相位是 `mutableFloatStateOf`，但**只在 `Canvas` 的 draw lambda 里读** → Compose 记为绘制阶段依赖，只重绘、不重组 | `MathBackdropMotion` 末尾 |
| **关动画就静止** | `Settings.Global.ANIMATOR_DURATION_SCALE == 0` → 循环不启动，只留一个静态姿态（相位固定 0.31） | 同上 |

线宽 **1 物理像素**（不乘 density）：它要的是"纸上一根细线"，不是 1dp 的 UI 元素。
透明度按主题分档：**硬朗浅色 0.12 / 硬朗深色 0.14 / 账页浅色 0.085 / 账页深色 0.115**
（账页最低：那边有成行色带 `BandTint`，再浓就成"脏底"）。周期 **34 秒**。

近实远虚的淡出下限取 `0.55 + 0.45·near`：原来试过 0.42，远处那半圈淡到看不见，整张图"缺一半"。

## 6. 单测（`Tesseract4DTest`，9 条全绿）

| 用例 | 防什么 |
|---|---|
| `六平面组合旋转矩阵处处正交`（37 个相位 × 4 个基向量） | 防把刚体旋转写成会拉伸的假旋转 |

| `相位归一化到零到一`（含 0 与 1 同姿态） | 防循环接缝跳变 |
| `深度归一化落在零到一且单调` | 防近实远虚反向 |

## 7. 接在哪一页 / 为什么不是「我的」

接在**关于页**（设置 → 关于），不是「我的」：这一页没有数据、常驻可达、留白最多。
「我的」和「设置」的卡片几乎铺满宽度，背景会被不透明卡片盖掉九成 —— 接上去等于白做。
关于页的正文在 16dp 内边距里，背景线正好落在留白与卡片间隙，能读到形变。

如果要推广，建议顺序：关于页（已接）→ 空状态（查教师未搜索 / 空闲教室空态）→ 设置页 → 我的。
不建议进课表页：那边已经有网格 + 侵蚀卡 + 小幽灵，再加动态背景会吵。
