## 3. 逐站探测（每站一段，探完即存）

### 3.1 中国教育考试网 `neea.edu.cn` —— **B 级（HTML 解析，结构很稳）**

**robots.txt：404（站点没有这个文件 → 无抓取限制声明）**

首页 `https://www.neea.edu.cn/` 200 / 68KB，栏目全部来自首页导航（未猜 URL）：

| 栏目 | 列表页 |
|---|---|
| 考试资讯 | `/html1/category/16093/615-1.htm` |
| 公示公告 | `/html1/category/1508/151-1.htm` |
| 中小学教师资格考试 | `/html1/folder/1507/1076-1.htm` |
| 全国计算机等级考试（NCRE） | `/html1/folder/1507/770-1.htm` |

**列表页结构（实测）**
- 条目：`ul > li > span > a[href='/html1/report/<栏目>/<id>-1.htm']`，**锚文本为空，标题在 `title` 属性里** ⚠️
- 每页 15 条；分页 `615-2.htm … 615-8.htm` + 「下一页」
- **无 JSON 接口**（页面里 `api/.json/ajax` 线索为 0，Playwright 抓包也只有静态资源）

**详情页（`/html1/report/2609/73-1.htm`，19KB）**
- 标题：`<title>教育部部署2027年全国硕士研究生考试招生工作 - 中国教育考试网</title>`
- 正文前缀：`发布时间： 2026-09-28 来源： 教育部`
- **可稳定取到：标题 / 发布日期 / 来源 / 正文首段**（做摘要足够）

**证据**：`docs/_probe/neea/home.html`、`615-1.htm`、`151-1.htm`、`detail-sample.html`

**结论**：`A-`/`B` 级。结构极稳（政府 CMS 模板十年不变），但**要解析 HTML**、且标题在属性里 —— 现有 feed 解析器已支持「属性取标题」这条路（教师抓取同款坑）。
**证书类只接「报名/考试公告」**：四六级(CET)/教资/NCRE 的公告都在「考试资讯 + 公示公告」两个列表里，**不碰任何成绩查询**。
