## 关键读数（尤其暗色正文）

- **HARD 暗色正文 `ink` = #EDE8DF**：对纸底 15.79:1，暖米白，非纯白 —— 达标且不刺眼。
- **HARD 暗色三级字 `inkFaint`**：原 #7E7468 对卡Alt 只有 3.27:1（不达标），提亮到 #988D82 后最低 4.61:1。
- 暗色里 rule / outline 的最低值都压在「对卡Alt」这一档：3.08 / 3.41（HARD）、3.23 / 3.24（账页），全部 ≥3:1。
