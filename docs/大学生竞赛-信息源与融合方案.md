# 大学生竞赛 —— 信息源调研与融合方案

> 调研时间：2026-11-11
> 目标 App：`cn.dkarbon.enroute`（沈阳农业大学学生端 Android）
> 读者：数据层实现者（Kotlin 手写 HTTP + HTML 解析，无 JS 引擎、无 RSS 库）
> 方法：全部结论来自**实际 HTTP 请求**（PowerShell `Invoke-WebRequest`，浏览器 UA），逐页核对状态码、响应字节数、编码、条目数与真实 `<a>` 片段。脚本与原始 HTML 证据留在 `docs/_probe/competition/`。
> 搜索引擎状态：tavily / deepseek MCP `fetch failed`；百度已对本站 IP 返回「百度安全验证」；Bing 中文多词查询会被降级成单字。**因此本报告不依赖搜索摘要，一律直连目标页验证。**

---

## 1. 结论摘要

1. **校内竞赛通知只有一个真正的栏目页：`https://job.syau.edu.cn/cxcy1/cxcyjs.htm`（学生创新创业与就业指导处「创新创业竞赛」，共 95 条，15 条/页）**。它用的是标准博达 VSB `<li><a>标题</a> 日期</li>` 结构，和 App 现有解析器**同一家族**，改个 baseUrl 就能跑。
2. **教务处没有独立的「学生竞赛通知」列表**。`jwc.syau.edu.cn/jxry/xsjs.htm` 页面标题虽是「学生竞赛」，但正文只有 3 个 2020 年的静态链接（国家级/省级/校级），**不是列表，不能接入**。真正的校内竞赛通知散落在**教务通知** `index/jwtz.htm`（按 `[实践教学科]` 标签识别）和 **job.syau 通知公告** `tzgg.htm`（286 条）里。
3. **三个校内源的结构家族互不相同，现有解析器只能直接吃下一半**：job.syau = 日期为裸文本的 `<li>`；jwc = `<li id="line_u7_N"><a><span>日期</span><em>[科室]标题</em></a></li>`（日期在**锚点内部**、标题含科室前缀、且**混用 `content.jsp?wbnewsid=` 形式链接**）；校团委 = `<div class="date"><b>日</b><span>年-月</span></div>` 把日期**拆成两段**。三者都要单独写选择器。
4. **全国级没有可稳定抓取的「官方统一竞赛通知源」**。中国高等教育学会（cahe.edu.cn）确有「竞赛工作」栏目但只是 6 个赛事子站的跳转页；《全国普通高校大学生竞赛分析报告》是一年一篇的**新闻稿**（如 `site/content/17082.html`），不是列表。真正能当信息流用的全国源是 **挑战杯官网 `/tzb`（57 条，规范 `/article/NNNN/`）** 和 **我爱竞赛网「榜单竞赛」分类（25 条/页，教育部榜单赛事视角）**，二者都无 RSS。**赛氪（saikr）与蓝桥杯报名站（dasai.lanqiao.cn）是纯 SPA，返回 1.4–4.6KB 空壳，必须 JS 渲染，本方案不接。**
5. **辽宁省级可用且干净**：`https://jyt.ln.gov.cn/jyt/gk/zxtz/index.shtml`（最新通知，15 条/页），URL 里直接带 `YYYYMMDDHHMMSS` 时间戳，**日期字段零解析成本**；robots.txt 无任何 Disallow。省赛通知确实在这里发（实测首条即「关于举办第四届全国大学生职业规划大赛辽宁省赛的通知」）。
6. **没有任何站点提供 RSS/JSON 订阅**。全链路 404：`jwc/job/rss.xml`、`feed`、`sitemap.xml`、`cahe/sitemap.xml`、`tiaozhanbei/rss`、`jyt/sitemap.xml`、`mcm/rss.xml`、`saikr/sitemap.xml` 全部 404。唯一例外是**我爱竞赛网有 `sitemap_index.xml`（200, text/xml）**，可作为 URL 发现用，但不是条目流。**结论：RSS 路线放弃，老老实实解析 HTML。**
7. **⚠️ 合规红旗：`*.syau.edu.cn` 全校站群 robots.txt 是 `User-agent: * / Allow: /$ / Disallow: /`——除首页外全站禁止爬取。** 技术与合规需要产品侧决策（见 §5）。省级与全国源均未禁止。

## 3. 各源抓取方案

### 3.0 结构家族定义（本报告用词）

| 家族 | 特征 | 现有解析器能否直接用 |
|---|---|---|
| `vsb/list-li-a` | `<li>` 内一个 `<a href="…info/{频道}/{文章}.htm">` + 日期文本/`<span>` | ✅ 基本可用 |
| `div-span-date` | 列表项由 `<div class="date">`/`<div class="txt">` 组合，日期被拆成 `<b>`+`<span>` | ❌ 需新写 |
| `table` | `<tr><td>` 表格布局 | ❌ 需新写 |
| `js` | 首屏 HTML 是空壳，内容由 JS 拉取 | ❌ 不可能（无 JS 引擎） |

**「日期在锚点内部」是本批新增源最集中的坑**：jwc 与 52jingsai 的日期都包在 `<a>…</a>` 里，若只取 `a` 之后的文本会全部丢日期。

### 3.1 学生创新创业与就业指导处 · 创新创业竞赛（**校内首选**）

- **列表**：`https://job.syau.edu.cn/cxcy1/cxcyjs.htm`（频道 `1040`，共 95 条，15 条/页，7 页）
- **真实条目片段**（300 字符内）：

```html
<li> <a href="../info/1040/3806.htm" target="_blank" title="我校在iCAN大学生创新创业大赛全国总决赛中获三等奖">我校在iCAN大学生创新创业大赛全国总决赛中获三等奖</a> 2025-12-17 </li>
```

- **选择器思路**：`li` → 第一个 `a[href*="/info/"]` → 标题优先取 `@title`（列表里的可见文本可能被截断，`@title` 是全文）→ 日期取 `li` 尾部裸文本，正则 `(20\d{2})-(\d{1,2})-(\d{1,2})`。
- **日期格式**：`YYYY-MM-DD`，**无 `<span>` 包裹**，纯文本节点。
- **相对链接**：`../info/…`，相对 `/cxcy1/` → 解析后 `https://job.syau.edu.cn/info/1040/3806.htm`。**必须用 `base = 列表页 URL` 做 RFC 3986 解析，不能字符串拼接。**
- **分页规律（坑）**：页码**倒序**。第 2 页是 `cxcyjs/6.htm`，最后一页是 `cxcyjs/1.htm`（共 7 页 → `6…1`）。**不能用 `page=N` 递增。**
- **详情页**：正文容器 `id="vsb_content"`（与现网一致）；附件走 `/system/_content/download.jsp?urltype=news.DownloadAttachUrl&owner=…&wbfileid=…`，实测该频道详情页命中附件链接。
- **内容实测**：混合「获奖喜报」（我校获…铜奖）与「开赛通知」（关于举办…校园选拔赛的通知）。做竞赛频道时建议**按标题前缀过滤**：`关于举办/关于开展/关于组织` → 通知类；`我校/喜报/获` → 战报类。

### 3.2 学生创新创业与就业指导处 · 通知公告（竞赛通知主战场）

- **列表**：`https://job.syau.edu.cn/tzgg.htm`（频道 `1023`，共 286 条，15 条/页）
- **片段**：`<li> <a href="info/1023/3858.htm" target="_blank" title="关于举办第四届全国大学生职业规划大赛沈阳农业大学校赛的通知">…</a> 2026-10-28 </li>`（相对链接**带不带 `../`** 在同一站不同栏目并不一致，务必按页解析）
- **命中示例**：职业规划大赛校赛、辽宁省动植物标本制作大赛校园选拔赛、中国国际大学生创新大赛校园选拔赛、大学生创新训练计划立项、**「关于公布2026年大学生创新创业竞赛目录的通知」**。
- **价值最高的一条**：`https://job.syau.edu.cn/info/1023/3815.htm`（2026 年竞赛目录），正文 `vsb_content` + 附件 `download.jsp`（实测 owner=1576847305, wbfileid=11834427）。**抓到后可离线生成「校内认定竞赛目录」，是竞赛日历与加分口径的依据。**
- **日期缺失**：无。**分页**：`tzgg/19.htm` … `tzgg/1.htm`（**倒序**，共 20 页 ≈ 286 条，同 3.1 的倒序规则）。

### 3.3 教务处 · 教务通知（按科室标签筛竞赛）

- **列表**：`https://jwc.syau.edu.cn/index/jwtz.htm`
- **真实片段**：

```html
<li id="line_u7_0"><a href="../info/1251/10663.htm"> <span>2026-11-09</span><em><span style="color:#0b6cb8;float:none;">[实践教学科]</span>关于对2025年度沈阳农业大学优秀本科毕业论文（设计）培育计...</em></a></li>
```

- **三个必须处理的差异**：
  1. **日期在 `<a>` 内部**（`<span>` 是锚点的第一个子元素），标题在 `<em>`，且带 `[科室]` 彩色前缀 → 解析时需 `a > em` 取标题、再剥离 `^\s*\[[^\]]+\]\s*`。
  2. **标题被截断**（结尾 `...`），`<a>` **没有 `title` 属性** → 列表只能拿到截断标题，**真标题必须进详情页取**。
  3. **同一列表混用两种详情 URL**：`../info/1248/10661.htm` 与 `../content.jsp?urltype=news.NewsContentUrl&wbtreeid=1249&wbnewsid=10662`。两者都要能解析（后者可反推频道=1249）。
- **分页**：`jwtz/191.htm` … `jwtz/1.htm`（**倒序**，约 192 页 = 每页 15 条）。首屏无「共 N 条」。
- **竞赛过滤**：当前页 15 条中 1 条含竞赛（`[实践教学科]关于开展沈阳农业大学教师教学竞赛项目征集工作的通知`）。**竞赛不是独立频道，只能靠标题关键词 + 科室标签双过滤**，且**召回率天然有限**——这正是必须同时接 job.syau 的原因。

### 3.4 校团委 · 通知公告（校级活动赛事）

- **列表**：`https://tw.syau.edu.cn/channel.jsp?urltype=tree.TreeTempUrl&wbtreeid=1053`（频道 `1053`）
- **真实片段**：

```html
<li> <div class="date"><b>5</b><span>2026-11</span></div> <div class="txt"> <a href="info/1053/8419.htm">关于开展沈阳农业大学2026年“用青春铺路 让理想闪光”主题演讲比赛的通知</a> <p>共青团沈阳农业大学委员会文件…
```

- **坑**：日期被**拆成两段**——`<b>` 是「日」，`<span>` 是「年-月」。必须拼 `YYYY-MM-DD`；只取 `<span>` 会只有月份。
- **额外红利**：`<li>` 内的 `<p>` 是**正文首段摘要**（实测每项都有），可直接做列表二次摘要/关键词命中，不必进详情页。
- **详情页**：`id="vsb_content"` ✅，正文为公文格式（含文号 `沈农大团发〔2026〕36号`），可用正则从文号/落款取「发文日期」。

## 4. 融合设计建议

### 4.1 分频道方案（推荐路径，改动最小）

现有「资讯」页已有聚合流。建议在 chips 增加一个 **「竞赛」** 频道，**复用现有 `NewsItem` 数据模型，只加 3 个字段**：

```
channel: COMPETITION            // 频道枚举
competitionLevel: NATIONAL | PROVINCE | SCHOOL   // 全国/省/校
noticeType:  OPEN | RESULT      // 开赛通知 / 获奖战报（由标题前缀判定）
```

- **数据映射**：
  - 全国 ← 挑战杯 `/tzb` + 我爱竞赛网「榜单竞赛」（可再加 mcm/CMC 用静态节点）
  - 省级 ← `jyt.ln.gov.cn` 最新通知 + 公示公告（标题含「大赛/竞赛/选拔赛」才入库）
  - 校级 ← `job.syau/cxcy1/cxcyjs.htm`（战报+通知）+ `job.syau/tzgg.htm`（通知主战场，关键词过滤）+ `tw` 通知公告（活动赛事）+ `jwc` 教务通知（`[实践教学科]` 标签）
- **每条 item 增加 `deadline: LocalDate?`**：从正文正则抽取（见 4.2）。
- **UI**：竞赛频道内做三段式 Tab（全国/辽宁/校内），与现有资讯流同一列表组件；卡片显示「来源 + 层级标签 + 报名截止倒计时」。
- **推送策略**：**只对 `noticeType=OPEN` 且 `deadline` 在 7 天内的条目推送**，战报类静默入流。这是避免「全量轰炸」的关键。

### 4.2 竞赛日历：报名开始/截止能不能拿到？

**能，但只能从正文抽，且覆盖率约一半。** 依据：

- 报名截止信息**不在任何列表里**，只在详情正文（`vsb_content` / `#content`）中。
- 实测正文可命中的正则骨架（已在 jyt 详情页命中 2 处）：
  ```
  (报名|报名时间|提交|作品提交|截止|截止日期)[^。；\n]{0,30}?(20\d{2})\s*[年\-/]\s*(\d{1,2})\s*[月\-/]\s*(\d{1,2})
  ```
  另需覆盖 `X月X日前`、`X月X日17:00前`、`即日起至X月X日` 三种口语写法，以及**只写月日省略年份**的情况（用列表日期年份兜底）。
- **建议落地方式**：
  1. 列表页同步 → 仅当标题命中 `关于举办|关于开展|通知` 时，**按需拉正文**（一次请求）。
  2. 正文抽 `deadline`；抽不到就标 `null`，UI 不显示倒计时（**不做猜测**）。
  3. 命中率预期：`关于举办…大赛的通知` 类条目约 50–70% 含明确截止日期；战报类为 0。
- **更稳的替代**：校内 `job.syau/info/1023/3815.htm`（竞赛目录）+ 各赛事官网时间窗做成**本地静态「赛事年历」**（mcm 每年 9 月、数学竞赛每年 11 月初赛、挑战杯偶数年校赛…），日历页以静态年历为主、抓取补充为辅。**这比纯抓取可靠得多，也更适合课表类 App 的"提前一个学期规划"场景。**

### 4.3 「按需抓正文 + 长期缓存」可行性

**可行，且是必须的。** 理由与做法：

- **必须**：jwc 列表标题被截断（`…` 结尾）、52jingsai 列表无日期、竞赛日历需正文 → 纯列表方案信息不完整。
- **量级**：竞赛类增量极低。job.syau 双创频道 95 条覆盖约 2 年；jt 最新通知 15 条/页、周级更新。**全量冷启动 < 400 次请求，日常增量 < 10 次/天**，对任何站点都不构成压力。
- **缓存策略**：
  - 列表：`ETag`/`Last-Modified` 条件请求（VSB 站群一般支持）；无则按 `URL + 列表首条标题` 做变更指纹。
  - 详情：**按文章 ID 永久缓存正文 HTML/纯文本**（文章内容不会变），只对 `deadline` 抽取值做一次计算并落库。缓存键建议 `sourceId + articlePath`（如 `job.syau|/info/1023/3858.htm`）。
  - TTL：列表 6 小时；详情永久；失败重试退避。
- **不要做的事**：不要在前台实时抓正文；不要抓「获奖名单」类附件的解析（PDF/Excel 解析成本远超收益，直接给外链）。

## 6. 待人工确认项

1. **【合规·最高优先】`*.syau.edu.cn` robots.txt 全站 `Disallow: /` 如何处理？** 三个选项：(a) 视为学校内部系统、按校内信息化授权沟通后抓取；(b) 改为**由用户端在 App 内触发、只抓用户点开的那一条**（等同人工浏览）；(c) 放弃校内源、只做全国+省级。
   注：本报告只做技术验证，不代表已获得授权。
2. **来源标注口径**：竞赛频道里「全国/辽宁/校内」三段式是否符合产品预期？还是想按「学科类/创新创业类/艺术设计类」分类？
3. **52jingsai（我爱竞赛网）是否可接受**：它是商业聚合站，条目含大量付费培训/证书类推广（实测首条即「Office 办公技能证书」），需要人工定「白名单关键词」（如仅收「教育部榜单赛事」分类）还是直接不用。

5. **分页深度**：竞赛频道首屏是否只要最新 15–30 条（够用、请求少），还是要翻历史（job.syau 双创 7 页、教务通知 192 页）。**192 页全量翻页会显著放大请求量，建议只做首 3 页。**
6. **jyt.ln.gov.cn 翻页机制未确认**：列表页未见 `index_2.shtml` 之类 href，翻页可能由 JS 触发；当前 15 条/页够用，如需历史需补测。
7. **大广赛 / 睿抗 / 中国高校计算机大赛** 未取得可用列表页（或仅少数壳页）：如产品要求覆盖，需再投入一轮逐个确认其「通知」栏目真实路径。
8. **`grs.syau.edu.cn` 频道号混排**（`1165/1141/1118`）：若要做研究生竞赛子频道，需先人工确认这些频道分别对应什么业务，不能靠猜。

### 7.2 新增「通用解析族」（`FeedParser.parseListGeneric`）

原来的解析器只认博达 VSB 的 `info/{栏目}/{文章}.htm`，挑战杯是 `/article/15841/`、
省教育厅是 `/jyt/gk/zxtz/{时间戳}/index.shtml`，一个都匹配不上。通用族的锚点是
**「像标题的链接 + 300 字内的一个日期」**，找不到日期就丢 ——
导航栏、页脚、友情链接全都没有日期，这一条就能筛干净。

配套两个过滤器（都是站点差异，不是 hack）：

- `FeedSource.titleInclude` —— 标题白名单。省教育厅什么都发（教师节、信息化评选），只留竞赛相关。
- `FeedSource.urlInclude` —— 链接白名单。挑战杯列表里混着 `2026国赛` 这类活动入口，只留 `/article/`。

### 7.3 顺手修掉的站群变体

`job.syau.edu.cn/cxcy1/cxcyjs.htm` 的日期排在 `</a>` **外面**
（`<li><a …>标题</a> 2025-12-17 </li>`），老解析器只读 `<a>` 内部 → 整批条目无日期。
现已兜住：`<a>` 内找不到日期时，往后 80 字再找一次。
