⑤ 资讯详情 · 正文卡用十字纹底（不压字）
第二排 · 三款纹理的放大样张（真实密度，非放大）
织 · 27px 菱格 · 双层斜线 + 竖向导引
格 · 24px 方格 + 交点圆点
十 · 30px 方格内十字（密度最低，最适合正文）
对照 · 文字叠在纹理上仍要 ≥4.5:1

三款纹理 · 从参考里取了什么

  • 织（lovely-donkey-52）：取「斜向双层编织 + 竖向导引」的骨架，把 #282828/#2c3539 双色块**降成两道 1px 线**，密度 27px。参考里是实心六边形，实心纹在纸底上会变成一块灰色噪声。
  • 格（brown-badger-26）：原样取 24px 方格 + 交点圆点，线宽 1px、透明度从 .08 提到 .16（纸底浅，太淡就看不见）。
  • 十（fluffy-chipmunk-60）：取「每格 1/4 与 3/4 处画线」的十字逻辑，格子从 55px 压到 30px —— 55px 在 392dp 屏上只出现 7 个格，看不出是纹。
  • 三款共用一层 tex-card：1px outline + 上暗下亮压印 + 160° 对角微光，让纹理「贴」在纸上而不是印在纸上。

纹理的硬约束

  • 全部用 var(--tex1/--tex2/--texDot)，亮档 ink 系 9%–16%，暗档 3.5%–6.5%。不超过 18%，否则正文开始发灰。
  • 纹理只出现在卡片内部，页面底色永远干净 —— 满屏纹理等于没有纹理。
  • 一张卡只用一款。个人身份卡不铺纹理（它已经有压印 + 折角，再压纹只会脏）；教务盒=格、校园盒=十、收藏盒=织、资讯正文=十。
  • 正文卡（资讯详情）必须用 十：30px 格 + 3.5% 透明度，段落行距 1.92 时纹线落在行间。
  • Compose 落点：新建 ui/kit/PaperTexture.kt，enum PaperTex { WEAVE, GRID, CROSS } + Modifier.paperTexture(tex, dark)，内部走 drawBehind 画线（一格 4 条 drawLine，一屏约 180 次，缓存 Path 后与纯色底同价）。

设置页分区

  • 结构：secttitle(9sp / inkFaint / 字距 .20em / 上距 22dp) → sbox(1px outline / 4dp 圆角 / 上暗下亮压印) → 行间 1px 线。
  • 区间隔：22dp 空白 + 无横线（横线在 box 内部）。原来用横线分段，是因为没有 box；现在 box 本身就是分隔。
  • 行的右侧统一「值 + ›」两段式：值 11.5sp inkFaint，箭头 12sp。分段控件（明暗三档）直接嵌在行里，不另起一行。
  • 危险项（清除所有数据）只改字色为 --seal，不加图标不加说明句。

资讯 · 底部灰度分割

  • 摘要文字底部套 mask-image: linear-gradient(to bottom, #000 46%, rgba(0,0,0,.12) 88%, transparent) —— 字是被吃掉的，不是被盖住的，所以滚动时不会有色块跳动。
  • 摘要下面 26dp 的 .cut：透明 → paper 62% 的竖直渐变。
  • 分割线：96dp 内 1px rule@55%，两端各 18% 渐隐到透明 —— 线只在中段存在，像纸上的一道压痕。
  • Compose：Modifier.drawWithContent 里 drawContent() 后用 drawRect(Brush.verticalGradient(Transparent → paper))；文字遮罩用 BlendMode.DstIn 叠一层同向渐变。

考试轴 · 对齐与「不隔离」

  • 一条轴走到底：去掉 ExamBucket.PAST 的分组头与折叠，已考完的按时间正序留在原位，整卡 alpha .55（现在也这样）。轴不再被 Header 打断。
  • 轴仍然按行内画（每行画自己那一段），因为 Lazy 行高不定；连续性靠「行顶 0 → 行底 height」无缝拼接，与现在一致。
  • 节点圆心恒等于 gap + DateLine/2，与日期行中线重合；gap 只影响行顶留白，不影响 x，所以横向永不偏移。
  • 「可以自由移动」：进页面时 rememberLazyListState(initialFirstVisibleItemIndex = 下一场所在行) —— 首屏直接停在下一场，往上滑是已经考完的，往下滑是更远的。
  • 今天/本周/更远的 Header 也去掉：只剩一条轴 + 「现在」三角。当天的卡用 1.5px 墨边 + 呼吸光晕区分。

个人卡 · 展开与收起是一套时序的镜像

段展开收起
卡片高度0 → 520ms，cubic-bezier(.22,.9,.24,1)，末端略微过冲100 → 520ms，cubic-bezier(.4,0,.2,1)，加速、无过冲
明细文字150 → 450ms 淡入，同时 +10dp → 0 归位（130ms 起 420ms）0 → 100ms 淡出并退回 +10dp，退净即离场
右上折角60 → 240ms 淡出340 → 520ms 浮现
总时长520ms520ms
  • 展开：纸先长 —— animateContentSize 520ms、cubic-bezier(.22,.9,.24,1) 带一点过冲；明细延迟 150ms 起淡入 300ms，同时从 +10dp 上移归位（130ms 起 420ms）。折角 60ms 后 180ms 退出。
  • 收起：字先退 —— 明细 100ms 内淡出并退回 +10dp（不留残余）；纸再 420ms 收拢，曲线换成 cubic-bezier(.4,0,.2,1)（加速、无过冲，一口气收干净）；折角等纸收到 340ms 才用 180ms 浮现，不在收拢中途闪。
  • 两侧总时长都落在 520ms，来回节奏一致。收起时先让字退净、再收纸，两段各管一段、互不重叠 —— 这就是「干净」的来源。
  • 点一下卡片看：卡面高度变化全程无跳帧，收起结束时不留半行字、不留空隙。
