# 课表卡片自定义页：13 条轴的可用性审阅（2026-11-28）

审阅对象：设置 → 课程表卡片（`ui/settings/CourseCardSettingsScreen.kt`、`TtPreview.kt`、`TtSample.kt`）
与渲染层（`ui/timetable/TtCell.kt`、`TtPreset.kt`）。
目的：主人问「每个部件能不能自由组合、预览是否完整直观、预设只留两套」。

## 一、结论

| 问题 | 判定 |
|---|---|
| 13 条轴是否都能单独改 | 能。每条轴 2–7 档，改一条只动一条；`setTtOverride` 逐条写盘，磁盘与内存同一次改完 |
| 组合冲突是否可见 | 可见。会被 `sanitize` 改掉的取值在胶片里画灰并禁点（`OptionChip` 的 `dis`） |
| 预览是否完整 | 基本完整，**有两处缺口**（见第四节） |
| 预览是否直观 | 修了侵蚀轴之后直观；缩放按 393dp 等比压，形状不失真 |
| 预设 | 收成两套：**硬朗**（最初的农业主题）/ **账本** |

## 二、13 条轴逐条

| 轴 | 档位 | 预览里能不能看出 | 备注 |
|---|---|---|---|
| 形状 | 方卡 / 便签 / 细线 / 色块 / 标签 / **硬卡**（新） | 能 | 硬卡 = 0 圆角 + 2dp 实边（原件就是 RectangleShape，见 commit 587ac60 的 TimetableScreen），硬朗农业的正身 |
| 装饰 | 无 / 左脊 / 顶帽 / 角点 / 底线 / 淡底 / 斜纹 | 能 | 细线框把淡底、斜纹吃掉（sanitize） |
| 信息量 | 三行 / 同行 / 底栏 / 只课名 | 能 | 只课名时教室行不画 |
| 角标 | 无 / 折角 / 斜纹带 | 能 | 斜纹带会吃掉第二行 → 强制只课名 |
| 侵蚀 | 不褪 / 上褪 / 斜线 / 整块淡 | **修好后才看得出** | 原来 `progress = 0f`，三档一模一样 |
| 呼吸 | 关 / 呼吸 / 褪色呼吸 | 能（会一直动） | 预览里也跑动画 |
| 底色 | 四色 / 单墨 / 无色 | 能 | 单墨要靠蓝家族样张才分得出 |
| 页头 | 紧凑 / 标准 / 舒展 | 能 | 改的是预览的表头高度 |
| 行高 | 紧凑 / 标准 / 宽松 | 能 | 0.88 / 1.0 / 1.12，下限 64dp |
| 底纹 | 无 / 横线 / 田垄 / 复相 / 纯色 | 能 | 田垄是硬朗的核心质感 |
| 底纹动效 | 关 / 开 | 能 | 与底纹正交，关动效不等于换纯色 |
| 超立方体 | 不显示 / 淡线 / 亮线 | 能（真转） | 预览里也跑 `MathBackdropMotion` |
| 转动逻辑 | 自由 / 跟手 / 反向 / 定格 / 正交 | 能 | 设置页没有手势，「跟手」退成自转 |

## 三、这一轮修的三个真缺陷

1. **侵蚀轴在预览里三档一样**（`TtPreview.kt`）
   `progress` 恒 0，而上褪 / 斜线 / 整块淡都按进度算 → 选哪档都不变。
   改为常量 `PREVIEW_ERODE = 0.45f`：预览不跑「小幽灵」，但侵蚀要看得见。

2. **13 格刻度恒全红**（`CourseCardSettingsScreen.kt`）
   实心判据是「覆盖位 >= 0」。可 m42 起预设写的就是显式值，覆盖位永远 >= 0 →
   十三枚点永远实心，刻度表达不了任何东西。改按「与当前预设值不同」判：
   实心 = 我改过这一条，空心 = 还是预设给的。

3. **账页的观感在设置页看不到**
   `layout`（页头质感 / 未排课行）是页面级标记，不参与格子渲染，迷你预览里没有它。
   本轮不硬塞：账本预设改用「细线框 + 竖脊单墨 + 横线格」表达，靠格子本身就能认出来，
   真机完整效果到课表页看。这条留在第四节当已知缺口。

## 四、仍存在的缺口（不装作没有）

- `layout = 1` 的页头质感与未排课行不在预览里（原因见上）。
- 三个特效开关（小幽灵 / 食物图标 / 当前课描边）只有药丸，没有样张 ——
  它们在预览里要动起来才有意义，静态样张反而误导。
- 深色模式的观感预览里看不到：预览跟随当前主题，想比就切主题再看。

## 五、预设：两套

| # | id | 名字 | 槽位 |
|---|---|---|---|
| 0 | `hard` | 硬朗 | 硬卡(5) + 左脊 + 三行 + 四色 + 田垄底纹 + 不侵蚀 + 不动 |
| 1 | `ledger` | 账本 | 细线(2) + 竖脊 + 同行 + 单墨 + 横线格 + 账页版式 + 定格 |

撤掉的三套（密排 / 日程 / 安静）：13 条轴逐条都能改，预设多了反而选不出来。

### 升级迁移（`ttSlotsVersion` 2 → 3）

老五套序号先映射：账页 `1 → 1`，其余四套 `→ 0`（`TtPresets.migrateIndex`）。
再看存下来的覆盖位是不是「原封不动等于旧预设」（`TtPresets.LEGACY_M43`）：

- **相同**（从没动过逐轴设置）→ 换成新预设的槽位，观感跟着预设走；
- **不同**（自己调过）→ 原样保留，只挪序号。

这样升级不会冲掉人手动挑的组合，也不会让「预设选中了但画面是另一套」。

## 六、验证

- 单测：`TtPresetTest` 适配两套预设、六档形状、旧序号映射；
- 真机：设置 → 课程表卡片，两枚预设各截一张，再逐条点 13 条轴看样张是否随档变化。
