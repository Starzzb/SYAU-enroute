⑪ 取舍

  1. 窄格先减线。单列 49dp、卡内净宽 40dp，一行只容得下四个半汉字。grid 每加一道竖线，卡的左右留白就被吃掉 1dp，马克思主义基本原理这类九字课名就压到三行——所以 cells 与 bands 只作为候选取值，默认落在 lines 或 air。
  2. 底纹只画在空白处。ruled / ridge / math 都落在 .p-grid 的背景层，课程卡用不透明的 --wash 覆盖其上；暗档把底纹透明度压到 22%–26%，避免线稿与课名争对比度。
  3. 轴宽是有代价的。rail 46dp + 圆牌只给 18dp 直径，圆牌内数字必须 ≤2 位；gutter 46dp 放得下 08:00/09:40 两行 8px。inline 与 none 把轴归零，七列各多出 6.6dp（≈半个汉字），代价是脱离格子就认不出第几节。
  4. nowLine 同屏只能一条。rule 用 1dp 陶土线 + 10:24 胶囊，落点在第 2 大节内 24%；band 把整两行提亮 7%；ring 只描当前课。三者同时出现会在 40dp 宽度里叠出三种强调。
