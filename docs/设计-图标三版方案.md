# 设计：图标三版方案（2026-11-20）

主人要求：**每个图标预备三个版本**，现在默认用一版，另两版留在代码里方便日后替换；方案单独成文。
本文就是那份方案。并排预览见 [`docs/design/图标三版.html`](design/图标三版.html)（Edge 无头截图可自查）。

---

## 1. 为什么是三版，不是「一个图标画三遍」

图标在三种场合的读法不一样：

| 场合 | 尺寸 | 常见背景 | 读法的关键 |
|---|---|---|---|
| 工具栏、列表行、页眉 | 16–24dp | 纸白/浅色卡片 | 笔画要够粗，缩小不糊 |
| 弹层、空态、引导 | 24–32dp | 半透明卡片、图片上 | 边界要圆润，不需要抢焦点 |
| 徽章、启动图、关于页 | 32–96dp | 深色/彩色块面 | 要有「图形感」，细线撑不住 |

一个几何画法撑不住三档，所以按**几何家族**备三版，而不是同一形状缩放三次。

## 2. 三个几何家族

| 变体（枚举） | 家族名 | 笔画 | 转角 | 视觉语气 | 默认用在哪 |
|---|---|---|---|---|---|
| `GEOMETRIC` | 折角几何 | 实心 2px 等效、方收口 | 直角/45° 折角 | 硬朗、像版面上的刻线 | **默认**。页眉、列表行、菜单 |
| `ROUND` | 圆润双线 | 1.8px 描边、圆端帽、圆角 | 圆角 | 轻、亲和 | 弹层、空态、提示 |
| `BLOCK` | 块面切割 | 整块填实，细节靠负形切 | 方角、切口 | 图形感强 | ≥28dp、徽章、关于页 |

共同约束（与 core 图标一致，避免换版时版式跳动）：

- 画布 **24×24 viewport**，`defaultWidth/Height = 24.dp`；调用点决定实际尺寸（16/19/24/32dp）
- 视觉重心留 1.5dp 安全边，笔画不出血
- 颜色一律 `Color.Black`，由 `Icon(tint = …)` 覆盖 —— **图标里不许写主题色**
- 同一符号三版的**外接尺寸一致**（例如书签都是 y=2…22），换版不会让行高变化

## 3. 本轮做的符号（7 个，各三版）

| 符号 | 语义 | 用在哪 | 备注 |
|---|---|---|---|
| `BookmarkOutline` | 收藏（未选中） | 资讯行、文章详情顶部 | 替换掉原来的「藏」字 |
| `BookmarkFilled` | 收藏（已选中） | 同上 | 填实 + 主色，点击有反馈（见 m31 规划 A4） |
| `OpenInNew` | 打开原网页 | ⋯ 菜单「来源」组、文章详情「查看原文」 | core 里没有合适的，自己画 |
| `Feedback` | 反馈/提建议 | ⋯ 菜单「想加别的网站？」、设置页 | 气泡 + 横线 |
| `Download` | 导出 | 地图编辑页常驻次按钮 | 托盘 + 下箭头 |
| `Save` | 保存（确认写入） | 地图编辑页常驻主按钮 | 软盘式，负形切出标签与内容 |
| `NetworkOff` | 校园网不可达 | `CampusNetworkHint` 提示行左侧 | 柱状信号 + 斜杠 |

历史遗留的 `Article` / `Today` / `StarBorder` / `MarkEmailUnread(Filled)` 暂时**只有一版**：
它们已经在用、观感稳定，等有新需求再补 V2/V3，避免这轮改动面过大。

## 4. 代码结构

文件：`app/src/main/java/cn/dkarbon/enroute/ui/icons/AppIcons.kt`

```kotlin
enum class IconVariant { GEOMETRIC, ROUND, BLOCK }

object IconVariants {
    @Volatile var variant: IconVariant = IconVariant.GEOMETRIC   // 全局开关，改这一行就全换
}

// 每版一个私有属性
private val BookmarkOutlineV1: ImageVector by lazy { … }   // 折角几何
private val BookmarkOutlineV2: ImageVector by lazy { … }   // 圆润双线（stroked）
private val BookmarkOutlineV3: ImageVector by lazy { … }   // 块面切割

// 对外只暴露一个名字，调用点永远不用知道是哪版
val BookmarkOutline: ImageVector
    get() = when (IconVariants.variant) { … }
```

- **调用点规矩**：只写 `AppIcons.BookmarkOutline`，绝不直接引用 `BookmarkOutlineV2`。
  这样换版只改 `IconVariants.variant` 一行（或一处常量）。
- 三版并排调试：`AppIcons.variantOf(IconSymbol.BookmarkFilled, IconVariant.BLOCK)` +
  `enum class IconSymbol`（7 个符号），给设计对照页与将来的「图标实验」设置项用。
- 描边版走 `stroked(name, width, vararg paths)`：只给 stroke，不给 fill，端帽/连接都圆。
- 填实/挖空版走 `vector(name, vararg paths)`：**挖空必须外框与内框写在同一条 path 里**并标 `PathFillType.EvenOdd`。

## 5. 画法与坑（这轮踩到的，写下来免得再犯）

1. **挖空不能分两条 path 画。**
   `vector()` 每给一条 path 就 `addPath` 一次，外框一条、内框一条时，内框会被当成实心填上，
   预览里就是「实心方块中间一小块白」。必须：
   ```
   "M4 3H20V21H4ZM6.4 5.4H13.6V10H6.4ZM6.4 13H17.6V18.6H6.4Z"  to PathFillType.EvenOdd
   ```
2. **加法细节别压到挖空区上。** 例如 OpenInNew 的箭嘴如果和边框大面积重叠，union 之后就是一团墨；
   箭嘴要么明确跨边（经典画法），要么完整落在框内，不能半压不压。
3. **描边版别用 1.5px 以下。** 19dp 显示时 1.6px 就开始发灰；1.8px 是经验下限。
4. **块面版忌讳细缝。** V3 书签中间那道 1.8px 竖缝，在 20px 尺寸下会被读成「两片书签」——
   所以 V3 只在 ≥28dp 用。
5. **预览页与代码必须同源。** 预览 HTML 里的 `d="…"` 要和 Kotlin 的字符串一字不差；
   这轮就因为两边不同步，预览先对了、代码还是错的。改动时两个文件一起改，改完重新截图对一遍。

## 6. 验收

- [ ] `docs/design/图标三版.html` 用 Edge 无头截图，7 个符号 × 3 版全部成形、无实心坨、无缺口毛刺
- [ ] 同一符号三版外接尺寸一致（书签 y=2…22；网络 y=3.2…21.8 等）
- [ ] `:app:compileDebugKotlin` 通过、全量单测不回归
- [ ] 真机 24dp / 19dp 两档目视：折角版不糊、圆润版不虚、块面版不裂
- [ ] 换版只需改 `IconVariants.variant` 一处（自查：grep 一遍有没有人直接引用 `…V2`/`…V3`）

## 7. 换版与新增的操作顺序

**换某一符号的版本**（例如觉得书签 V2 更好）：
1. 打开 `docs/design/图标三版.html` 对照确认；
2. 改 `IconVariants.variant`（全局）或在调用处显式 `variantOf(IconSymbol.BookmarkOutline, IconVariant.ROUND)`（局部）；
3. 真机看 19dp/24dp 两档，别只看预览页的 40px。

**新增一个符号**：
1. 先确认 `material-icons-core` 里真的没有（`Icons.Outlined.*` 里 `Close`、`Search` 都有，别想当然重画）；
2. 画 V1/V2/V3 三条数据，外接尺寸对齐现有符号；
3. 加成 `private val XxxV1/V2/V3` + 对外 `val Xxx: ImageVector get() = when(…)`；
4. 加进 `IconSymbol` 与 `variantOf()`，预览页补三列；
5. 走 §6 验收。
