主人这一轮提了十处改动，横跨资讯、更新、考试、关于、地图五个页面。本文按「一条需求 → 一处改动 → 落在哪个文件 → 怎么验收」拆开，
先分条归纳，再分配任务，最后给不遗漏核对表。

原则沿用 AGENTS.md：
- **看得见的效果先出 HTML 原型**（`docs/design/`），确认后再写进 App；
- 数据层、解析器、缓存策略、文案调整**不用原型**，直接写代码 + 单测；
- 界面里不写说明书文字（「轻点展开」「点击查看」一律不许）。

## 1. 资讯页（轨道 A）

### A1 头部收纳：只动页眉，不动正文；下滑才回

现状（`ui/feed/FeedScreen.kt`）：
- 页眉、搜索行、截止行、失败行、频道筛选装在同一个 `AnimatedVisibility(visible = !headerHidden)` 竖直收放块里（第 245-255 行），
  收起时**整块高度塌缩**，列表跟着上移 —— 这就是主人说的「主体内容移动」。
- 第 228-238 行有一段 `delay(1200)` 静止后自动 `headerHidden = false` 的逻辑 —— 就是主人说的「静止不动就还原」。

改成：
1. 页眉层改为**浮层**（`Box` 里先 `LazyColumn`，页眉 `Modifier.align(TopStart)` 叠在上面），
   列表 `contentPadding.top` 预留页眉高度 —— 页眉位移不再挤动列表。
2. 收起动画只走 `graphicsLayer { translationY = -h * p; alpha = 1 - p }`，全程不触发布局。
3. 判定：用 `LazyListState.isScrollInProgress + firstVisibleItemScrollOffset` 的增量
   - 向上滚（内容下行、offset 增大）→ 收；
   - **向下滚（offset 减小）且 `firstVisibleItemIndex == 0`** → 放；
   - 列表已经滚下来时下滑，先让内容回顶，到顶后继续下滑才放出页眉（第二次下滑放页眉）。
4. 删掉 `delay(1200)` 那三行；`headerHidden` 不再有任何定时复位。
5. 页眉收起时留 1dp 露出一条边（AGENTS「内容被截断/露出边」的表达手段），不写「下滑可见」。

验收：列表滚到第 30 条 → 页眉不见但**第一条条目位置不动**；把手指往下拉，内容不动、页眉滑出；静止 10 秒仍不自动弹回。

### A2 页眉内容重排：一行放得下，其余全进「⋯」

目标结构（只两行，第二行是搜索行）：

```
行1：资讯            [搜索图标]  [⋯]
行2：搜索框（点搜索图标才展开，展开后常驻到失焦）
行3：频道筛选（保留）
```

- 删掉「查」字按钮（第 202-205 行注释与实现一起），改成 24dp 矢量放大镜，点击只做一件事：聚焦搜索框。
- 删掉 `SourceNoteBar`（第 1456-1495 行）整条 —— 「条目摘自校内公开页面」没有了。
- 页头「⋯」菜单（第 1133-1160 行）重排为分组：

| 组 | 项 |
|---|---|
| 动作 | 刷新、全部频道全部已读、只看收藏（图标态） |
| 来源 | **预设站点**（列出每个源的名字 + 最近一次抓取状态 + 「在浏览器打开」） |
| 来源 | **想加别的网站？** → 打开仓库 issues，标题预填 `[新增来源] 网站名 网址` |

- 「源站」「反馈」两个文字按钮并入上表「来源」组，页眉不再单列一行。
- 预设站点清单要从数据层取：`FeedRepository`/`FeedModels` 里的源定义暴露成
  `data class FeedSource(name, url, note)` 列表给 UI（当前只在前端写死常量 `SOURCE_PAGE`，要改成读源清单，避免两处不一致）。

验收：页眉只剩「资讯 + 搜索图标 + ⋯」；菜单里能看到全部预设站点与各自状态；点「想加别的网站」跳到 issues 且标题已预填。

### A3 文章详情页「藏」→ 矢量图标

现状：详情页顶部与列表行都用文字「藏」做收藏开关（`FeedScreen.kt:1227`、`:1218` 注释）。
改成：
- `ui/icons/AppIcons.kt` 新增两个自绘图标（24dp / viewport 24×24，颜色交给 tint）：
  `BookmarkOutline`（右上缺角的书签）与 `BookmarkFilled`（同形状填实）。
- 详情页顶部换成这对图标，**去掉「藏」字**；列表行的收藏标沿用同一对图标，保证两处语义一致。
- 图标形状可参考常见书签式样（主人明确说不用管版权）——画在 AppIcons 里就是自有资源。

### A4 收藏的点击反馈

- 状态：未收藏 = 描边 + `t.inkSoft`；已收藏 = 填实 + `t.primary`（现有逻辑保留）。
- 反馈（三拍，共 260ms）：
  1. 图标 `scale` 1 → 1.28（`spring(dampingRatio = Medium)`）；
  2. 一圈 8dp→26dp 的描边圆环同时淡出（`alpha 0.5 → 0`）；
  3. 整行背景一次 4% 主色闪（120ms 进、140ms 出）。
- 取消收藏：同款反向（scale 0.86），不掉帧、不复位滚动位置。
- `reducedMotion`（系统关动画）时只做颜色切换，不缩放不闪。

## 4. 考试安排（轨道 D，需要原型）

文件：`ui/academic/ExamScreen.kt`（477 行，现有 `NextUpCard` / `BucketHeader` / `TimelineRow` / `ExamCard`）。

### D1 卡片重设计
- 边缘高亮三态：
  - **已过去**：1dp 灰描边、内容降到 55% 不透明；
  - **下一场**：1dp 主色描边 + 外发光（`blur` 模拟 8dp 光晕）；
  - **未到（更远）**：1dp 常规描边。
- 呼吸动效：下一场卡片 `scale 1 → 1.012 → 1`、光晕 alpha `0.35 → 0.6 → 0.35`，周期 3.2s，`infiniteRepeatable`；
  系统关动画时静止。
- 卡片内容：课名（15sp 粗） / 时间（`MM-dd HH:mm–HH:mm`） / 地点 / 座位号（有则显示），右侧留一个「还有 3 天」的小字。

### D2 时间轴
- 竖直轴在左侧 28dp 处，节点 = 每场考试；
- **自己的位置**：轴上一个「当前时刻」标记（小三角 + 细线），随真实时间落在两场考试之间；
- 节点状态：已过 = 空心灰点；下一场 = 实心主色点 + 呼吸光晕；更远 = 空心常规；
- 轴上方加**LED 跑马灯**：一粒 3dp 光点从「当前时刻」向下滚到「下一场」节点，到点闪一下再回到当前时刻，循环（周期按剩余天数的对数缩放，最短 4s、最长 12s）；
- 已考的历史折叠在「历史（3 场）」组里，展开可翻看；展开时对应节点**点亮**（主色描边 + 60% 填充），与卡片状态同步。

### D3 验收
- 考试页在任何滚动位置都不掉帧（`gfxinfo` 掉帧率 < 2%）；
- 时间轴节点与卡片状态一一对应（同一条数据，不允许两处各自算）；
- 关掉系统动画后只剩静态状态色。

原型要先把四种状态并排画出来（已过 / 下一场 / 更远 / 历史展开）。

## 5. 关于页（轨道 E，需要原型）

文件：`ui/about/AboutScreen.kt`（286 行）＋ `ui/common/Tesseract4D.kt`（180 行）。

### E1 卡片透出背景
- `AboutCard` 底色从实色改半透明：亮色 `surface.copy(alpha = 0.62f)`、暗色 `0.58f`，描边保留；
- 卡片阴影减一档，让超立方体动画在卡片后面可见；
- 正文对比度自检：半透明底上的 `ink` 与底图最亮处的对比度仍 ≥ 4.5:1（取 Tesseract 顶点最亮色算）。

### E2 速度不固定
- 现状是匀速 `animateFloat(infiniteRepeatable)`；改为**自驱相位**：
  ```kotlin
  // 每帧推进相位，速度随两个低频正弦叠加 —— 转起来像有人用手拨
  val speed = base * (1f + 0.55f * sin(t * 0.17f) + 0.25f * sin(t * 0.53f + 1.1f))
  phase += speed * dt
  ```
- 视觉目标：慢 → 渐快 → 最快速持续 1-2 秒 → 回落，周期约 20-30 秒，不出现突变跳步。
- 关动画时停在固定姿态（不是空白）。

### E3 实现来源
主人允许直接找现成实现。做法：先 `web_search` 找 4D 旋转矩阵 / 超立方体投影的公开实现（POV-Ray / shadertoy / processing 版本），
把**数学部分**（16 顶点、6 个旋转平面、透视投影）搬成 Kotlin，渲染仍用 Compose `Canvas`，不引入新依赖。

## 6. 地图共建编辑页（轨道 F，需要原型）

文件：`ui/map/CampusMapScreen.kt`（1162 行，编辑浮层在第 846-1100 行一带）＋ `data/map/MapEdits.kt`。

### F1 可上下拉动的浮层
- 从固定高度改成三档 draggable sheet：**30% / 62% / 92%**，拖动跟手，松手就近吸附；
- 内容与拖动冲突：内容滚到顶再继续下拉才缩，滚到底再上推才涨（nested scroll）；

### F2 「添加字段」到底是什么（要 redesign 并说清）
现状第 941-946 行：`＋ 添加字段` → 弹窗「添加字段」，用同名列覆盖官方值。
改成**两层**，语义分开：
1. **分类（类别）**：从 `manifest.kindOptions()` 里选，是「这个图块属于哪一类」，改的是 `kind`；
2. **自定义字段**：键 + 值，是「这一类之外你额外想记的事」（如 `楼号=A3`、`有饮水机=是`），
   只存在 `edits.json`，不改官方数据；
   面板里给 3 个常用键的快捷片（`楼号` / `层数` / `备注`），其余自由输入；
   与官方同名的键会覆盖显示（现有规则保留），面板上直接标 `覆盖官方值`。
- 文案里不写操作说明，用分组标题 + 示例值表达：「分类：请选择」/「自定义字段：楼号 | 层数 | 备注 | 自定义」。
- 单测：`MapEdits` 增加一条「自定义键与官方键同名 → 用户值优先，导出时带 label 前缀」的用例。

### F3 保存 / 导出
- 底部两个按钮**常驻**：左 `导出`（次），右 `保存`（主）—— 保存才是确认动作；
- 点 `保存`：写入 `edits.json`，按钮短暂变「已保存 · HH:mm」，不弹窗；
- 点 `导出`：先落盘再弹一行感谢：`谢谢，这份标注会帮到后来的人`（一次性，2.5s 后淡出，不阻塞）；
- 导出仍然走现有 `ACTION_CREATE_DOCUMENT`（GeoJSON / CSV），上传开关行为不变。
