配色：水墨（StyleKit ink-wash）

宣纸打底，墨色分层，苔绿/赭石/米/青灰做低饱和强调。旧主题的农械橘与硬投影退出。
墨 Primary#2C2C2C
宣纸#F8F5F0
苔#6B7B6E
赭#A89279
米#C4B9A8
青灰#697A7C
旧朱印#8F4A3A
夜墨底#191713
  • 不用鲜艳饱和色；强调色只出现在极小的面积上（选中下划线、圆点、印章）。
  • 不用厚重阴影；层次靠 1px 细线、纸的第二层与留白。
  • 线宽收在 1–1.5px，像毛笔细线；折角与缝线是唯一的「硬」形状。

主题：从三套并存活到一套

按本次指令收拾主题系统。
舍弃三套 FormSpec 里的第二套 SCHOLAR。它靠衬线正文与行斑马线，和水墨的留白气质冲突。
合并HARD 的 0 圆角结构留下，配色换成墨；EDITORIAL 的留白与细线口径留下。合成一套 FormSpec.Ink。
移除设置里的「主题风格」入口与 styleSet 读写；EnRouteTheme 固定单套，仅保留明暗。
// Theme.kt（目标形态）
enum class StyleSet { INK }          // 只留一套
FormSpec.Ink = FormSpec(
  radiusCard = 4.dp, radiusSheet = 4.dp,
  ruleWidth = 1.dp, shadowRadius = 0.dp,
  paperTexture = true,                // 极轻纸纹，alpha ≤ .04
  shapes = ShapeSet.Ink,
)
InkTokenSet.Light = InkTokenSet(
  paper = #F8F5F0, card = #FCFAF6, cardAlt = #F1ECE3,
  ink = #2C2C2C, inkSoft = #4A4A46, inkFaint = #6E6C66,
  rule = #DBD5C9, outline = #BDB6A7,
  olive = #6B7B6E, amber = #A89279, slate = #697A7C,
  primary = #2C2C2C, accent = #A89279,
  hardShadow = #2C2C2C,
)

翻卡：动效参数

原来看起来像「展开面板」，现在改成真的向下翻页：封面绕上沿转出去，信息从缝里升起来。
阶段时长 / 曲线变化
起手0–120 ms · cubic-bezier(.18,.86,.22,1.03)卡片高度开始长；封面阴影加深到 22dp
翻落0–640 ms · 同上，带 1.03 的轻微过冲rotationX 0 → −168°；到 90° 时影子最重
让位300 ms · linear封面淡出（opacity 1 → 0），缝线留在原处
信息140 ms 后启动 · 420 ms正文 translateY 8 → 0、透明度 0 → 1；行序不动
收拢反向 420 ms信息先退、封面回位；不播过冲，收得干净
点卡片任意处开合；返回键先收卡片（BackHandler），再退页面。
