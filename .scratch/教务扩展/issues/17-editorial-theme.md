# 17: 第二套主题「校报头版（Editorial）」——放开旧红线

**What to build:** 在现有两套 `StyleSet`（`HARD` 硬朗农业 / `SCHOLAR` 学院纸本，二者只差配色）之外，
新增**第三套结构级不同的主题**：`EDITORIAL`。

主人 2026-11-14 原话：
> 「同时也可以着手开发另一套主题了，**不必拘泥之前的红线**」

即：0 圆角、禁渐变/阴影/纹理、单字号阶梯这些旧约束**本主题内不再适用**。
但「数据诚实」「对比度达标」「交互可达」三条**依然不可破**。

**Blocked by:** 无（`docs/评审-前端设计方案-v3.md` §5 已有完整规格）

**Status:** ready-for-agent

## 设计依据

完整规格在 `docs/评审-前端设计方案-v3.md` **§5 方向 B：校报头版（Editorial）**，
本票只补充「实现约束」与「落地顺序」。规格要点（照 v3 执行，不要另创）：

- **布局骨架**：单栏长读 + 规则线分区，**不用卡片容器**；标题区像报纸头版（刊头 + 日期线 + 主标题）
- **组件形态**：行与行之间用 1–2dp 横线分节，靠**留白与字重**承担层级，而非边框/底色
- **字体**：标题用**衬线**（中文思源宋体/Noto Serif SC 一类），正文保持无衬线；
  数字改回非等宽的衬线数字（与 `HARD` 的 IBM Plex Mono 形成鲜明对比）
- **允许使用**：较大的字距、首字下沉、栏宽约束、轻微纸张纹理/暖色渐变底、
  圆角（本主题可选小圆角）、**低强度阴影仅用于"纸张浮动"语义**（不得用于每个卡片）
- **禁止**：为了好看而编数据、把「暂缺」藏起来、降低对比度到 4.5:1 以下

## 实现约束（关键：不要再做"只换配色"的主题）

第三套主题必须在**这三层**与现有两套不同，否则等于没做：

| 层 | 要求 |
|---|---|
| **布局变体** | 允许 `StyleSet` 携带「是否使用卡片容器」开关；Editorial 下卡片退化为"分节 + 规则线" |
| **排版系统** | 独立的字族/字号阶梯/行高/字距；`NumericFont` 在本主题下可切衬线数字 |
| **形态 token** | 圆角半径、阴影强度、描边粗细、底纹/渐变——新增字段，且 `HARD`/`SCHOLAR` 下取值保持现状（零回归） |

`Theme.kt` 里 `StyleSet` 枚举加 `EDITORIAL`；设置页「风格」三项可选。
**两套老主题的渲染结果必须逐像素不变**（有回归测试或真机截图对比）。

## 落地顺序（每一步可独立回退）

1. **token 与主题层**：新增 `EditorialTokens.kt`（实现 `InkTokenSet`）、扩展形态字段、
   `StyleSet.EDITORIAL` 接线、设置页选项。此时界面无变化（只是能选中）
2. **一个页面做样板**：`ui/timetable/`（课表）——它是全 App 最"表格化"的页面，
   最能暴露「去卡片化」是否成立。做完截图给主人看
3. 主人确认后再推：`我的`（等票 16 落地后）→ 资讯流 → 考试/成绩 → 培养方案/大纲
4. 收尾：对比度自测表、性能（滚动帧率不退化）、深色变体

- [ ] 设置页能切到第三套，切换即时生效、重启后保持
- [ ] 课表页在 Editorial 下**没有卡片容器**，用规则线与留白分区；标题为衬线
- [ ] 与 `HARD` 并排截图，**不是"同一版式的两套配色"**（评审会按这条判失败）
- [ ] 对比度全部实测达标（正文 ≥4.5:1、大字 ≥3:1），把实测值写进票底
