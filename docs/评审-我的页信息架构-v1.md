## 0. 结论（先看这段）

| # | 结论 |
|---|---|
| 1 | 现状不是「入口太多」，是**同一件事有三个入口、而真正常用的那件事在 1.6 屏下方**。经逐块加总：本页总高 **≈1180dp（≈1.7 屏）**，`空闲教室` 位于 **scrollY ≈ 1095dp**，与 `设置`、`查教师` 同级同权。 |
| 2 | 三条重复必须消除：**登录态出现 3 处**（身份卡 / 本机数据 / 教务首行）、**设置出现 2 处**（右上齿轮 + 教务末行）、**考试 / 成绩 / 培养方案各出现 2 处**（卡片一次 + NavRow 一次）。 |
| 3 | 给出三套方案：**一「三段式 + 工具抽屉」**（保守）、**二「学业磁贴 2 列 + 工具行」**（主推）、**三「手风琴」**（极简上限）。三套都在**分层规则**上与现状不同，不是换配色。 |
| 4 | **推荐方案二**：首屏内同时命中「下一场考试 / 培养方案学分 / 加权绩点 / 空闲教室」四件，全页从 1.7 屏压到 **≈1.17 屏**，高频入口 0 次滚动、1 次点击。 |
| 5 | 三套方案**不动数据层**（`AppState` / `TimetableViewModel` / `HomeModel` 一行不改），因此数据诚实条款（`—` 不填 0、分母缺失不画条、绩点缺失说「暂缺」、三态不合并）**自动继承**。 |
| 6 | 顺带修掉一处事实错误：**校园地图的主入口不该在「我的」**——它的真实起点是「我要去上课的那间教室」，应该在课表/课程详情页；「我的」只留次级入口。这一条写进方案一/二/三都成立。 |

App 内**无埋点、不上报**（合规红线），所以下面的频率是**场景推演**，不是测出来的。落地时建议在 debug 变体里本地记录「我的」页内的点击序列（只存本机、可一键清空、release 关闭），两周后回来核对这张表——如果「课程大纲」的实际点击高于「校园地图」，分组要跟着数据改，别跟我的推演改。

| 入口 | 频次（推演） | 峰值场景 | 判级 |
|---|---|---|---|
| 空闲教室 | 每周 3–5 次 | 自习/找空教室 | **日频** |
| 下一场考试 | 考前两周每天 | 考试周 | **周期峰值** |
| 校园地图 | 开学 2 周每天，之后每月 1–2 次 | 找楼/报到 | **开学季高频** |
| 成绩查询 | 出分期 1–2 周内 5–10 次，其余 0 | 学期末 | **脉冲** |
| 考试安排（列表） | 每学期 3–6 次 | 考前 | 低频 |
| 课程大纲 | 每学期 3–8 次 | 开学/查考核方式 | 低频 |
| 查教师 | 每学期 2–5 次 | 选课前/答疑 | 低频 |
| 培养方案 | 每学期 1–2 次 | 选课/学期初 | 低频 |
| 历年课表 | 每学期 0–2 次 | 学期初 | 极低频 |
| 设置 | 每学期 0–2 次 | 换主题/清数据 | 极低频 |
| 登录 / 续期 | 触发式，学期 1–3 次 | 会话过期 | 触发式 |
| 本机数据 | 仅故障时 | 排障 | 诊断 |

**判级口径**：「日频」= 一周 ≥3 次，必须首屏且 0 滚；「脉冲」= 短窗口内爆发，用**卡片数字**承载，不额外占入口；「低频/极低频」= 允许 ≥1 次点击 + 折叠。

## 2. 三套方案共用的六条分组规则（先定规则，再定布局）

规则必须是**可判定**的（拿到一个新入口，能直接算出它归哪一层），否则半年后又会长回平铺。

| 规则 | 内容 | 判定问题（只问这一句） |
|---|---|---|
| **R1 数据即入口** | 首屏已经展示其**数值**的对象，那张卡/格**本身就是唯一入口**，下方列表不得重复出现同名项 | 「这件事的数字是不是已经在屏幕上了？」→ 是 → 不加 NavRow |
| **R2 唯一真相** | 同一状态只在一处显示，且那一处是**权威位置** | 「这个状态在别处已经有权威显示了吗？」→ 有 → 本页删 |
| **R3 时间优先** | 含日期 / 倒计时 / 「今天就变」的信息，永远在静止数据之上 | 「这条会自己变吗？」→ 会 → 第一层 |
| **R4 日频提权** | 不含日期但**一周 ≥3 次**的工具，允许越过 R3 直升第一层（唯一例外：空闲教室） | 「一周用几次？」→ ≥3 → 第一层 |
| **R5 危险隔离** | 不可逆 / 涉及凭据 / 排障的动作（清数据、保持登录、调试、写密码）**不得与日常入口同屏**，一律进设置页 | 「按错了会丢东西吗？」→ 会 → 设置页 |
| **R6 诊断折叠** | 纯排障信息默认收起，需要时一次展开，离开即收 | 「用户只在出问题时才看吗？」→ 是 → 折叠 |

**由此得到的页面骨架（三套方案共用同一套归属，只是形态不同）**：

```
L0 身份（常驻，非分组）  身份卡 / 三态 / 续期
L1 现在（第一层）        下一场考试 · 空闲教室                ← R3 + R4
L2 学业（第二层）        培养方案学分 · 成绩概览（绩点/通过）  ← 卡片即入口（R1）
L3 工具（第三层，折叠）  校园地图 · 查教师 · 课程大纲 · 历年课表
L4 本机（第三层，折叠）  课表门数 · 周次 · 提醒 · 登录态        ← R6
L5 设置（右上齿轮，唯一）外观 / 提醒 / 数据 / 保持登录 / 清除 / 调试 / 关于
```

### 2.1 入口归属表（13 个现网入口 + 3 个条件项，一张表说清）

| 入口 | 现状位置 | 新归属 | 归属理由（引用规则） |
|---|---|---|---|
| 身份卡（姓名/班级/专业/年级/学号/院系/层次/入学） | 首屏第 2 段 | **L0 常驻** | 它是页面的「标题替代」（底栏已写「我的」，所以页内不重复标题），同时承担三态登录入口，是唯一身份真相 |
| 会话过期提示行 | 身份卡下方独立行 | **并入身份卡内部**一行附注 | R2：与 `identitySubtitle` 说的是同一件事；合并后砖红文案 + 内联「续期登录」仍保留（`SessionText` 的三态文案一字不改） |
| 登录 / 续期（教务首行 NavRow） | 教务组第 1 行（条件） | **删除**，只由身份卡承担 | R1 + R2：身份卡在 `None/Expired` 态整张可点（`identityClickable`），功能不丢，重复去掉 |
| 下一场考试（卡片） | 首屏第 4 段 | **L1** | R3：唯一含倒计时、唯一「今天就变」的数据 |

| 成绩概览（卡片） | 首屏第 6 段 | **L2** | 脉冲数据，用「加权绩点 3.42 / 通过 55 门」两个数字承载；出分期就是入口本身 |

| 培养方案学分（卡片） | 首屏第 5 段 | **L2** | 低频但要「一眼看到差多少」；卡内有条 + 还差 N 学分，本来就是入口 |
| 培养方案（NavRow） | 教务第 4 行 | **删除**，由学分卡承担 | R1 |
| **空闲教室** | 教务第 8 行（1.57 屏） | **L1（提权）** | R4：一周 3–5 次，是全页最高频入口，必须 0 滚可达；含「第 N 节 · M 间」动态数字，也满足 R3 的一半 |

| 查教师 | 教务第 9 行 | **L3** | 低频（每学期 2–5 次），无日期，不属于「现在」 |
| 课程大纲 | 教务第 5 行 | **L3** | 低频（开学一次性），166 门索引靠搜索进，不适合占首屏 |
| 历年课表 | 教务第 6 行 | **L3** | 每学期 0–2 次 |
| 设置 | 齿轮 + 教务第 10 行（两处） | **只留右上齿轮**（唯一入口） | R5 + R2：设置里有「清除所有数据」这类不可逆动作，绝不与日常入口同权同高 |
| 本机数据：课表门数 | 本机数据第 1 行 | **删除**（设置页已有「已载入 N 门课」） | R2 |
| 本机数据：周次 | 本机数据第 2 行 | **L4 折叠**（保留「未校准」提示） | R6：唯一没有别处权威显示的一条，降级但不丢 |
| 本机数据：上课提醒 | 本机数据第 3 行 | **删除**（设置页已有开关） | R2 |
| 本机数据：登录态 | 本机数据第 4 行 | **删除**（身份卡三态 + 设置页 `settingsLine`） | R2 / D-1 |
| 刷新按钮 | 顶条右侧文字按钮 | **保留**（方案一/二原样；方案三挪到「现在」折叠头右侧） | 现网用 `verticalScroll` 无下拉刷新，按钮是唯一手动刷新动作，删了会丢掉「抓空了要重试」的出口 |

**净结果**：13 个入口 + 3 个条件项 → 屏上元素从 **17 段**降到 **12 段**，重复入口 **6 处归零**，页内总高 1.70 屏 → 方案一 1.32 屏 / 方案二 1.17 屏 / 方案三 1.00 屏。

## 3. 方案一：三段式 + 工具抽屉（保守，最小改动）

**定位**：不改列的个数，只改**分层的表达**——把「平铺的两张 4 行/10 行卡片」拆成「三层 + 一个可收起的抽屉」。骨架仍是单列 `Column`，与现网代码结构一一对应，最容易落、最容易回退。

### 3.3 分组与折叠

- 三个区标题（现在 / 学业 / 工具）+ 一个抽屉尾（本机状态），全部沿用现网 `SectionLabel` 的视觉（11sp、`inkFaint`、字距 +0.5），只是加了内容与顺序。
- 「工具」默认**收起**，抽屉头右侧显示四项名单摘要（静态词，不含数字，因此不存在空值说谎问题）。
- 「本机状态」默认**收起**，展开是 4 行只读（复用现网 `StatRow`）。

### 3.4 入口归属

完全执行 §2.1，无差异。特别地：
- 考试/成绩/培养方案三条 NavRow 被删，卡片即入口（R1）。
- 登录 NavRow 被删，身份卡承担（R1/R2）。
- 设置 NavRow 被删，只留齿轮（R5）。
- 校园地图**降级**到抽屉内第 1 行，并在课表页补一个「去地图」的次级入口（另一张票）。

### 3.5 手势 / 展开态

| 场景 | 规格 |
|---|---|
| 点卡片 / 条目 | 走现网 `stack`（`mutableStateListOf<UserPage>`），`BackHandler` 已就绪，返回即 pop |
| 抽屉展开 | 点 48dp 抽屉头 → `animateDpAsState(180ms)` 高度过渡（`Motion.base`）；箭头 ▾/▸ 旋转 180°（120ms） |
| 抽屉记忆 | `rememberSaveable` 记「工具 / 本机」各自的展开布尔；**切 tab 回来保持**，冷启动回到默认（全收起） |
| 长按 | **不新增长按**。理由：全 App 只有课表格有长按菜单（`CourseQuickActions`），「我的」页新增长按会变成隐藏功能，可发现性为 0 |
| 下拉刷新 | 不新增。保留顶条「刷新」文字按钮（现网行为：`refreshHome()` + `homeLoading` 文案切换） |
| Expired 态 | 身份卡整张可点 + 卡内砖红附注 + 内联「续期登录」；不新增独立行 |
| 返回键 | 只在子页 pop；折叠态不拦截返回 |

### 3.6 代价（不许只写优点）

| 代价 | 说明 |
|---|---|
| 仍是单列长条 | 首屏信息量提升有限（613dp 装完），一眼扫读效率不如方案二的 2 列格 |
| 「工具」从 10 行变 4 行，但**没变少**，只是藏起来了 | 真实入口数没减（R1 只删重复），用户如果要找「历年课表」仍需先展开 |
| 徽标压缩有信息损失 | 层次/入学两项移入「展开」，一个学期看一次的信息换 18dp，划得来，但要接受「打开就能看到全部学籍」变成两步 |
| 空闲教室是「条」不是「卡」 | 47 间 / 第 5 节两个数字在一行里字号只能到 13sp/500，不如方案二的 26sp 等宽数字好读 |

### 3.7 最适合 / 不适合

- **最适合**：想**一周内上线**、不想动栅格与卡片样式的场景；也适合作为方案二落地前的过渡态（分层规则先上，形态后改）。
- **不适合**：一屏内要「看清四个数字」的诉求（学分/绩点/门数/间数在同一屏横比）。

## 4. 方案二：学业磁贴（2 列）+ 工具行（**主推**）

**定位**：借 `评审-前端设计方案-v3.md` 方向 A 的**布局轴**（2 列不等高磁贴 + tile span），但**不借它的材质轴**——磁贴仍是 **0 圆角 + 1dp 描边 + 无阴影 + 等宽数字**，主色只用于数字与进度条填充。这样既拿到「一屏四个数字」的扫读效率，又不破 `HardTokens` 的三条红线（见 v3 §10.1：布局与材质是两个独立轴，可以只取一个）。

### 4.3 网格规格（硬朗体系内的 bento，不是 A 的软磁贴）

| 项 | 值 |
|---|---|
| 内容边距 | 左右 16dp（现网 `Space.gutter`） |
| 列 | 2 列等宽，列间距 **10dp** → 每列 **159dp** |

| 触区 | 磁贴整块（≥104dp）；工具格 76dp；身份条 ▾ 44dp |

### 4.4 分组与折叠

- 第一层（现在）= 考试 span2 + 空闲教室 span2，两块都是**面状磁贴**，与下面的 1×1 数据格形成「大/小」对照，这就是本方案的层级信号。
- 第二层（学业）= 两个 1×1，不加区标题（磁贴尺寸已说明它是次级）；这一条是**取舍**：不写「学业」二字能省 24dp，代价是用户不知道这两格属于一类。若主人要显式分组，加回 24dp 区标题即可（预算变 838dp，仍 1.2 屏）。
- 第三层（工具）= 2×2 四个紧凑格（76dp），格内只有名称 + badge，无描述。
- 第四层（本机）= 一行收起，「课表 0 门 · 第 12 周」两个数写在收起态摘要里（**空值必须走 `—` 分支**：`课表 — 门`、`周次未校准`）。

### 4.5 入口归属

执行 §2.1，无差异。方案二独有的一条：**「工具」四格不显示描述行**，所以「校园地图」的 badge 只能写「相对位置」（现网就是这个词，不编造距离）。

### 4.6 手势 / 展开态

| 场景 | 规格 |
|---|---|
| 点磁贴 | 整块可点 → push 子页；按压反馈用现网 `clickable` 默认（**不加 scale 动画**，硬朗体系无缩放惯例） |
| 身份条 ▾ | 点开卡内展开 4 项学籍（高度 40→82dp，180ms）；再点收起。**不再有独立的「身份卡」大块** |
| 工具格 | 单击进子页；**无长按**（同方案一理由） |
| 本机状态 ▸ | 点开为 4 行只读（复用 `StatRow`），再点收起；`rememberSaveable` 记忆 |
| 刷新 | 顶条文字按钮保留；刷新中按钮文案切「读取中」并禁用（现网逻辑） |
| Expired | 身份条副标题变砖红「会话已过期 · 点此续期」，整条可点；**不额外占一行** |

### 4.7 代价

| 代价 | 量化 / 缓解 |
|---|---|
| **135dp 宽（实际 159dp）格子里的中文** | 11sp 中文一行约 12–13 字。「毛泽东思想和中国特色社会主义理论体系概论」（22 字）在 1×1 格里必然 2 行 + 省略号，可读性弱于现网 15sp 单卡 | 长课名只出现在「下一场考试」的 span2 磁贴（宽 318dp，约 26 字/行）；1×1 格里只放 ≤6 字的短标签（「加权绩点」「通过门数」） |
| **失去「一张卡只说一件事」的阅读节奏** | 现网 `HomeCards` 的设计取向是单卡单事，2 列后眼睛要跳 | span2/1×1 的尺寸对比本身就是节奏；且 2 列只在「我的」页用，课表/资讯仍单列 |
| **及格线风险：两个 1×1 格里数字互相抢** | 学分 106/165 与绩点 3.42 同为 26sp，若并列容易被当成同一科 | 学分格内保留进度条（唯一带条），绩点格内保留「通过 55 门」副行 —— 用**条 vs 无条**区分 |
| **与 v3 A 的视觉相似度** | 主人可能觉得「这就是 v3 的 A」，而 A 的材质（18dp 圆角 + 柔阴影）已被本文明确拒绝 | 本方案在 v3 §10.1 里是「BENTO 布局 × HARD 材质」的组合，属于 v3 允许的轴组合；验收时对比截图必须能看出「直角 + 描边」 |
| **实现成本** | `LazyVerticalGrid` 只有 6 个格子，用两个 `Column` + `Row` 手搭即可（与 v3 §4.8 的降级方案一致），不引依赖 | ≈2.5 人日（含身份条压缩与工具格） |

### 4.8 最适合 / 不适合

- **最适合**：**学生高频场景**——一屏内同时拿到「还有几天考试 / 差多少学分 / 绩点多少 / 现在哪间教室空」，四件事都是「3 秒内要答案」，且都不需要滚动。
- **不适合**：把「我的」当纯账户页的人（会觉得磁贴太热闹）；也不适合当全 App 模板（v3 §4.9 已判定 Bento 不适合课表页）。

### 5.1 线框（360 × 800 dp）


| 段 | dp | 累计 |
|---|---|---|
| 顶条 | 44 | 44 |
| 身份卡（原样，不压缩） | 120 | 164 |

### 5.3 分组与折叠

- **互斥手风琴**：同一时刻最多一个区展开（点开 B 自动收起 A），避免「全展开又变回平铺」。
- 折叠头是**信息载体**，不是纯标题：右侧摘要必须写「里面有什么 + 关键数字」（`学分 64% · 绩点 3.42 · 通过 55`）。摘要里任何数字缺失都必须显示 `—`（`HomeModel` 的 null 分支直接落到这里）。

- 展开「工具」后：4 行 × 44dp = 176dp。
- 展开「本机」后：4 行 `StatRow` = 148dp。

### 5.4 入口归属

执行 §2.1，无差异。方案三独有的一条：**「设置」不进手风琴**（连折叠头都不给），只留齿轮 —— 因为手风琴的语义是「同层级内容切换」，而设置不是同级内容，是另一个层级。

### 5.5 手势 / 展开态

| 场景 | 规格 |
|---|---|
| 点折叠头 | toggle；互斥（同时只有一个 open）；`animateDpAsState(180ms)` 高度 + 摘要区淡出 120ms |
| 记忆 | `rememberSaveable` 记 open 的 key（单值，不是集合）；切 tab 保持，冷启动回到「现在」 |
| **返回键接管** | 若当前有非默认区展开 → 返回键先把它收起（不再 pop 页面）。这是本方案唯一的导航语义变化，`BackHandler` 需要加一级判断 |
| 长按折叠头 | **不做**「固定展开」（隐藏功能，且与互斥规则冲突） |
| 下拉刷新 | 拆掉顶条「刷新」文字按钮，改为「现在」折叠头右侧的刷新图标（`↻`，触区 44dp）。理由：全页只有「现在」这一区含网络数据，刷新放这里语义更准 |
| Expired | 身份卡整张可点 + 卡内砖红附注（与方案一同规格） |

### 5.6 代价

| 代价 | 说明 |
|---|---|
| **高频入口退化为两次点击** | 空闲教室虽然在「现在」里（默认展开，1 击），但若用户上次收起了「现在」，就变成「展开 + 点」= 2 击。**必须靠「默认展开『现在』」这条硬规定兜住**，否则本方案对最高频入口是净退步 |
| 摘要行是新增的文案负担 | 4 个折叠头各要一句摘要，且每个数字都要有 `—` 分支 → 新增 4 处空态，全部要按 D1–D8 写 |
| 互斥手风琴违反「我全都要看」的直觉 | 想看「学业 + 工具」必须来回切；若用户在对比「我差多少学分 + 大纲里那门课考什么」，会很烦 |
| 发现性依赖摘要 | 摘要若写得太抽象（「学期相关」），用户永远不知道里面有什么 |
| 一屏不滚的收益被留白吃掉 | 502dp 内容 + 194dp 空白，视觉上会显得「空」，与「信息密度高」的硬朗气质相反 |

### 5.7 最适合 / 不适合

- **最适合**：把「我的」定位成**账户 + 设置入口**、且主人认为「考试/成绩/教室都应该从别处进」的场景；也适合作为「极简」的上限样板上桌对比。
- **不适合**：**学生高频场景**（理由见 §5.6 第一条：高频入口天然要 2 击）。

### 6.2 推荐：**方案二**

1. **它唯一同时满足「高频 0 滚」与「一屏五个数字」。** 学生的真实用法不是「逛我的」，是「我知道我要什么，给我」。方案二的首屏 496dp 内同时给出：还有几天考试、差多少学分、绩点多少、现在哪间教室有空 —— 这四件事恰好是全 App 除课表外最常被问的四个数。
2. **它的层级不是靠颜色或圆角做的，而是靠「磁贴尺寸 + 数字字号 + 描边轻重」**，这三样在 `HardTokens` 里都有现成档位（`Stroke.hairline` / `NumericFont` / 26sp Bold），不新增 token，不破三条红线。
3. **它把「收起」用在了正确的地方**：收的是诊断信息（本机状态）和低频工具；收的不是高频入口。方案三的病根是把「现在」也做成可收的，等于给最高频的动作加了一道门。
4. **它给 v3 的 BENTO 布局轴提供了一个低风险落点**：先在「我的」页验证 2 列网格在 vivo V2301A 上的滚动与点击精度，再决定要不要推到学业主页（v3 §10.2 的第 1 步）。即使全 App 最终不选 A，这一页单独用 2 列也不违和。

### 6.3 何时改选方案一 / 方案三

| 条件 | 选 |
|---|---|
| 一周内要上真机、不想动卡片样式 | 方案一（分层规则先落地，形态后改，规则可原样迁移到方案二） |
| 主人认为「我的」只该是账户页，考试/成绩/教室都从课表页进 | 方案三 + 课表页补三个入口（否则高频动作全变成跨 tab） |
| 主人要「和 v3 的 A 真正一致」 | 不选本文任何一套，直接按 v3 §4 实现（含 18dp 圆角 + 柔阴影 —— 那会破 `HardTokens` 红线 1、2，需要主人书面确认） |

### 6.4 可以混合的部分（推荐落地时就这么做）

**方案二的骨架 + 方案一的「本机状态」抽屉 + 方案三的折叠头摘要写法**：磁贴给高频，抽屉给低频，摘要文字给「收起时也要有信息」。三者不冲突，合起来正是本文 §2 那张骨架图。

## 7. 全页视觉层级规格（三套方案共用）

### 7.1 五级层级（只允许这五级，跳级等于没有层级）

| 级 | 承担者 | 字号 / 字重 / 字体 | 颜色 | 判据 |
|---|---|---|---|---|
| **L0 身份** | 姓名 | 17sp / Bold / 系统 | `ink` | 全页唯一的「人名」 |
| | 副标题 / 学籍 | 11sp / Normal | `inkFaint`（Expired 态 `brick`） | 一行说完「我是谁」 |
| **L1 现在** | 倒计时数字 | **26sp / Bold / NumericFont** | `ink`（今天/明天 `brick`） | 会自己变、且影响今天行动 |
| | 教室间数 | 26sp / Bold / NumericFont | `ink` | 同上 |
| | 组内强调 | **3dp `primary` 竖条**（`Stroke.accentBar`） | `primary` | **全页只有 1 处** |
| **L2 学业** | 学分 / 绩点 | **26sp / Bold / NumericFont** | `ink` | 学期级、静止、要横比 |
| | 进度条 | 6dp 槽 + 6dp 填充，0 圆角 | 槽 `cardAlt` / 填 `primary` | 分母缺失 → **不画条**（现网逻辑） |
| **L3 工具** | 条目名 / 磁贴名 | 13sp / Normal（磁贴 11.5sp/500） | `ink` | 每次点进去看新东西 |
| | badge（数量/学期） | 11sp / NumericFont | `inkFaint` | 空 → 不显示（不写 0） |
| **L4 本机/诊断** | 4 行只读 | 12.5sp / 11.5sp | `inkSoft` / `ink` | 排障才看 |
| **L5 页脚** | 版本号 / 木鱼 | 10sp / NumericFont | `inkFaint` | — |

### 7.2 分隔手段（只有三级，不许自创第四种）

| 级 | 手段 | 用在哪 |
|---|---|---|
| 组间 | `SectionLabel`（11sp / `inkFaint` / 字距 +0.5）+ 上下留白（上 16 / 下 4） | 现在 / 学业 / 工具 / 本机 之间 |
| 卡间 | `CardGap` = 12dp（方案二网格改 10dp 间缝） | 磁贴/卡片之间 |
| 行间 | 0.6dp `rule` 分隔线（现网 `Divider`） | 工具行、本机行、卡内分栏 |

### 7.3 强调预算（硬规定）

- 整页 `primary` 只允许出现在：**下一场考试的 3dp 竖条**、**学分进度条填充**、**倒计时「今天/明天」的砖红**（`brick` 不算 `primary`）。合计 ≤3 处。
- 砖红（`brick`）只允许三处：会话过期附注、倒计时今天/明天、不及格门数。**绝不用作「入口可点」的提示色**。
- 磁贴**不做色块分区**（与 v3 A 的 4 色相相反）：本页 6 个格子，若 4 种底色会把「硬朗纸墨」变成看板。

### 7.4 数据诚实的落点（三套方案都必须满足，逐条对应 v3 §8.1）

| 位置 | 规定 |
|---|---|
| 数字缺失 | 显示 `—`，**字号降到 20sp/500/`inkFaint`**（不许「大号灰字」占位）；不显示 `0` |
| 学分分母缺失 | 不画进度条，条的位置**不留空**（避免假条） |
| 绩点缺失 | 「暂缺」，不是 `0.00` |
| 空闲教室为 0 间 | 不写「0 间」，走 `HomeModel.freeRoomsEmptyHint()` 的三分支（真空 / 会话失效 / 选楼没生效） |
| 折叠头摘要 | 任何数字缺失都要 `—`；摘要**不放**加载动效 |
| 空态 | 「原因 + 下一步动作」，且**零动效**（转圈/呼吸都不许，空是结论不是过程） |
| 三态登录 | 文案全部走 `SessionText`，**一个字都不在本文重写** |
