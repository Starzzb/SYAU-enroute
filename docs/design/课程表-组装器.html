三 · 槽位与取值（这是「够不够细」的账）

轴取值管什么互斥
shape方卡 / 便签 / 细线 / 色块 / 标签卡片的骨架：圆角、投影、底色、内边距细线不叠投影
decor无 / 左脊 / 顶帽 / 角点 / 底线 / 淡底 / 斜纹骨架之上的装饰，任何形状都能叠角点与 badge=corner 占同一角落
meta三行 / 同行 / 底栏 / 只课名课名与地点教师怎么排只课名时不显示角标文字
badge无 / 折角 / 斜纹带自标/未读这类状态标记斜纹带只在只课名时用（否则吃字）
erosion不褪 / 上褪 / 斜线 / 整块淡上完课的褪色方式，只褪色不删卡无
motion关 / 呼吸 / 褪色呼吸格子的微动效，可整页关关掉后与静态完全一致
tone四色 / 单墨 / 无色色从哪来：科类四色、统一墨色、完全无色无色时色块形状退化为描边
backdrop+bgMotion无 / 横线 / 田垄 / 复相 / 纯色 × 关/缓移页底纹理，可一键换纯色、可关动效纯色与纹理解释互斥

单格组合 = 形状 5 × 装饰 7 × 编排 4 × 角标 3 × 侵蚀 4 × 动效 3 × 配色 3 = 15120；扣掉互斥约 1.2 万。
