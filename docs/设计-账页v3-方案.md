# 设计 · 账页 v3 方案（一页纸）

> 状态：**待主人点头，未写一行码**　日期：2026-11-15　作者：design-v3-2
> 前提：全部前端设计纪律已作废（`24b9dd2`）。本方案**不追求"全仓统一"**，只追求：这一套主题读起来舒服、看起来有性格。
> token 结构留着当管道，但没有任何测试或文档能强迫它。

## 0. 一句话

前两轮都在**拆 Material**（去圆角、去阴影、去格线），拆完还是个素 Material。
这一版**换骨架**：屏幕不是"一列卡片"，而是**一页书**——常驻页眉、行号页边、页脚 folio；
层级不再用盒子（卡/线/圆角），改用**排版**（字号、字重、基线、缩进、页边注）。

## 1. 这版长什么样

### 1.1 页面骨架（四页共用）

```
┌────────────────────────────────────────────┐
│ 资讯                              未读 86 查│ ← 页眉：常驻 44dp，不被内容顶走
│────────────────────────────────────────────│   章节 15sp/700 · 状态 11.5sp · 「查」
│  竞赛 ──────────────────────────────── 12  │ ← 栏目名 11.5sp/500 + 短横线，右端是本组条数
│ 01 │ 关于举办 2026 年全国大学生数学建模竞赛 │ ← 行号（页边槽 22dp 右对齐）· 标题 17sp/600
│    │ 各学院：现将校内选拔的报名、培训与赛程 │ ← 摘要 13sp/22sp，最多 2 行
│    │ 安排通知如下…                          │
│    │ 竞赛 · 11-11 · 剩 6 天                 │ ← 元信息 11.5sp/16sp，inkFaint
│ 02 │ 关于下学期选课的通知                   │ ← 条目间距 18dp（不是卡片外边距）
│    │ 教务 · 11-10 · 剩 2 天                 │
│  ────────────────────────────────────────  │ ← 组间短横线：缩进到正文左沿，长 56dp
│  就业 ──────────────────────────────── 41  │
│ 03 │ 中储粮 2027 届校园招聘公告             │
│────────────────────────────────────────────│ ← 页脚：1 条 1dp 线
│    课表          资讯          我的         │ ← 纯文字索引，48dp 触区，无图标无胶囊
│                                第 2 / 7 组 │ ← folio：当前组序号（真实数据，不编）
└────────────────────────────────────────────┘
```

「我的」同骨架，正文换成**账目行**（不再是磁贴网格）：

```
│  学业 ──────────────────────────────── 6   │
│ 01 │ 学分绩点                        3.42  │ ← 「科目 ⋯ 值 单位」右对齐成列
│ 02 │ 已修学分                      128 学分 │   数字用衬线等宽，竖向对齐
│ 03 │ 排名                         12 / 341  │
```

设置页走**目录**（三层：目录 → 分类页 → 叶子页，借 BiliPai 的结构，见 §5 批 2）：

```
│  设置 ──────────────────────────────────   │
│ 01 │ 外观            主题、字号、线条疏密  › │ ← 副标题列举"这页里有什么"，不是宣传语
│ 02 │ 教务与数据      账号、缓存、刷新时机  › │   分组名不复读分类名（避免"隐私里还有隐私"）
```

### 1.2 层级手段（只有五种，盒子语言整体退场）

| 手段 | 怎么用 | 为什么够 |
|---|---|---|
| **位置** | 页眉（章）/ 栏目名（组）/ 行号（条）/ 页边（注） | 四个横向带位，一眼分出层级 |
| **字号** | 15 页眉 · 17 标题 · 16 正文 · 13 摘要 · 11.5 元信息 | 相邻差 ≤2sp，不跳档：靠"小差"而不是"大跳" |
| **字重** | 700 页眉 · 600 标题 · 500 数字 · 400 正文 | 单靠字重就能分层，不必再加线加框 |
| **留白** | 段内 0 · 条目间 18 · 组间 28 + 短横线 | 留白是这台设计的**主要材料** |
| **颜色** | 只有 ink / inkSoft / inkFaint 三档 | 颜色只做"淡出"，**不做**分层 |

全页 **0 个容器框**：没有 Card、没有描边盒子、没有色带块、没有阴影。条目就是"行"。

### 1.3 阅读节奏

三种密度交替，而不是等距刷列表：**主条目**（标题+2 行摘要+元信息）/ **次条目**（1 行）/
**页边注**（行号、条数、folio，不进正文流）。
一屏 ≈ 5–6 条（v2 卡片式约 3.5 条）——密在信息量，松在行距与留白。

## 2. 与 v2 的三处本质区别（硬门槛）

| # | v2（被推翻） | v3 | 为什么是"本质" |
|---|---|---|---|
| 1 | Material 骨架做减法：顶栏 + 卡片列表 + 图标 tab | **书本骨架**：常驻页眉 + 行号页边 + 页脚 folio；条目是"行"，全页无容器框 | 换的是**版面结构**：内容的组织单位从"盒子"变成"行 + 页边槽"。这决定后面所有细节，不是反过来 |
| 2 | **盒子语言**：层级靠圆角/描边/阴影/色带 | **排版语言**：层级靠字号/字重/基线/缩进/页边注 | 盒子整条退场。票 31 只把盒子的圆角改成方角——**盒子还在**，所以主人看不出变化 |
| 3 | **等距堆叠**：每条自带容器、间距相同，眼睛在找盒子边界 | **三种密度 + 组间短横线 + 行号列**：眼睛沿行号列下行，像读一页账 | 节奏从"列表"变成"页"，这是"舒适度"唯一能落地的地方 |

**加项**：搜索从"没有"变成常驻入口（页眉右侧）。

## 3. 阅读舒适度：具体参数（设备基准：vivo V2301A，逻辑宽 360dp）

| 参数 | 取值 | 为什么是这个数 |
|---|---|---|
| 正文 | **16sp / 行高 28sp（1.75）** | 16sp 是 360dp 上"不眯眼"的常见下限；1.75 落在中文长读舒适带（1.6–1.8）偏上。v2 是 15/24 = **1.60**，正好压在下沿——主人判"不够松弛"。再高到 1.8+，段落会散成"一行一句" |
| 行长 | **≈20 全角字**（正文栏 320dp） | 左页边槽 22 + 右留白 18 = 320dp；320÷16sp ≈ 20 字，落在中文 18–25 字舒适带中部。超过 30 字，每行回扫成本陡增 |
| 段间距 | **22dp ≈ 0.8× 行高** | 段与段要断得开、又不能像两篇文章。0.8× 是"断得开但不空"的经验值；v2 的 32dp 反而把条目切碎 |
| 标题 | 17sp / 26sp / 600 | 只比正文 +1sp、字重 +200。**靠字重与位置分层，不靠字号堆**——v2 的 22sp 大标题是版面装饰，占首屏却没帮人读 |
| 摘要 / 元信息 | 13sp/22sp · 11.5sp/16sp | 摘要退一档（0.8× 正文）；元信息只做定位，11.5sp 是最小可读档 |
| 行号 | 10.5sp 衬线等宽，inkFaint | 页边槽的"账本行号"，等宽保证 01/02/10 竖向对齐 |
| 页眉 | 15sp/700 + 1dp 线，常驻 | 给"我在书里"的定位感，顺手治"内容顶走标题"的老毛病 |
| 条目间距 | 18dp ≈ 0.64× 行高 | 让条目成"一块"而不是"一行" |
| 触区 | 整行可点 ≥48dp；按压态 = 行底色 +2%（不是水波纹/胶囊） | 无卡片后热区靠整行承载，按压反馈要"轻" |
| 深色 | "夜账"：纸深墨浅，不是反色 | 正文对比仍 ≥4.5:1（功能要求，非纪律）；页眉线降到 inkFaint，夜里不发亮 |

## 4. 搜索

- **入口**：页眉右侧「查」字块（48dp 触区），四页都在；**不进 tab、不进设置**。
- **形态**：全屏覆盖页，输入框就是页眉，不引入新导航框架。
- **搜四类**（全是本地已有数据，不发网络请求）：教师（姓名/工号）→ 教师详情；教室（楼/房间）→ 空闲教室或当周位置；
  地点（地图 POI）→ 地图定位；设置项（标题匹配）→ 设置页对应行。
- **最小可用**：输入即搜（防抖 120ms）、按类分组、每条可直达、无结果给人话（"没搜到 · 试试教师姓名或教室号"）、
  空输入给四类各 3 条常用入口。**不做**：拼音模糊、历史云同步、跨端。

## 5. 实施批次（每批一次装机验完）

| 批 | 范围 | 装机看什么 |
|---|---|---|
| **1** | **资讯页 + 我的页**换新骨架（页眉/行号页边/无卡片/页脚 folio/组间短横线）。课表不动（票 33 在改 Pager） | ① 一屏读几条 ② 连读 3 屏眼睛累不累 ③ 像"一本书"还是"一个 App" |
| **2** | **课表账页化**（只在 `WeekGrid` 内做视觉，**不动 Pager 容器接口**，遵守与 `home-api-fix-2` 的约定）+ **设置页改三层目录**：分类目录 → 分类页 → 叶子页；目录每行 = 标题 + **列举"这页有什么"的副标题** + chevron；分组名不复读分类名；行视觉 44dp 而命中区补到 48dp（BiliPai 实测值见票 35 报告 §1.1–1.4，具体 dp 按我们 16sp 正文重测）；说明文字分三角色：目录副标题 / 开关副标题随状态变 / 长解释进点开后的面板 | 课表是否融进页眉/页脚体系；设置页能否"不点进去就知道东西在哪" |
| **3** | **搜索**（入口 + 四类索引 + 跳转）+ 四页一致性收尾 | 输入到跳转 ≤2 步；四类各有一条跑通 |

**主题切换**：保留热切，**不引入重启**。新版式参数都是 CompositionLocal 值，热切没有半态；
只有"换字族且需重算 measure"才需要重启——真到那步再单开一票。主人说可以重启，但能不做就不做。

## 6. 与现有代码的关系

- **不动**：`data/`、`ui/map/`、`MathBackdrop`（票 29/32 另算）、票 33 的 Pager 容器接口。
- **复用**：`InkTokens`（三档颜色够用）、`LocalForm`（当"版式参数包"用，**不新增任何强制语义**）、`primaryInk()`。
- **替换**：`FeedScreen` / `UserScreen` / `SettingsScreen` 的**渲染层**（数据与 ViewModel 一行不动）。
- **新建**：`ui/ledger/`（页眉、行号页边、账目行、folio、组标题）——只服务这套主题，不做通用化。

## 7. 已知风险

1. 行号会变噪声 → 条目 <3 不显示；滚动中不重排（稳定 index）。
2. 无卡片热区不清 → 整行可点 + 2% 按压底色；长按进操作单（与原行为一致）。
3. 「我的」可能显空 → "科目 ⋯⋯ 值 单位"右对齐成列 + 点状引导线；空值显示「暂缺」。
4. folio 组序号必须是真实数据，不编造进度。
5. BiliPai 只借结构不借码（GPL-3.0）；要用组件则 **Miuix 是 Apache-2.0**，先核 Compose 版本兼容再定。
