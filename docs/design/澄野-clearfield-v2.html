01配色：一个主色，一个强调，其余全部退后

一个主色承担「今天 / 进行中 / 主按钮 / 选中」，一个强调色只做小面积点缀（未读点、角标、警示性强调）。 主色浅层是主色按 8% 覆在纸底上算出来的，不进色板；小字号的有色文字自动往深（或往浅）推到 4.5:1 以上， 主按钮上的字色按对比度自动黑白翻转。换主色时强调色若与之撞车，会自动让位到信息色，避免两个入口同色。 下面每一格的比值都是当前主题下当场计算的，低于门槛会标红。

05浮层与模式切换：从按钮里长出来

浮层不是「弹出一个新东西」，而是那一枚图标按钮自己展开：裁剪框从按钮所在的右上角 36×36 开始， 260ms 内长到整张卡，内容分七档错峰进场；收起走同一条路径反向 180ms，遮罩同步淡出。 明暗切换用色块蔓延——新主题从按钮圆心以圆形裁剪铺满全屏，半径按视口对角实时算， 支持 View Transitions 的浏览器走原生快照，不支持的用同色圆形遮罩兜底，减少动效偏好下直接换。

08落到代码：改动面与不动的地方

本页只是原型，尚未写入 Kotlin。落地时新增 StyleSet.CLEAR = 3 与 FormSpec.Clearfield，旧三套逐像素不动。 新增开关：softGrid（去竖实线）、noErosion（已上课不再画斜纹）、progressLive（进行中底部进度）、 roundedNav（胶囊选中态）。调参台上的圆角 / 字级 / 密度 / 阴影四个滑杆对应 FormSpec 的四个乘数， 默认 1.0 即本页初始观感；主色与强调色仍走壁纸取色的两个入口，浅层与小字色由 ColorUtils 按本页同一套对比度兜底算出。 外部字体（Fraunces / Noto Sans SC / JetBrains Mono）与 lucide 图标不进 APK：App 内回落到已打包的 IBM Plex Mono、 系统无衬线与 material-icons-core + 自绘图标，衬线周次用系统 serif。 交互落地：色块蔓延在 Compose 里用 Canvas 圆形裁剪 + Animatable（560ms，同一条缓动）， 锚点浮层用 Popup + graphicsLayer 的 clip 与 scale，原点取按钮中心； 子页推入用 AnimatedContent 的 slideInHorizontally，父页同步左移 12%。 不动的部分：UrpClient 与全部解析器、缓存与数据诚实口径、触区下限、现有三套主题的渲染分支、页面结构与信息层级。
