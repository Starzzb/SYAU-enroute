## 3. 合规现状（如实记录，不假装没问题）

### robots.txt 实测（2026-11-14，4 个站点取样）
```
User-agent: *
Allow: /$
Allow: /*.htm$
Allow: /*.html$
Disallow: /info/*.htm$      ← 只有主站 www.syau.edu.cn 有这一条
Disallow: /*?*
Disallow: /
```
按 robots 规则（最长匹配优先）：
- **静态 `.htm` / `.html` 页面 = 允许**；带查询串（`?`）= **禁止**
- 主站 `/info/*.htm` 明确禁止；**学院子站没有这条**，其 `/info/...htm` 教师详情页依 `Allow: /*.htm$` 属于允许范围
- 其余路径一律 `Disallow: /`

> ⚠️ 这与 `AGENTS.md` 里「`*.syau.edu.cn` 的 robots 是 `Disallow: /`」的**简化说法不完全一致**：
> 实际是「**静态页允许、带参数禁止、主站 /info 禁止**」。已按实测更正表述，
> 并据此约束抓取器：**只抓静态 `.htm`，永不请求带 `?` 的 URL**。

### 因此
- 本项目仍是**个人测试构建**，**分发需学校授权**（AGENTS.md 硬规矩 5 未变）
- 抓取器必须：只抓公开页、不登录、不带查询串、同站串行 ≥1.2 秒、可随时停
- 落库只存**工作信息**（姓名/职称/职务/院系/研究方向/办公地点/工作邮箱/照片），
  手机号/身份证/住址/出生日期一律不取不存

## 4. 下一段计划（建议，等批复）

### 4.1 抓取策略：分三档，别写一个大而全的解析器

| 档 | 站点 | 做法 |
|---|---|---|
| **A 通用**（12 站） | 植保、土环、经管、动科、林学、信电、水利、食品、生科、外语、理学、农学 | 列表页 → `a[href*="info/"]` 取详情链接 + 翻页（`index_2.htm` / `xxx/2.htm`）→ 详情页按**标签词**抽字段（「职称」「研究方向」「电子邮箱」…） |
| **B 文本行**（工程、体育） | 工程学院、体育教学部 | 列表页从**正文文本**抽「姓名 + 职称」，再去详情页补字段；锚文本为空的用「链接位置 → 周边文本」还名 |
| **C 无详情页**（园艺、马院） | 园艺学院、马克思主义学院 | 只有列表/表格 → **只能拿到姓名 + 教研室/分类**，字段极少。**要不要收**请批示：我倾向收「姓名 + 单位 + 来源页」，并在 App 里如实显示「仅姓名」 |

### 4.2 去重与身份
- 同一人可能出现在「教师名录」与「博导名单」两个列表 → 以 **姓名 + 详情页 URL** 去重；
  **不做同名合并**（同名不同人是真实存在的，宁可在 App 里显示两条也不要错并）
- 每人必须有 `source`（详情页 URL）与 `fetchedAt`

### 4.3 落库形状（拟）
`assets/faculty/<code>.json`（按学院分文件，单文件 ≤ 建议 200KB）：
```json
{"schema":1,"college":"农学院","code":"nxy","generatedAt":"…",
 "count":91,"withTitle":0,"withEmail":0,
 "teachers":[{"name":"陈温福","title":"","dept":"","research":"…","office":"","email":"",
              "photo":"https://…","source":"https://nxy.syau.edu.cn/info/1392/6907.htm",
              "fetchedAt":"2026-11-14T20:40:00+08:00"}]}
```
外加 `assets/faculty/_index.json`（各院人数 + 字段覆盖统计）供 App 首屏用。

### 4.4 工作量估计
- A 档 12 站：每站 1 解析器配置 + 字段别名表，约 1.5 天（含跑通、抽样人工核对每站 3 条）
- B 档 2 站：各约 2 小时（要处理锚文本缺失）
- C 档 2 站：各 1 小时（简单，但信息量低）
- 全量首跑：约 **800 个详情页 × 1.2 秒 ≈ 16 分钟**（同站串行），分站点跑更稳

### 4.5 风险
1. **页脚/导航污染**：列表页里 `2–4 汉字的导航项`（学院概况/组织机构）会被误当人名 —— 必须限定「在列表容器内」+「链接指向 /info/」
2. **同名不同人**：不做智能合并
3. **照片版权/可用性**：先只存 URL，不下载图片（下载要单独评估体积与授权）
4. **站点改版**：脚本必须能「解析出 0 条就报错退出」，不能静默产出空文件
