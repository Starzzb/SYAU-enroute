### 抽屉的三档与手势

| 动作 | 结果 |
|---|---|
| 点抓手（位移 < 4 px） | dt0 → dt1 → dt2 → dt0 循环，方便一只手换档 |

## 2. 三条轴的分组：cell / grid / bg

轴不只管格子。按 `sc` 字段分三类，各自渲到不同位置：

| sc | 轴 | 渲到哪 |
|---|---|---|
| `cell` | 0 形状 1 装饰 2 字段 3 角标 4 侵蚀 5 动效 6 底色 | 每个格子拼类名 `sh0 dc1 mt0 bg0 er1 mo0 tn0` |
| `grid` | 7 页头 8 行距 9 底纹 10 底纹动效 | 课表容器：`hd0 gd0 bd1 drift` |

`cellHTML` 只遍历 `cell` 轴；`gridHTML` 拼 4 条；`sc=bg` 的两条交给 `project()` 画。

- **序号即契约**：`AXES` 下标 = 槽位下标 = 预设数组 `s` 下标 = Kotlin `TtSlots` 字段序。代码里没有一处 `if (axis === 'shape')`。
- **渲染靠循环拼类名**：`for(var i=0;i<N;i++) k+=' '+AXES[i].k+s[i]`；CSS 只需为「新取值」补一条选择器。
- **互斥是规则表**：`{w:[轴,值], and:[另一轴,值], set:[轴,新值]}`，`sanitize()` 顺序套用直到无变化。胶片里「这个值能不能选」= 试设 → sanitize → 值变了即**不可选**（灰化 + 朱砂斜杠）。与 Kotlin `TtPresets.sanitize` 同构。

### 现有 5 条互斥

    {w:[3,2], set:[2,3]}                  角标=斜纹带 → 字段只能「只课名」（否则吃掉第 4 个字）
    {w:[1,3], set:[3,0]}                  装饰=角点 → 角标关（同一个角落）
    {w:[0,2], and:[1,5], set:[1,0]}       形状=细线 且 装饰=淡底 → 装饰关
    {w:[0,2], and:[1,6], set:[1,0]}       形状=细线 且 装饰=斜纹 → 装饰关
    {w:[6,2], and:[0,3], set:[0,0]}       底色=无色 且 形状=色块 → 形状回落方卡

### 子轴：不是互斥，是锁

`转动逻辑` 带 `sub:11`，父轴（超立方体）为「不显示」时整条锁住：`locked(i,s) = AXES[i].sub!==undefined && s[AXES[i].sub]===0`。

- 行的写法：`class="row sub lock"`，缩进 17px + 一个「└」直角折线（`::before` 横 9px、`::after` 竖 9px，色 `--rule`），把「这是别人的子项」画出来，不写说明文字。
- 锁住时：整行 `opacity:.45`、右侧值显示「—」（不是把当前取值灰着写出来，那会让人以为还在生效）、刻度尺上那一格点不动、点了也不开胶片。
- **不做成 sanitize 规则**。早先写成 `{w:[11,0],set:[12,3]}`（不显示 → 强制定格），结果是用户开回来时发现动法被偷偷换成定格，值被吃掉了。改成「锁」以后取值照旧保存，只是不让改。

胶片不再只写文字。`sampleHTML(i, v, sel)` 按轴号分派，画的就是那个取值本身：

| 轴 | 实样 |
|---|---|
| cell 七条 | 45×52 真格子，用 `compose()` 拼真类名渲染；只有 `mo`（动效）传 `'anim'` 让动画继续跑，其余传 `'still'` |

| 底纹 | 45×52 图案块：无=空、横线、田垄（隔行压暗）、复相（横竖细网）、纯色；`bd1` 带 `drift` 会缓慢下移 |
| 超立方体 / 动法 | 92×52 迷你 canvas，真的跑同一套 `project()`；透明度 0 / .26 / .30 / .40 对应不显示/淡线/亮线 |

两个必须注意的实现细节：

- 迷你 canvas 的半径要按画布尺寸再放大，用 `cv.dataset.alpha ? 0.50 : 0.34`，否则 92×52 里的立方体只有指甲盖大。
- 五种动法静态长得一样就失去意义，初始相位按档错开：`[0.30,1.62,0.92,1.15,0.55][mode]`，静止截图也能看出「转过来的角度不同」。

## 5. 超立方体（`ts`）与它的子项 转动逻辑（`tm`）

数学照抄 Kotlin，不另写一套：

- 16 顶点 = `±1` 的三十二位组合；`EDGES` 用 `popcount(i^j)==1` 生成 32 条棱。
- 4D→3D：XY 平面与 ZW 平面各转一个角，`k4 = 1/(2.6 - w)` 透视；3D 再绕 `0.52 / 0.36` 倾一次；3D→2D：`k2 = 1.9/(4.2 - z3)`。
- **正交投影**（`tm=4`）：`k4 = 0.52`、`k2 = 0.52` 都改成常数 —— 没有近大远小，线互相平行，就是教科书上「立方体套立方体」的 Schlegel 图。
- **跟手横滑**（`tm=1`）：只有这一档在 `pointerdown` 时接管，`pointermove` 里 `phase += dx*0.012`，松手保留 0.94 的惯性衰减；其余四档不动手。
- 画布在格子下面（`z-index`），课卡仍在最上层 —— 与「课名永远最上层」同一条规矩。
- 五档动法只在超立方体显示时可选；不显示时整条锁住，见 §3 末尾「子轴」一节。

### 五档动法的出处（都是开源实现，不是凭空想的）

- [tsherif/tesseract-explorer](https://github.com/tsherif/tesseract-explorer)（three.js）：4D 旋转平面可调、**透视/正交可切换**、可任意角度停住 → 「正交投影」「定格」两档的依据。
- [Coding Train #113 · 4D Hypercube](https://thecodingtrain.com/challenges/113-4d-hypercube)（p5.js）：两个平面上同时旋转 + 鼠标拖拽转向 → 「自由旋转」「跟手横滑」。
- [orybkin/Tesseract](https://github.com/orybkin/Tesseract)（4D blocksworld）：绕第四轴做双轴反相旋转的观感 → 「反向双转」。

## 6. 侵蚀三档（都吃整卡）

| 档 | 遮罩 | 观感 |
|---|---|---|
| 上褪 er1 | `linear-gradient(180deg, wash 0%, wash72 50%, wash22 100%)` 铺满整卡 | 上半褪得厉害、下半留一点，像被翻旧的纸 |
| 斜线 er2 | `repeating-linear-gradient(135deg, …wash…)`，opacity .8，整卡 | 斜向划痕感，最像「用旧了」 |
| 整块淡 er3 | `linear-gradient(160deg, wash92, wash58)` 整卡 + 文字 .84 | 整张淡下去，信息还在 |

关键：洗色必须用 `--wash`（浅 `#EFE9DC` / 深 `#1F2723`），**不能用 `--paper`**。卡片底色比纸更白，拿纸色去洗白卡等于没洗 —— 第一版就是这么栽的。

## 7. 交互细节

- 点一行 → 就地展开胶片（`scrollIntoView({block:'center'})`，对应 Compose 的 `BringIntoViewRequester`）；展开后列表会滚到那一行，末几行不会被折线挡住
- 胶片首格「跟随」= 显式 -1，不是把预设值拷进 overrides（拷进去就分不清「碰巧一样」和「钉死」）
- 点已选中的格子 → 松回跟随；点互斥格 → 不响应（灰化 + 斜杠）
- 换预设 → 13 条覆盖全部松回 -1（否则「换了没变化」）
- 刻度尺点一下直接滚到那一行

## 8. 进 Compose 的注意

1. 胶片必须**复用同一个 `TtCourseCell`**，只换 `TtSlots` + `Modifier.width(45.dp).height(52.dp)`；另写一套绘制必然对不上真课表。
2. 预览不能进 `LazyColumn` —— 进了滚动容器就一定会跟着滚，与「固定不动」直接冲突。
3. 禁用/高亮按 `TtPresets.resolve()` **之后**的值算，不是按 overrides；`sanitize` 会抹掉 `decor=3 && badge=1` 这类组合。
4. 侵蚀 progress 在设置页钉死采样（1 / .45 / 0），别接真实时间。
5. 动效别全开：42 格同时呼吸会掉帧，设置页只在预览那一屏开。
6. 格内两行中文受 fontScale 影响，预览要给 `LocalDensity` 固定字阶，否则 1.3 倍下每行只放 3 个字。
7. 超立方体要 `Canvas` + 每帧 `phase` 递增（`withFrameNanos`），32 条棱 `drawLine` 一次画完；「跟手横滑」用 `pointerInput` 的 `detectHorizontalDragGestures`，松手用 `animateDecay`。别用 `Animatable` 一个顶点一个顶点插值。
8. 子轴锁在 Compose 里就是 `enabled = slots.ts != 0`：`SegRow` 整行 `alpha = .45f`、当前值写「—」、刻度尺那一格 `enabled = false`。**不要在 `TtPresets` 里加「ts=0 → tm=定格」的 sanitize 规则**，理由见 §3 子轴一节。

### 预览的真几何（TtPreview.kt）

    手机宽 393dp（PHONE_W），axisW 40dp，bandH 14dp，weekH 44dp
    headerH = 20 / 26 / 32（页头轴三档）
    rowH    = 88dp × 0.88 / 1 / 1.12，下限 64dp（行距轴三档）
    contentH = weekH + headerH + bandH×3 + rowH×6

- 外层 `BoxWithConstraints` 只做**等比缩放**：`scale = (maxWidth / 393dp).coerceAtMost(1f)`，内层固定 393×contentH，`graphicsLayer { scaleX = scale; scaleY = scale }`。宽高同一系数——主人 m03987 明确要求「不去形变，可以等比例缩放」。
