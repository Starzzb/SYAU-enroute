## 群公告 / Release 正文

**沈农在途 0.8.0+m32：这次要先卸载旧版，再装新的**

先说结论——这次更新**不能**像以前那样点一下就装上，得先把旧版卸掉。原因在我这边：我把发布签名密钥删了，而且没有备份。Android 的规矩是同一个应用名签名必须一模一样，签名换了系统就拦着不让覆盖安装（会提示「应用未安装 / 更新包与已安装应用不兼容」）。所以这一版换了新签名，旧版没法原地升级。

**装之前请按这个顺序来（大约三分钟）**

1. 打开旧版 → 地图 → 点一个面 → 底部「导出」→「另存 GeoJSON」，存到手机存储里（这个名字不用改，记一下在哪）
2. 长按桌面图标卸载旧版（系统设置 → 应用 → 沈农在途 → 卸载）
3. 装新版（地址见下）
4. 连上校园网或 mangoVPN，重新登录教务 → 课表、成绩会自动拉回来
5. 地图 → 「导入标注」→ 选第 1 步存下来的那个 GeoJSON，标注就回来了

**会丢什么、要不要管**

| 东西 | 卸载后 | 怎么办 |
|---|---|---|
| 课表、成绩、考试安排 | 没了 | 重新登录后自动重抓，不用手动做 |
| 地图标注（自己填的名称、层数、备注） | 没了 | **必须按第 1 步先导出**，装完用「导入标注」带回来 |
| 收藏、偏好设置（深色、字号等） | 没了 | 需要重新设一遍，这部分没有导出 |
| 登录状态 | 没了 | 重新登录，密码仍然只用一次、不保存 |
| 内置的大纲与培养方案 | 不受影响 | 跟着安装包走，2066 门都在 |

**下载地址**

- GitHub Release（首选）：https://github.com/Starzzb/SYAU-enroute/releases/tag/m32
- 123 网盘（国内更快）：【待补】
- 蓝奏云（备用）：【待补】

文件：`SYAU-enroute-m32.apk`，约 8 MB。装完在「我的 → 关于」能看到 `0.8.0+m32`。

**以后就照旧了**：这一版装好之后，App 内「检查更新」恢复正常，下次更新点一下就装上，不用再卸载。

**如果你会用电脑 / adb**（可选，能少丢一点）：`adb uninstall -k cn.dkarbon.enroute` 会保留应用数据目录，随后 `adb install` 新包，部分机型能把收藏和标注留下来；不成功也不影响，还是按上面五步走。

有问题、想加资讯来源、发现错字，都往这里丢：https://github.com/Starzzb/SYAU-enroute/issues

## 发布渠道盘点（回答「还有什么其他渠道」）

| 渠道 | 适不适合 | 说明 |
|---|---|---|
| **GitHub Releases** | 主渠道，已用 | 直链稳定、能放 sha256、`latest.json` 就指它；国内有时慢，可用 gh-proxy / jsDelivr 加速 |
| **123 网盘** | 适合，你已在做 | 免登录门槛低、分享页直观；缺点是外链会变、大文件限速，链接一变就得改公告 |
| **蓝奏云** | 适合 | 8 MB 属于它的舒适区，下载快、手机端体验好；链接里的域名会换，得定期核对 |
| **阿里云盘 / 天翼云盘** | 可选 | 天翼在校园里接受度高；阿里需要客户端登录；百度限速太狠，不建议放主链 |
| **QQ 群文件 / 微信群文件** | **校内传播效率最高** | 群文件能长期留存、可断点续传，学生不用注册任何账号；建议配一句「群文件里搜沈农在途」 |
| **Gitee Releases** | 可选 | 国内速度快、无需代理；需要实名、仓库公开，等于把代码也放出去 |
| **酷安** | 可选 | 个人开发者可发应用，学生/数码人群集中；需要实名审核，且要写清楚权限用途 |
| **校内公众号 / 表白墙 / 贴吧** | 适合做「通知」 | 只发公告 + 网盘链接，正文短；这类渠道不适合挂 APK 直链 |
| **自建服务器 47.95.12.198** | 兜底 | 出口约 148 KB/s，8 MB 要一分多钟；只适合当备用直链，别当主链 |
| **对象存储（腾讯 COS / 阿里 OSS）** | 长期最优 | 几毛钱一个月，直链稳定不限速，可以给 `latest.json` 用；缺点是走公网流量，被刷了要盯着账单 |

**建议组合**：GitHub Release 做 `latest.json` 的官方源（App 内更新靠它），123 网盘 / 蓝奏云做「不会用 GitHub 的人」的入口，QQ 群文件做校内扩散，公告三处同一份文案。
