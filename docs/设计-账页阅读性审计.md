# 设计审计 · 账页主题阅读舒适度（课表 / 资讯 / 设置 / 我的）

> 审计日期：2026-11-14
> 审计对象：`ui/theme/EditorialTokens.kt`（账页 / LEDGER）+ 四个页面在账页语汇下的实际排版代码
> 测量基准：真机 vivo V2301A，1260×2800 px，**411dp 宽**（来源 `docs/真机验收-m19.1.md` 实测），密度 ≈3.07
> 口径：全部参数**取自代码字面值**；对比度用 WCAG 相对亮度公式**实算**（sRGB 线性化后 0.2126R+0.7152G+0.0722B）
> 阈值：中文正文行高 1.5–1.8×（<1.4 挤、>2.0 散）；行长 25–40 字/行（>45 累）；正文对比 ≥4.5:1、次要 ≥3:1

## 0. 结论速览

| 指标 | 实测 | 判定 |
|---|---|---|
| 正文行高倍数（资讯详情正文 14sp/25sp） | **1.79×** | ✅ 落在 1.5–1.8 |
| 正文行长（详情正文，411dp 屏） | **27.1 字/行** | ✅ 25–40 |
| 正文/次要对比度（账页亮色） | Ink 15.49 / InkSoft 8.73 / InkFaint 5.36 | ✅ 全部达标 |
| 最低对比度出现位置 | **课表「进行中」课程的侵蚀遮罩**（1.17:1）与「已上完」便签课名（2.19:1）；暗色下新闻/就业分类徽（3.90 / 4.28） | ❌ 低于 4.5 |
| 段间距 vs 行距（资讯详情正文） | 段间距 14dp / 行高 25sp = **0.56×** | ❌ 段落比行内还紧 |

**最严重的三个阅读问题（详见 §7）：**
1. 【严重】资讯详情正文段间距 14dp 小于行高 25sp——段落之间比行内更挤，长文读到第 3 段就糊成一片。
2. 【严重】课表正在上的课程被 92% 纸色侵蚀遮罩覆盖，课名对比度从 15.49:1 掉到 **1.17:1**，上课时课程名几乎不可读。
3. 【严重】课表课程格内字号 7.5–10sp（教师名 7.5sp ≈ 23px），低于中文舒适下限；行高倍数 1.3（账页 10/13）。

## 6. 密度：两种极端

| 类型 | 位置 | 实测 | 评价 |
|---|---|---|---|
| **密度过高** | 课表课程格 | 列宽 51.9dp、行高 ≥64dp，格内塞 3 行字（10/8/7.5sp）+ 3dp 色帽 + 3dp 内边距；教师名 7.5sp ≈ 23px | 超出中文可读下限，回行后 3 行仍放不下 6 字课名即省略号 |
| 密度过高 | 资讯紧凑卡 | 标题 14sp 2 行 + 9.5sp 元信息 1 行，整卡 ≈59dp，卡间距 8dp | 一屏 6–9 条，是用户可选密度，可接受 |
| 密度过高 | 我的页磁贴 | 9.5sp 副行 + 10sp 标题 + 12.5sp label，半磁贴内 26sp 数字与 9.5sp 副行跳 2.7 倍 | 层级靠字号跳级成立，但 9.5sp 微字占比过高 |
| **空白浪费** | 我的页尾部 | Spacer 22 + 版本号 + Spacer 18 + 木鱼 + Spacer 28 ≈ **68dp** | 首屏信息密度与页尾装饰失衡 |
| 空白浪费 | 资讯详情底部 | Space.xxl=24 + Space.huge=32 连续收尾 | 轻微 |

## 8. 修复优先级建议

1. **S1**：资讯详情正文把段落间距从 `spacedBy(14.dp)` 提到 ≥ 行高（建议 20–28dp，或直接去掉 14dp 间隔、改用段落间空行）。
2. **S2**：侵蚀遮罩加「文字保护层」——先对课名区域做保留（遮罩只压色帽/背景，不压文字），或把遮罩 alpha 0.92 降到 ≤0.35（此时课名对比仍 >4.5）。
3. **S3**：课表格内最小字号提到 ≥10sp，教师/教室合并成一行或缩短；左轴时间 8.5sp 提到 10sp。
4. **M1–M2**：已上完课名改 inkFaint 全不透明；暗色分类徽底色 alpha 22% 提到 32% 或文字用对应暗色变体。
5. **M3**：把四个页面的 fontSize/lineHeight 收敛到 `EditorialTypography` / `bodyLeading`，或删除无效 token，避免「改主题不生效」的维护陷阱。
6. **M4**：设置页风格说明移入「风格」点开后的弹窗/说明页（符合 AGENTS.md）。
