## 级别怎么区分

三份培养方案是**同一套专业在不同年份的不同版本**，必须能区分开。每条记录带三个字段：

| 字段 | 含义 | 2023 示例 | 2025 示例 |
| --- | --- | --- | --- |
| `年级` | 招生年级（数字） | `2023` | `2025` |
| `级别` | 展示用级别名 | `2023级` | `2025版` |
| `方案版本` | 源文件名 | `2023级沈阳农业大学本科人才培养方案` | `2025级沈阳农业大学本科人才培养方案` |

跨年级对齐用 `完整名称`（专业 + 班型），例如 `农学（卓越计划实验班）` 在三个年级都能对上；
`专业名称` 保留原文（2023/2024 写作 `农学-卓越计划实验班`，2025 写作 `农学（卓越计划实验班）`）。

## 字段说明

**培养方案**（`培养方案_YYYY.json`，数组，每项一个专业）

- `年级` / `级别` / `方案版本` / `专业名称` / `专业简称` / `完整名称` / `培养类型`
- `章节页范围`：PDF 物理页码区间
- `专业介绍` `培养目标` `毕业要求` `主干学科` `专业核心课程` `主要实践性教学环节`
  `专业方向` `修业年限` `授予学位`：原文段落（已去页眉页脚）
- `培养目标列表`：`[{编号, 内容}]`
- `毕业要求列表`：`[{编号, 标题, 内容, 指标点:[{编号, 内容}]}]`
- `课程设置与教学进程`：`[{课程代码, 课程名称, 英文名称, 课程类别, 课程性质,
  `学分, 总学时, 理论学时, 实验学时, 开课学期, 学分要求, 选修模块}]`
- `学分结构表` / `各学期学分分配表` / `对应矩阵`：原表单元格矩阵（保留表结构）
- `开课单位说明` / `课程替代情况说明`：仅 2025 版有内容

**课程大纲**（`课程大纲_2021_土地与环境学院.json`）

- `课程名称` / `英文名称` / `课程类型`（理论课 / 实验课 / 实践课）/ `pdf页码范围`
- `基本信息`：课程代码、开课教研室、学分、学时、课程类别、教材、参考书、执笔人、审核人、制定时间
- `章节`：`{"一、课程基本信息": 正文, ...}` 全文章节原文
- `教学章节`：`[{条目, 单位, 说明}]`（第X章 / 实验X / 实习X）
- `教学内容学时一览表`：`[{教学内容, 线上学时, 线下学时, 实验学时数, 学时合计}]`
- `课程目标列表`、`实践内容`

**课程总索引**（`课程总索引.json`，按课程代码归并四份文档）

- `课程名称` / `英文名称` / `学分` / `总学时` / `开课学期`：各文档出现过的值（数组，差异即版本差异）
- `出现于`：`2023级培养方案` / `2024级培养方案` / `2025版培养方案` / `2021版课程大纲`
- `文档覆盖数` / `有课程大纲` / `出现在年级`
- `专业_2023` / `专业_2024` / `专业_2025`：开设该课程的专业
- `方案页_2023` / `方案页_2024` / `方案页_2025` / `大纲页范围`：定位页码
- `大纲课程类型` / `开课教研室` / `课程类别`
- `归一名称` / `检索键`：罗马数字全半角统一后的检索用键

## 数据诚实说明

1. **学分合计 ≠ 官方总学分**：方案把选修课各模块的全部候选课都列出，学生只修其中一部分。
   要「最低毕业学分」请读 `学分结构表`，不要用课程行求和。
2. **课程性质是补齐值**：表中大量单元格纵向合并，程序按「同类别下延续上一个性质」补齐，
   类别切换时重置。原文确实为空的保留空串。
3. **同一课程代码跨年级可能不同**：学分/学时/开课学期有差异（如 `901041201 植物与肥料分析`
   在 2024 是 16 学时 1 学分、2025 是 66 学时 3.5 学分）。索引里全部保留在数组里，不做覆盖。
4. **`主干学科` 空值**：2023/2024 版「市场营销」原文即 `4.主干学科` 后直接接下一节，
   确为空项，按「数据诚实」留空，不臆造。
5. **OCR 页**：21 个页面文本层缺失或极短，用本机 `ollama glm-ocr:latest` 补识别；
   空白页已标注 `页面性质: 空白页`，识别的校名误字已统一校正为 `沈阳农业大学`。
6. **页码**：`pdf页码` / `章节页范围` 均为 PDF 物理页（从 1 开始），不是书内印刷页码。

## 提取实现要点

- 文本层优先：四份 PDF 均有可提取文本，表格用 PyMuPDF `find_tables()`，
  表头列名按 `课程代码/课程名称/学分/总学时/理论/实验/开课学期/学分要求` 定位，
  列名识别失败时按「9 位数字列 + 中文名列」内容兜底。三份方案的课程表结构一致，共用同一解析器。
- 2025 版课程名称单元格是「中文名/英文名」合排，按中英文正则拆分。
- 页眉 `本科专业人才培养方案-XXX` 用于切分专业段落；通识选修目录页按表头特征排除，
  不会污染专业页范围。
- 毕业要求兼容四种排版：`要求1【理想信念】`、`1.工程知识：`、`1.【理想信念】`、`1：内容`。
- 校验口径：每个专业页范围内所有 9 位课程代码，与解析出的课程行代码集合逐一比对，
  2023/2024/2025 三份均为零差异。
