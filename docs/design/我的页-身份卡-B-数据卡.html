「我的」页 · 身份卡（数据优先方向）

学生证是“身份”，但主人真正想点开看的是成绩。所以收起态就把最关键的一个数放到最大——加权绩点 3.37 当主角，姓名学号退为辅助；展开态是四个数摊开成仪表盘。
假数据：张三 / 2024000000 / 土地资源管理 · 2024级。下方两张卡片用灰块示意。

真机 360dp HARD 主题 · 农械橘 #C2521F 暂缺＝弱化灰字，不填 0 点开提示＝数值引力 + 主色按钮，不用蓝链

变体 A —— 主数字 + 卡内「看成绩」按钮

把“展开”做成卡内高饱和主色药丸，和巨号绩点并排；展开后数字让位，四个数摊开成 2×2 仪表盘。

变体 B —— 露边预览 + 通栏「展开完整成绩」按钮

收起态故意把下方仪表盘露一条边并用渐变吞掉，再用通栏主色药丸压在折叠线上；“被截断”本身就是最强暗示。
