三层筛（从粗到细）
1. 搜索框：名字 / 代码，随打随筛，右侧「搜」是主色实心（唯一的强动作）；
2. 类型 chip 带数量：实心选中 = 单选，浅字 = 可点；数量直接写在标签里，不用点进去数；
3. 学院横滑：一次只看一个学院，换学院不重置类型筛选。

按钮形态分三种，不靠文字解释
· 实心填充 = 已选中的单选；
· 细边框 = 可点的单选；
· 虚线边框 = 布尔开关（有学分 / 有 PDF 页），与「单选」在形态上就是两套东西。

列表行补两个事实：课程类型标签 + PDF 页码（pdf页码范围 一直躺在资产里没上屏）。页码只在此册有值时显示，没有就留空 —— 不猜。
