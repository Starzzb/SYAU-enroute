# 06: 教师详情接入学院官网公开信息（带缓存）

**What to build:** 学生在「查教师」搜到某位老师后点进去，能看到学院官网上的公开资料
（职称、研究方向、办公地点、联系邮箱、指导研究生等，按实际可得的来），
页面顶部标注**信息来自学院官网 + 抓取时间**；离线时显示上次缓存的内容而不是空白。

**Blocked by:** 05（调研结论）、01（教师列表稳定可用）

**Status:** wontfix（被票 08 吸收）

## 要做的事

- 按 05 的字段表实现解析器（VSB 站群模板，尽量复用现有 `FeedParser` 的通用抽取能力）
- 按 05 的缓存方案落地：键、TTL、手动刷新、失败时回退到旧缓存并标注时间
- 教师详情页：教务侧字段（院系/职称/工号/学期）与官网字段分区显示，缺失项整块不显示
- 官网只在部分网络可达时，给可执行提示，不显示误导性空态
- 缓存内容只落公开教师信息，**不落学生个人信息**

## 验收标准

- [ ] 校园网下搜教师 → 点详情 → 能看到官网公开资料与抓取时间
- [ ] 断网/换到移动数据后重进同一位教师，显示缓存内容并标注时间
- [ ] 官网改版导致解析失败时：不崩、不显示假数据、明确说「没解析到」
- [ ] 解析与缓存键逻辑有 JVM 单测（用 05 抓的样本做夹具）
- [ ] 全量单测通过，`assembleDebug` 成功
- [ ] `docs/URP-学生端接口清单.md` 或新文档里补上官网信息源的实测记录

## 边界

- 只读；不抓学生个人信息；不做任何写操作
- 写盘范围：`data/faculty/*`（新目录）、`ui/home/TeacherScreen.kt`、`data/Prefs.kt`、
  `ui/TimetableViewModel.kt`、`ui/AppState.kt`、测试、`docs/`
